8. 도움 받기

가능한 버그, 개선 요청 또는 코드 질문이 있는 경우 다음 페이지에 문제를 제출하세요. OpenFAST Github 저장소.

OpenFAST 사용 관련 질문의 경우 사용자는 다음을 고려해야 합니다. FAST 포럼, FAST 관련 Q&A의 10년 이상의 유산을 제공합니다. GitHub 문제나 포럼에 질문을 게시하기 전에 포럼의 검색 기능을 사용해야 합니다.

연락주세요 제이슨.존크먼@nlr.정부 또는 앤디.플랫@nlr.정부 OpenFAST 개발 계획이나 기여 방법에 관한 질문이 있습니다.
