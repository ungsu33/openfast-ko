4.12.2. 출력 파일

SeaState는 에코 파일, 파고 파일, 파동 운동학 파일, 요약 파일, 시계열 파일 등 5가지 유형의 출력 파일을 생성합니다. 다음 섹션에서는 이러한 파일의 목적과 내용을 자세히 설명합니다. SeaState 드라이버 파일 또는 SeaState 기본 입력 파일에서

4.12.2.1. 에코 파일

다음을 설정하면 에코 플래그를 TRUE로 설정하면 해당 파일의 내용이 명명 규칙을 사용하여 파일에 반영됩니다. OutRootName.dvr.ech HydroDyn 기본 입력 파일용 및 OutRootName.SeaSt.ech SeaState 기본 입력 파일의 경우 입니다. OutRootName 는 ​​드라이버 입력 파일의 SEASTATE 섹션에 지정되거나 OpenFAST 프로그램에 의해 지정됩니다. 에코 파일은 입력 파일을 디버깅하는 데 유용합니다. 입력 파일을 구문 분석하는 동안 SeaState에서 오류가 발생하면 에코 파일의 내용이 잘립니다. 오류는 일반적으로 마지막으로 성공적으로 에코된 줄 다음 줄에 해당합니다.

4.12.2.2. 파고 파일 드라이버 파일의

설정 WaveElevSeriesFlag 를 TRUE로 설정하면 전체 SeaState 파도 그리드의 파도 고도를 이름이 있는 텍스트 기반 파일로 출력할 수 있습니다. OutRootName.WaveElev.out. 출력 파동 그리드는 기본 SeaState 입력 파일의 SPATIAL DISCRETIZATION 섹션에 의해 제어됩니다. 이러한 파도 고도는 다음과 같이 결정된 파도 고도와 별개이며 별도로 출력됩니다. 대신 시계열 출력 파일에 기록되는 SeaState 기본 입력 파일의 NWaveElev . 파고 출력 파일 OutRootName.WaveElev.out 에는 1차 항과 2차 항의 합인 총 파고 고도가 포함됩니다(2차 파동 운동학이 선택적으로 활성화된 경우). 여기에 설명된 파고 파일은 시각화 목적으로 유용합니다.

4.12.2.3. 파동 운동학 파일

WrWvKinMod 는 SeaState 드라이버의 파동 운동학 출력을 제어합니다. 드라이버는 전역 원점(0,0)에서 파고 시계열을 별도의 출력으로 출력합니다. 기본 SeaState 입력 파일의 .Elev 파일의 경우 WrWvKinMod = 1. 이 파일은 유효한 파일로도 사용됩니다. WvKinFile 용 WaveMod = 5(외부에서 생성된 파고 시계열). 이는 다음을 사용하여 얻은 파동장 출력과 독립적인 별도의 파동 고도 출력입니다. WaveElevSeriesFlag = TRUE 및 다음으로 얻은 파고 시계열 SeaState 기본 입력 파일의 NWaveElev .

경우 WrWvKinMod = 2, SeaState는 확장자가 있는 8개 출력 파일의 모든 파동 그리드 지점에서 전체 파동 운동학(속도, 가속도, 동적 압력 및 파고 고도)을 출력합니다. .Vxi, .Vyi, .Vzi, .Axi, .Ayi, .Azi, .DynP및 이 플래그 값 아래에 .Elev. 속도 및 가속도 출력은 모두 지구에 고정된 전역 좌표계에 있습니다. 이 파일은 다음과 같이 유효합니다. WvKinFile 용 WaveMod = 6(외부에서 생성된 전체 파동 운동학 시계열)이며 사용자가 자신의 입력 파일을 작성하려는 경우 템플릿으로 사용할 수 있습니다. WaveMod = 6.

4.12.2.4. 요약 파일

SeaState는 명명 규칙을 사용하여 요약 파일을 생성합니다. OutRootName.SeaSt.sum 경우 SeaStSum 매개변수는 TRUE로 설정됩니다. 이 파일에는 물 밀도, 수심, 정수위, 파도 격자, 1차 파도 주파수 구성 요소 및 사용자가 요청한 시계열 출력을 포함하여 바다 상태 모델에 대한 주요 정보가 요약되어 있습니다.

4.12.2.4.1. 사용자 요청 출력 요약

요약 파일에는 사용자가 요청한 모든 파동 고도 및 파동 운동학 시계열 출력 채널에 대한 정보가 포함되어 있습니다.

4.12.2.4.1.1. 파동 운동학 출력 위치

첫 번째 열에는 SeaState 입력 파일의 OUTPUT CHANNELS 섹션에 입력된 파동 운동학 출력 위치의 인덱스가 나열되어 있습니다. 자이, 이및 이 플래그 값 아래에 지 는 전역 관성 프레임 좌표계에서 파동 운동학 출력 위치의 공간 좌표를 제공합니다.

4.12.2.4.1.2. 파고 출력 위치

첫 번째 열에는 SeaState 입력 파일의 OUTPUT CHANNELS 섹션에 입력된 파고 출력 위치의 색인이 나열되어 있습니다. 자이 및 이 는 전역 관성 프레임 좌표계에서 파고 출력 위치의 공간 좌표를 제공합니다.

4.12.2.4.1.3. 요청된 출력 채널

SeaState 입력 파일의 OUTPUT CHANNELS 섹션에 입력된 대로 요청된 모든 시계열 출력 채널의 문자열 레이블이 여기에 요약되어 있습니다.

4.12.2.4.2. 파동 주파수 부품

이 섹션은 자유 표면의 (0,0)에서 1차 파동 고도의 주파수 영역 설명(이산 푸리에 변환 또는 DFT의 관점에서)을 제공하지만 다음과 같은 경우에는 기록되지 않습니다. WaveMod = 0 또는 6. 첫 번째 열, 인덱스는 각 파동 주파수 구성 요소의 인덱스를 식별합니다. 유한 깊이 파수, 각주파수 및 파동 성분의 방향은 다음과 같이 지정됩니다. k, 오메가및 이 플래그 값 아래에 방향각각. 마지막 두 열은 실수(REAL(DFT{WaveElev})) 및 허수(IMAG(DFT{WaveElev})) 1차 DFT 파동 진폭의 일부입니다. DFT는 음의 주파수 성분과 양의 주파수 성분을 모두 생성합니다. 시간 영역 파고가 실수 값이기 때문에 음의 주파수 성분은 양의 주파수 성분의 켤레 복소수입니다. DFT의 음의 주파수 성분과 양의 주파수 성분 간의 관계는 다음과 같습니다. \(k\left( - \omega \right) = - k\left( \omega \right)\) 및 \(H\left( - \omega \right) = {H\left( \omega \right)}^{*}\), 여기서 H 는 파고의 DFT이고 * 는 공액복합체를 나타냅니다.

4.12.2.5. 결과 파일

SeaState 시계열 결과는 명명 규칙을 사용하여 텍스트 기반 파일에 기록됩니다. OutRootName.SeaSt.out 때 OutSwtch 는 1 또는 3으로 설정됩니다. SeaState가 OpenFAST에 연결되어 있고 OutSwtch 가 2 또는 3으로 설정된 경우 OpenFAST는 SeaState 결과를 포함하는 마스터 결과 파일을 생성합니다. 결과는 표 형식으로 되어 있으며, 각 열은 데이터 채널이고(첫 번째 열은 항상 시뮬레이션 시간임), 각 행은 시뮬레이션 출력 시간 단계에 해당합니다. 데이터 채널은 SeaState 기본 입력 파일의 OUTPUT CHANNELS 섹션에 지정됩니다. SeaState에서 생성된 파일의 열 형식은 다음을 사용하여 지정됩니다. OutFmt 및 OutSFmt 매개변수입니다.
