4.8.14. 부록 F. SubDyn의 주요 변경 사항

처음 출시되었을 때 SubDyn(v0.4)은 FAST v8의 문서화되지 않은 기능으로 포함되었으며 독립 실행형 아카이브로 패키지되었습니다. v0.4부터 SubDyn은 FAST v8 및 OpenFast에 잘 통합되었으며 독립형 형태도 사용 가능합니다. 이 부록에서는 v0.4 이후 SubDyn에 대한 중요한 수정 사항을 간략하게 설명합니다. 다음은 사용자가 느낄 수 있는 주요 변경 사항입니다. 자세한 내용은 변경 로그.txt 공식 아카이브 및 GitHub 로그 내의 텍스트 파일입니다.

4.8.14.1. V1.05.00 (2021년 10월)

  • 버전 1.05.00은 OpenFAST 버전 3.1+와 통합됩니다.

  • SubDyn 드라이버는 지정된 노드에서 로드를 지원합니다.

  • 시각화를 위해 Craig-Bampton/Guyan 및 FEM 모드를 JSON 형식으로 출력

  • 다양한 지점에 강체 질량 매트릭스가 포함된 간소화된 yaml 파일 출력

  • 견고한 어셈블리에 대한 버그 수정.

  • 요약 파일에 보고된 대량에 대한 버그 수정

4.8.14.2. V1.04.00 (2020년 9월)

  • 버전 1.04.00은 OpenFAST 버전 2.4와 통합됩니다.

  • 부재 유형: 빔, 고정 링크, 프리텐션 케이블

  • 조인트 유형: 캔틸레버, 유니버설, 핀, 볼

  • 집중질량에 대한 모든 항 입력

  • Guyan 댐핑 매트릭스

  • 추가 레버 암

  • SoilDyn의 커플 링

  • 제한된 노드에서 유연한 고정도를 통한 토양-구조 상호 작용(SSI)과 해당 노드에서 경계 조건을 시뮬레이션하는 6x6 강성 및 질량 매트릭스를 허용하는 새로운 입력 파일이 포함됩니다.

  • 제어 가능한 초기 장력 케이블 요소

4.8.14.3. V1.03.00a-rrd(2017년 9월)

  • 버전 1.03.00a-rrd는 OpenFast 소프트웨어.

4.8.14.4. V1.01.01a-rrd(2014년 9월)

버전 1.01.01a-rrd는 FAST v8 소프트웨어 v8.09.00a-bjj.

  • 유한 요소 고유값 버그 수정: 전체 시스템 고유값이 요약 파일에 잘못 보고되었지만 결과에는 더 이상 영향이 없습니다. 이 버그는 이제 수정되었습니다.

  • 전단 면적 보정 계수 개선: Timoshenko 처리의 전단 면적 보정 계수가 이제 Steinboeck et al.과 일치합니다. (2013).

  • TP 반응에 대한 공식이 이론 매뉴얼을 준수하도록 재배열되었으며 출력 결과에 아무런 영향도 미치지 않습니다.

4.8.14.5. V1.01.00a-rrd(2014년 6월)

버전 1.00.01a-rrd는 FAST v8 소프트웨어 v8.08.00c-bjj.

새로운 구현에는 잘 정의된 데이터 교환 인터페이스( FAST 모듈화 프레임워크를 따르는FAST 모듈화 프레임워크에 따라)는 SubDyn을 다른 다중물리 소프트웨어 패키지에 훨씬 더 간단하게 통합할 수 있게 해줍니다.

버전 v0.4 이후 몇 가지 개선 사항과 버그 수정이 구현되었으며 모듈은 광범위한 검증 노력을 거쳐 좋은 결과를 얻었습니다.

  • Eigensolver 버그 수정: LAPACK 솔버는 단정밀도에서 불안정한 것으로 판명되었으며 이제는 코드의 다른 부분에서 사용되는 정밀도에 관계없이 배정밀도로만 실행됩니다.

  • 입력 파일 형식이 변경되었습니다. 부록 A의 샘플 입력 파일과 다음 참고 사항을 참조하세요.

    • 첫 번째 헤더 줄이 제거되었습니다.

    • 시뮬레이션 제어 섹션:

      • SDeltaT: 이제 "DEFAULT" 키워드(0.0 대신)가 SubDyn의 시간 통합에 글루 코드 시간 단계가 사용됨을 나타내는 데 사용됩니다.

      • IntMethod: 허용되는 값은 이제 1-4(0-3 대신)입니다.

      • SttcSolve: 새로운 플래그가 도입되었습니다. TRUE로 설정하면 SIM(정적 개선 방법)이 사용됩니다.

    • FEA 및 Craig-Bampton 매개변수 섹션:

      • v0.4에서는 유지된 모든 Craig-Bampton 모드에 대해 감쇠 계수를 지정하거나 모든 모드에 대해 한 번만 지정해야 했습니다(만일 CBMod = 거짓). 이 버전에서는 사용자가 감쇠 계수를 원하는 만큼 입력할 수 있습니다. 유지된 C-B 모드의 개수(N모드)는 입력된 감쇠 계수 수(J댐핑), 마지막 댐핑 값은 나머지 모든 모드에 대해 복제됩니다.

    • 기본 반응 조인트, 인터페이스 조인트, 멤버 및 멤버 코사인 행렬 섹션:

      • 입력 파일의 모든 테이블에는 헤더 아래에 단위가 있는 한 줄이 있어야 합니다.

    • 출력: 요약 및 Outfile 섹션:

      • 이 섹션에는 이제 "출력: Fast/Subdyn 출력 파일 변수"라는 제목의 섹션에서 이전에 할당된 매개변수도 포함되어 있습니다.

  • 요약 파일의 수량 중 일부가 수정되었습니다. 실제로 일부 출력 행렬은 인덱스 불일치로 인해 잘못된 값으로 출력되었습니다. 새 요약 파일은 더 짧으며 컴파일러 지시어 DEBUG가 설정되지 않은 한 일부 CB 메서드 매트릭스를 포함하지 않습니다.

  • SIM. 이 새로운 구현은 특정 부하(정적 중력 및 부력 부하 또는 터빈에서 전달되는 고주파 부하 등)의 영향을 포착하는 데 필요한 모드 수를 최소화하는 데 도움이 됩니다. 이전 버전에서는 정적 및 고주파수 힘에 의해 자극된 하부 구조 모드를 사용하기 위해 많은 수의 내부 모드가 필요했습니다. 이러한 모드는 더 이상 필요하지 않으며 정확한 결과를 얻으면서도 더 적은 수의 모드를 유지할 수 있습니다(참조: 섹션 4.8.6). SIM이 활성화되면 Craig-Bampton 감소에 의해 고려되지 않는 모든 모드가 준정적으로 처리됩니다.

  • 이제 하위 구조의 첫 번째 고유 주파수가 전체 시스템의 예상 에너지 포함 모드보다 훨씬 높은 경우 내부 C-B 모드를 유지하지 않고 SIM에만 의존할 가능성이 있습니다.

  • FAST 내의 SubDyn 결합에는 이제 HydroDyn 유체 역학 모듈과의 완전한 유체 탄성 결합이 포함됩니다.
