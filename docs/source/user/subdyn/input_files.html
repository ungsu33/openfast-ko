4.8.3. 입력 파일

사용자는 기본 SubDyn 입력 파일을 통해 형상 및 속성을 포함한 하부 구조 모델 매개변수를 지정합니다. 독립형 모드에서 사용하는 경우 추가 드라이버 입력 파일이 필요합니다. 이 드라이버 파일은 TP 기준점의 동작을 포함하여 일반적으로 FAST에 의해 SubDyn에 제공되는 입력을 지정합니다.

행 수가 지정된 테이블을 제외하고는 입력 파일에서 행을 추가하거나 제거해서는 안 됩니다.

토양 구조 정보가 포함된 추가 입력 파일(SSIfile)는 사용자가 기본 SubDyn 입력 파일의 섹션 아래에 경로를 지정하여 제공할 수 있습니다. BASE REACTION JOINTS.

SubDyn는 SI 시스템(kg, m, s, N)을 사용합니다. 별도로 지정하지 않는 한 각도는 라디안 단위로 간주됩니다.

4.8.3.2.4. 적용된 하중

입력 파일의 다음 섹션에서는 구조의 지정된 접합부에 하중을 적용하는 옵션을 제공합니다. nAppliedLoads [-]는 다음 표에 나열된 적용 하중 수를 지정합니다. 사용자는 정상 하중과 비정상 하중의 조합을 지정할 수 있습니다(둘 다 함께 추가됨). 하중은 전역 좌표계에 있습니다. 정상 하중은 테이블의 열(Fx, Fy, Fz, Mx, My, Mz)로 제공되는 반면, 비정상 하중은 CSV 파일로 제공됩니다. CSV 파일 이름은 테이블의 마지막 항목에 제공됩니다. 파일 이름이 비어 있으면 비정상 하중을 읽지 않습니다. 적용된 하중 테이블의 예는 다음과 같습니다.

4.8.3.3. SubDyn 기본 입력 파일

SubDyn 입력 파일은 하부 구조 형상, 통합 및 시뮬레이션 옵션, 유한 요소 매개변수 및 출력 채널을 정의합니다. 부재의 형상은 전역 참조 시스템(관성 프레임 좌표계)에서 변위되지 않은 하부 구조의 접합 좌표로 정의되며, 원점은 편향되지 않은 타워 중심선과 MSL의 교차점 또는 지상 기반 구조물의 경우 지면 수준입니다. 부재는 두 개의 관절을 연결합니다. 여러 멤버가 공통 조인트를 사용할 수 있습니다. 유체역학 및 중력 하중은 노드에 적용되며, 이는 부재를 여러 개로 세분화한 결과입니다(NDiv 입력) 요소(노드는 각 요소의 끝에 위치함)로, 모듈에서 계산됩니다. 부재 속성에는 외경, 두께, 재료 밀도, 영률 및 전단 계수가 포함됩니다. 부재 속성은 조인트에서 지정됩니다. 속성이 한 조인트에서 다른 조인트로 변경되면 내부 노드에 대해 선형으로 보간됩니다. 기하학적 특성과 달리 재료 특성은 단일 부재 내에서 변경할 수 없습니다.

파일은 여러 기능 섹션으로 구성됩니다. 각 섹션은 SubDyn 모델 및 하위 구조의 측면에 해당합니다.

이 설명서가 테이블 항목의 ID를 참조하는 경우 이는 테이블 항목에 대한 정수 식별자이며 지정된 테이블 항목에 대해 고유해야 합니다.

IJointID, 이는 다음과 일치해야 합니다. JointID STRUCTURE JOINTS 테이블에서 값을 찾았습니다. 캔틸레버 조인트만 인터페이스 조인트 역할을 할 수 있습니다. 또한 동일한 강체 어셈블리에 속하는 여러 조인트를 인터페이스 조인트로 할당할 수 없습니다. (이 또한 중복됩니다.)

각 인터페이스 조인트에는 전환 부분 ID 또는 TPID. 고유하게 식별되는 각 전환 부분 TPID, 다른 모든 전환 조각과 독립적으로 편향될 수 있으며 여러 관절을 동일하게 할당하여 각 전환 조각에 단단히 부착할 수 있습니다. TPID. 모든 관절이 동일하다는 점에 유의하십시오. TPID 공유된 전환 부분에 대한 견고한 연결을 통해 효과적으로 서로 견고하게 연결됩니다. 고정 바닥 구조의 경우 모든 TPID 테이블에 존재하는 것은 1부터 시작하는 연속적인 정수 시퀀스를 형성해야 합니다. 플로팅 구조의 경우 정확히 하나의 조인트가 할당될 수 있습니다. TPID = 0. 이 조인트는 부동 하부 구조에 대한 강체 기준점 역할을 하는 더미 전환 부분입니다. 대안적으로, TPID = 0은 플로팅 구조에 대해 생략될 수 있으며, 이 경우 정확히 하나의 전환 부분만 있을 수 있습니다. TPID = 1(여러 관절을 할당할 수 있음) 이 경우 단일 전환 부분은 강체 기준점 역할도 하며 이전 버전의 SubDyn가 부동 하부 구조를 모델링하는 방식을 복제합니다. 정확성과 수치 안정성을 위해 플로터 중심 근처의 조인트를 강체 기준점으로 선택하여 강체 변위에 대한 탄성 편향을 최소화하는 것이 좋습니다.

여러 개의 독립적인 전환 부분을 포함하는 기능이 SubDyn에 추가되어 멀티로터 시스템의 하위 구조(고정 바닥 및 부동) 모델링이 가능해졌습니다. 고정 바닥 구조의 경우 인터페이스 조인트가 다음에 할당됩니다. TPID = 1은 첫 번째 터빈을 시뮬레이션하는 첫 번째 ElastoDyn 인스턴스의 플랫폼 기준점에 견고하게 연결됩니다. 할당된 인터페이스 관절 TPID = 2는 두 번째 터빈을 시뮬레이션하는 두 번째 ElastoDyn 인스턴스의 플랫폼 기준점에 견고하게 연결됩니다. 등. 플로팅 구조의 경우에도 동일하게 적용됩니다. 단, 특수 강체 기준점은 다음에 할당됩니다. TPID = 0. SubDyn는 ElastoDyn 인스턴스(또는 SubDyn 독립 실행형 드라이버에 정의된 전환 부분)에 연결되지 않은 이 지점에 대한 플로터의 강체 모션을 해결합니다. 강체 기준점의 모션은 플로터의 변위된 "강체" 위치를 정의하며 작은 탄성 편향은 이 강체 구성을 기준으로 해결됩니다. 이 공식은 탄성 변형을 선형으로 유지하면서 잠재적으로 큰 강체 운동을 수용하는 데 필요합니다. 대안으로, 터빈이 하나만 있는 부유식 시스템의 경우 강체 기준점은 다음과 같습니다. TPID = 0은 생략될 수 있으며, 이 경우 유일한 전환 조각이 허용됩니다( TPID = 1)은 이전 버전의 OpenFAST와 마찬가지로 ElastoDyn에 대한 인터페이스이자 SubDyn의 강체 기준점 역할을 합니다.

4.8.3.3.14. 출력: 요약 및 개요 파일

입력 파일의 이 섹션에서 사용자는 원하는 출력 동작에 대한 플래그와 스위치를 설정합니다.

다음 두 입력은 모드 형상을 디스크에 기록해야 하는지 여부를 지정합니다. OutCBModes Guyan 및 Craig-Bampton 모드의 출력을 제어하는 ​​플래그입니다. 비슷하게, OutFEMModes, FEM 모드(CB 감소 이전에 제약 조건이 있는 전체 시스템)의 출력을 제어합니다. 현재는 처음 30개의 FEM 모드만 디스크에 기록되지만 사용자가 선택한 CB 모드는 모두 기록됩니다. 두 입력 모두에 대해 다음 옵션을 사용할 수 있습니다: 0, 출력 없음, 1, JSON 형식으로 출력. JSON 파일에는 노드 좌표, 노드 간 연결, 각 모드 및 노드의 변위, 각 모드의 주파수가 포함됩니다. JSON 형식 파서를 사용하는 Matlab 또는 Python을 사용하면 이러한 파일을 쉽게 읽을 수 있습니다. 파일은 viz3danim 도구를 사용하여 모드를 시각화하기 위해 열 수 있습니다(참조: 라이브 버전 , 또는 그 github 저장소).

현재, OutCOSM 무시됩니다. 향후 릴리스에서는 다음을 지정합니다. OutCOSM = TRUE는 SubDyn가 출력 채널 목록에서 요청된 멤버에 대해서만 요약 파일에 방향 코사인 행렬(편향되지 않음)을 포함하도록 합니다.

지정 OutAll = TRUE는 SubDyn가 모든 조인트(내부 노드 아님)에서 힘과 모멘트를 출력하도록 합니다. 즉, 특정 관절에 연결된 각 부재의 끝 절점에서 3개의 힘과 3개의 모멘트의 정적(탄성) 성분과 동적(관성) 성분이 모든 관절에 대해 출력됩니다. 이러한 출력은 OutRootName.SD.out* 출력 파일과 아래 출력 채널 섹션을 통해 직접 지정된 출력 파일입니다.

4.8.3.4. SSI 입력 파일

개별 SSI 파일(SSIfiles)은 제한된 각 노드에 대해 제공될 수 있으므로 SSIfiles의 최대 개수는 다음과 같습니다. NReact. SSIfile에서는 SSI 질량 행렬에 대해 최대 21개의 요소와 최대 21개의 SSI 강성 행렬 요소를 제공할 수 있습니다. 질량과 강성 요소는 말뚝과 지반 효과를 모두 설명합니다. 이 시점에서는 추가 댐핑을 제공할 수 없습니다.

'Mtxtz', 'Mtytz', 'Mtztz'. 행렬 요소가 제공되지 않으면 기본적으로 0으로 설정됩니다. 레이블에는 강성 또는 질량 행렬 요소를 지정하는 'K' 또는 'M'이 포함되어 있으며, 적용 방향은 예를 들어 'Kxy'는 y를 따른 단위 변위로 인해 x를 따른 힘을 나타냅니다.
