4.8.4. 출력 파일

SubDyn는 에코 파일, 요약 파일, 시계열 결과 파일의 세 가지 유형의 출력 파일을 생성합니다. 다음 섹션에서는 이러한 파일의 목적과 내용을 자세히 설명합니다.

4.8.4.1. Echo 파일

사용자가 설정한 경우 Echo SubDyn 드라이버 파일 또는 기본 SubDyn 입력 파일의 TRUE에 플래그를 지정하면 해당 파일의 내용이 명명 규칙을 사용하여 파일에 반영됩니다. OutRootName.dvr.ech 드라이버 입력 파일의 경우 OutRootName.SD.ech 기본 SubDyn 입력 파일의 경우. OutRootName 드라이버 입력 파일의 SUBDYN 섹션이나 FAST 입력 파일에 지정됩니다. 에코 파일은 입력 파일을 디버깅하는 데 유용합니다. SubDyn가 입력 파일을 구문 분석하는 동안 오류가 발생하면 에코 파일의 내용이 잘립니다. 오류는 일반적으로 마지막으로 성공적으로 에코된 줄 다음 줄에 해당합니다.

4.8.4.2. 요약 파일

SubDyn는 명명 규칙을 사용하여 요약 파일을 생성합니다. OutRootName.SD.sum 만약에 SumPrint 매개변수는 TRUE로 설정됩니다. 이 파일에는 다음을 포함하여 하위 구조 모델에 대한 주요 정보가 요약되어 있습니다.

  • 변위되지 않은 노드 형상: 모든 항목의 목록(NNodes) 노드와 X,Y,Z 전역 SS 좌표계의 좌표입니다. 참고하세요 NNodes 다음보다 크거나 같을 수 있습니다. NJoints, 에 따라 NDiv (기본 입력 파일 매개변수).

  • 끝 노드의 요소 연결 및 속성: 모든 목록(NElems) 요소, 시작 및 끝 노드(Node_I, Node_J) 및 속성 집합의 ID(Prop_I, Prop_J) 시작 및 끝 노드에 있습니다. NElems 다음보다 크거나 같을 수 있습니다. NMembers, 에 따라 NDiv (기본 입력 파일 매개변수).

  • 속성 집합. 테이퍼 멤버를 사용하는 경우 보간된 직경 및 두께 값을 기준으로 기본 입력 파일에 지정된 속성 세트 외에 추가 속성 세트가 포함될 수 있습니다. 헤더와 그 의미는 섹션에 설명된 것과 동일합니다.

  • 반응 DOFs 및 인터페이스 DOFs 및 관련 고정성; DOFs의 실제 인덱스(DOF_ID)는 반응 및 인터페이스 노드와 연관되어 고정성 수준을 구별하기 위해 (1/0) 플래그와 함께 나열됩니다.

  • 집중 미사 일정. 이는 기본 입력 파일에 있는 해당 섹션의 에코입니다. 섹션을 참조하십시오.

  • 조인트, 노드 및 해당 질량에 대한 연결을 포함한 멤버 일정. 테이블에는 식별자별로 모든 구성원이 나열됩니다(MemberID), 시작 및 끝 노드 포함(Joint1_ID, Joint2_ID), 관련질량(대량의) 및 멤버 길이에 따른 노드 식별자 목록입니다.

  • 멤버의 방향 코사인 행렬입니다. 각 행(열 2-10)은 방향 코사인 행렬 항목(DC(1,1) ~을 통해 DC(3,3)) 식별자가 첫 번째 열에 나열된 멤버의 경우입니다. 방향 코사인 행렬은 각 멤버에 대해 전역 참조에서 로컬 좌표계로의 변환을 지정합니다.

  • TP 기준점이 자유 끝이라고 가정할 때 전체 하부 구조 시스템에 대한 정렬된 고유 주파수[헤르츠(Hz)]입니다(ElastoDyn에서 FAST까지의 가능한 결합을 무시함). 총 가 있습니다 NDOFs 고유주파수와 고유벡터.

  • TP 기준점이 고정 끝이라고 가정할 때 C-B 감소 시스템에 대한 정렬된 고유 주파수(Hz)입니다. 총 가 있습니다 N모드 C-B는 고유주파수와 고유벡터를 줄였습니다.

  • 전체 하부 구조 시스템 고유 벡터. 각 열은 파일에서 이전에 식별된 해당 고유 주파수와 연관된 고유 벡터를 나타냅니다.

  • C-B 감소 시스템 고유 벡터(PhiM 행렬). 각 열은 파일에서 이전에 식별된 해당 고유 주파수와 연관된 고유 벡터를 나타냅니다.

  • PhiR 인터페이스 DOFs의 단위 강체 운동으로 인해 발생하는 내부 노드의 행렬 또는 변위(섹션 참조). 매트릭스의 각 열은 각 베이스 및 인터페이스 조인트에 대한 인터페이스 DOF를 따라 지정된 단위 강체 모션에 대한 내부 DOF 변위를 나타냅니다.

  • TP 기준점을 참조하는 하부 구조 등가 강성 및 질량 행렬(KBBt 및 MBBt), Guyan 감소를 기반으로 합니다. 이는 ElastoDyn에 대한 타워 고유 모드를 계산하는 동안 하부 구조 유연성의 효과를 계산하는 데 유용합니다.

  • 전역 원점을 기준으로 한 강체 등가 질량 행렬(MRB); 6x6 질량 행렬.

  • 하부 구조 총(건조) 질량.

  • 전체 좌표계의 하부 구조 질량 중심 좌표입니다.

요약 파일과 변수의 다양한 섹션은 설명이 필요 없으며 파일에서 쉽게 식별할 수 있습니다.

4.8.4.3. 결과 파일

SubDyn 시계열 결과는 명명 규칙을 사용하여 텍스트 기반 파일에 기록됩니다. OutRootName.SD.out 언제 OutSwtch 1개 또는 3개로 설정됩니다. SubDyn가 FAST에 결합되고 OutSwtch 2 또는 3으로 설정되면 FAST는 SubDyn 결과를 포함하는 마스터 결과 파일을 생성합니다. 결과는 OutRootName.SD.out 각 열은 데이터 채널(첫 번째 열은 항상 시뮬레이션 시간임)이고 각 행은 시뮬레이션 시간 단계에 해당하는 테이블 형식입니다. 데이터 채널은 입력 파일의 SDOutList 섹션에 지정됩니다. SubDyn 생성 파일의 열 형식은 다음을 사용하여 지정됩니다. OutFmt 및 OutSFmt 입력 파일의 매개변수입니다.
