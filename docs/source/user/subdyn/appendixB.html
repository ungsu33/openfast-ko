4.8.10. 부록 B. OC4 재킷 드라이버 파일

SubDyn의 드라이버 입력 파일 (OC4 Jacket Driver File):

이 파일에는 환경 조건(중력 및 수심), 수치 솔루션 매개변수(예: 적분 시간 간격, 시간 단계 수), 전역 참조 프레임의 TP 참조점 좌표, 전역 Z축에 대한 구조 형상의 회전 각도(도), TP 참조점 변위, 속도 및 가속도(파일의 정상 상태 또는 시계열)에 대한 입력 모드 및 그렇지 않은 경우 관련 입력 파일이 포함됩니다. 정상상태 입력.
