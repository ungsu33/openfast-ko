4.8.12. 부록 D. 출력 채널 목록

이것은 SubDyn 모듈에 대해 가능한 모든 출력 매개변수의 목록입니다. 이름은 의미별로 그룹화되어 있지만 사용자가 적합하다고 생각하는 대로 SubDyn 입력 파일의 OUTPUT CHANNELS 섹션에서 정렬할 수 있습니다. \(M \alpha N \beta\), 노드를 나타냅니다. 회원의 \(\beta\) 부재의 \(\alpha\), 여기서 \(\alpha\) 는 [1,99] 범위의 숫자이고 행에 해당합니다. MEMBER OUTPUT LIST 테이블의 \(\alpha\) (참조: 섹션 4.8.3.3.15) 및 \(\beta\) 는 [1,9] 범위의 숫자이고 노드에 해당합니다. \(\beta\) 의 NodeCnt 목록입니다.

일부 출력은 SS 참조 좌표계(전역 관성 프레임 좌표계)에 있으며 접미사로 끝납니다. ss; 다른 것들은 로컬(회원) 참조 시스템을 참조하며 접미사 "Xe", "Ye" 또는 "Ze"를 갖습니다(섹션 7 참조).
