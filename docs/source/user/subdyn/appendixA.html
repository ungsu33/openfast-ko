4.8.9. 부록 A. OC4 재킷 입력 파일

SubDyn의 기본 입력 파일 (OC4 Jacket SubDyn's Input File):

이 파일에는 통합 방법에 대한 정보가 포함되어 있습니다(예: Adams-Bashforth 4 일} 순서), 수치해 매개변수(예: 적분 시간 간격, 정적 솔버 플래그, Craig-Bampton 감소 내에서 유지할 모드 수), 유한 요소 분석 정보(빔 요소 모델, 부재당 요소 수), 조인트, 부재 연결 및 부재 단면 속성을 통한 빔 부재의 기하학적 정의. 이 파일은 또한 SSI 입력 파일(토양/말뚝 강성 및 질량 행렬)을 지정합니다.
