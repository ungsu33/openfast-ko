4.8.2. SubDyn 실행

이 섹션에서는 개인용 컴퓨터에서 SubDyn을 얻고 실행하는 방법에 대해 설명합니다. 소프트웨어의 독립 실행형 버전과 FAST 결합 버전이 모두 고려됩니다.

4.8.2.1. SubDyn 소프트웨어 다운로드

선택할 수 있는 SubDyn 소프트웨어에는 독립형과 FAST 시뮬레이터에 결합되는 두 가지 형태가 있습니다. 사용자가 반드시 두 가지 양식을 모두 필요로 하는 것은 아니지만 처음부터 하위 구조의 모델을 구축하는 경우 독립형 모델에 익숙하고 실행해야 할 가능성이 높습니다. 독립형 버전은 모델 문제 해결에도 유용하며 해상 풍력터빈의 공기-유체-서보-탄성 시뮬레이션 수행에 관심이 있는 사용자에게 도움이 될 수 있습니다.

사용자는 OpenFAST 설치를 참조하여 SubDyn을 다운로드하고 컴파일할 수 있습니다.

4.8.2.2. SubDyn 실행

4.8.2.2.1. 독립형 SubDyn 프로그램 실행

독립형 SubDyn 프로그램, SubDyn_win32.exe는 FAST에 연결하지 않고 사용자 입력 모델의 하위 구조 동적 응답을 시뮬레이션합니다. 결합된 버전과 달리 독립형 소프트웨어는 기본 SubDyn 입력 파일 외에 드라이버 파일을 사용해야 합니다. 이 드라이버 파일은 TP 기준점의 모션을 포함하여 FAST가 일반적으로 SubDyn에 제공하는 입력을 지정합니다. SubDyn 요약 파일과 결과 출력 파일은 독립형 SubDyn을 사용할 때 모두 사용할 수 있습니다(SubDyn 출력 파일에 관한 자세한 내용은 섹션 4 참조).

다음과 같이 입력하여 DOS 명령 프롬프트에서 독립형 SubDyn 소프트웨어를 실행합니다.

>SubDyn_win32.exe MyDriverFile.dvr

여기서, MyDriverFile.dvr 는 다음에 설명된 대로 SubDyn 드라이버 파일의 이름입니다. 섹션 4.8.3.3. SubDyn 기본 입력 파일은 섹션에 설명되어 있습니다. 섹션 4.8.3.2 FAST에 결합된 SubDyn 실행.

4.8.2.2.2. FAST와 연성된 SubDyn 실행

다음과 같이 입력하여 DOS 명령 프롬프트에서 결합된 FAST 소프트웨어를 실행합니다.

>FAST_Win32.exe Test21.fst

여기서, 테스트21.fst 는 기본 FAST 입력 파일의 이름입니다. 이 입력 파일에는 FAST 내에서 SubDyn 기능을 활성화 또는 비활성화하는 기능 스위치와 SubDyn 입력 파일에 대한 해당 참조가 있습니다. 자세한 내용은 FAST와 함께 제공되는 설명서를 참조하십시오.
