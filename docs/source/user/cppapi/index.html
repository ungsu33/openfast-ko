4.20. C++ API 사용자 가이드

이 문서는 C++ API 및 글루 코드에 대한 빠른 참조 가이드를 제공합니다. 일반 사용자가 다른 OpenFAST 매뉴얼과 함께 사용하도록 고안되었습니다. 설명서는 새 릴리스가 출시될 때마다 업데이트되며 소프트웨어의 개선 또는 수정에 대한 추가 정보를 제공하기 위해 필요에 따라 업데이트됩니다.

C++ API는 C++ 글루 코드를 통해 OpenFAST를 실행하기 위한 고급 API를 제공합니다. C++ API의 주요 목적은 일반적으로 C++로 작성된 CFD 솔버와 같은 외부 프로그램에 OpenFAST를 연결하는 데 도움을 주는 것입니다. C++ API 설치는 CMake를 통해 활성화됩니다. BUILD_OPENFAST_CPP_API 플래그입니다.

샘플 글루 코드 FAST_Prog.cpp 는 C++ API 사용법의 데모로 제공됩니다. 글루 코드를 사용하면 여러 프로세서에 걸쳐 OpenFAST를 병렬로 사용하여 여러 터빈을 시뮬레이션할 수 있습니다. 글루 코드는 다음과 같은 단일 입력 파일을 사용합니다. cDriver.i (download).

# -*- mode: yaml -*-
#
# C++ glue-code for OpenFAST - Example input file
#

n_turbines_glob: 3       # Total number of turbines in the simulation

debug: False             # Enable debug outputs if set to true

dry_run: False           # The simulation will not run if dryRun is set to true

sim_start: init          # Flag indicating whether the simulation starts from scratch or restart
                         # [init | trueRestart | restartDriverInitFAST]

coupling_mode: strong    #  Coupling mode
                         # [strong | classic]

t_start: 0.0             # Start time of the simulation

t_end: 1.0               # End time of the simulation; tEnd <= tMax.

t_max: 4.0               # Max time of the simulation

dt_FAST: 0.00625         # Time step for FAST. All turbines should have the same time step.

n_substeps: 1            # Number of substeps per timestep of the glue-code

n_checkpoint: 160        # Restart files will be written every so many time steps

set_exp_law_wind: false  # Set velocity at the turbine using an exponential law profile.

Turbine0:

  turbine_base_pos: [ 0.0, 0.0, 0.0 ]  # The position of the turbine base for actuator-line simulations

  num_force_pts_blade: 0               # The number of actuator points along each blade for actuator-line simulations

  num_force_pts_tower: 0               # The number of actuator points along the tower for actuator-line simulations.

  restart_filename: "banana"           # The checkpoint file for this turbine when restarting a simulation

  FAST_input_filename: "t1_Test05.fst" # The FAST input file for this turbine

  turb_id:  1                          # A unique turbine id for each turbine

Turbine1:
  turbine_base_pos: [ 0.0, 0.0, 0.0 ]
  num_force_pts_blade: 0
  num_force_pts_tower: 0
  restart_filename: "banana"
  FAST_input_filename: "t2_Test05.fst"
  turb_id:  2

Turbine2:
  turbine_base_pos: [ 0.0, 0.0, 0.0 ]
  num_force_pts_blade: 0
  num_force_pts_tower: 0
  restart_filename: "banana"
  FAST_input_filename: "t3_Test05.fst"
  turb_id:  3

4.20.1. 명령줄 호출

mpiexec -np <N> openfastcpp

4.20.2. 공통 입력 파일 옵션

n_turbines_glob

시뮬레이션에 포함된 총 터빈 수입니다. 입력 파일에는 여러 개의 터빈 관련 섹션(터빈0, 터빈1, …, 터빈(n-1))와 일치합니다. nTurbinesGlob.

디버그

true로 설정된 경우 디버그 출력 활성화

dry_run

dryRun이 true로 설정된 경우 시뮬레이션이 실행되지 않습니다. 그러나 시뮬레이션에서는 입력 파일을 읽고, 터빈을 프로세서에 할당하고, 개별 터빈 인스턴스 실행을 준비합니다. 이 플래그는 시뮬레이션을 실행하기 전에 시뮬레이션 설정을 테스트하는 데 유용합니다.

sim_start

시뮬레이션이 처음부터 시작되는지 아니면 다시 시작되는지를 나타내는 플래그입니다. sim_start 는 세 가지 값 중 하나를 취합니다.

  • init - 시뮬레이션을 시작할 때 이 옵션을 사용하십시오. t=0s.

  • trueRestart - OpenFAST를 사용하면 터빈 시뮬레이션을 다시 시작할 수 있지만 Bladed 스타일 컨트롤러와 같은 외부 구성 요소는 그렇지 않을 수도 있습니다. 시뮬레이션의 모든 구성요소가 다시 시작되는 것으로 알려진 경우 이 옵션을 사용하십시오.

  • restartDriverInitFAST - 언제 restartDriverInitFAST 옵션이 선택되면 개별 터빈 모델은 다음에서 시작됩니다. t=0s 를 실행하고 hdf5 파일의 액추에이터 노드에 저장된 유입 데이터를 사용하여 지정된 재시작 시간까지 실행합니다. C++ API는 모든 OpenFAST 시간 단계에서 액츄에이터 노드의 유입 데이터를 hdf5 파일에 저장한 다음 이 다시 시작 옵션을 사용할 때 다시 읽습니다. 이 다시 시작 옵션은 글루 코드가 CFD 솔버일 때 특히 유용합니다.

coupling_mode

커플링 모드 선택. coupling_mode 는 다음 두 값 중 하나를 사용합니다. strong 또는 classic. strong 결합 모드는 모든 드라이버 시간 단계에 대해 2개의 외부 반복을 사용합니다. classic 커플링 모드 호출 step() 기능은 느슨한 결합 모드를 사용합니다.

t_start

시뮬레이션 시작 시간

t_end

시뮬레이션 종료 시간입니다. t_end <= t_max

t_max

시뮬레이션의 최대 시간

dt_fast

FAST의 시간 간격입니다. 모든 터빈은 동일한 시간 간격을 가져야 합니다.

n_substeps

드라이버 프로그램의 시간 단계당 OpenFAST의 하위 시간 단계 수입니다.

n_checkpoint

재시작 파일은 많은 시간 단계마다 기록됩니다.

set_exp_law_wind

True/False의 부울 값입니다. true인 경우 지수 0.2와 90미터에서 기준 풍속 10m/s를 사용하는 거듭제곱 법칙 바람 프로필을 사용하여 Aerodyn 노드의 속도를 설정합니다. 이 옵션은 대규모 CFD 시뮬레이션을 실행하기 전에 개별 모드에서 액추에이터 라인 시뮬레이션 설정을 테스트하는 데 유용합니다.

4.20.3. 터빈별 입력 옵션

turbine_base_pos

액추에이터 라인 시뮬레이션을 위한 터빈 베이스의 위치

num_force_pts_blade

액추에이터 라인 시뮬레이션을 위한 각 블레이드의 액추에이터 포인트 수

num_force_pts_tower

액추에이터 라인 시뮬레이션을 위한 타워를 따른 액추에이터 포인트 수입니다.

restart_filename

시뮬레이션을 다시 시작할 때 이 터빈에 대한 체크포인트 파일

FAST_input_filename

이 터빈의 FAST 입력 파일

turb_id

각 터빈의 고유한 터빈 ID
