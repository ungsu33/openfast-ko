4.11.3. 출력 파일

HydroDyn는 에코 파일, 요약 파일, 시계열 파일의 세 가지 유형의 출력 파일을 생성합니다. 다음 섹션에서는 이러한 파일의 목적과 내용을 자세히 설명합니다.

4.11.3.1. Echo 파일

다음을 설정하면 Echo HydroDyn 드라이버 파일 또는 HydroDyn 기본 입력 파일의 TRUE에 플래그를 지정하면 해당 파일의 내용이 명명 규칙을 사용하여 파일에 반영됩니다. OutRootName.dvr.ech 드라이버 입력 파일의 경우 OutRootName.HD.ech HydroDyn 기본 입력 파일의 경우. OutRootName 드라이버 입력 파일의 HYDRODYN 섹션에 지정되거나 OpenFAST 프로그램에 의해 지정됩니다. 에코 파일은 입력 파일을 디버깅하는 데 유용합니다. HydroDyn가 입력 파일을 구문 분석하는 동안 오류가 발생하면 에코 파일의 내용이 잘립니다. 오류는 일반적으로 마지막으로 성공적으로 에코된 줄 다음 줄에 해당합니다.

4.11.3.2. 요약 파일

HydroDyn는 명명 규칙을 사용하여 요약 파일을 생성합니다. OutRootName.HD.sum 만약에 HDSum 매개변수는 TRUE로 설정됩니다. 이 파일에는 부력, 하부구조 체적, 해양 성장 중량, 시뮬레이션 메쉬 및 해당 속성, 포텐셜 유동체에 대한 복사 커널을 포함하여 유체 역학 모델에 대한 주요 정보가 요약되어 있습니다.

텍스트가 인덱스를 참조하는 경우 이는 테이블의 특정 행을 참조하는 것입니다. 인덱싱은 1부터 시작하여 행 아래로 연속적으로 증가합니다.

4.11.3.2.1. WAMIT-모델 부피 및 부력 정보

이 섹션에서는 변위되지 않은 위치에서 각 포텐셜 유동체의 부력을 요약합니다. 하이브리드 포텐셜 유동/스트립 이론 모델의 경우 플랫폼의 전체 부력을 얻으려면 후속 섹션에 보고된 스트립 이론 부재 부력에 이러한 부력 값을 추가해야 합니다.

4.11.3.2.2. 스트립 이론 부피 계산

이 섹션에는 이동되지 않은 위치에 있는 모든 스트립 이론 구성원의 결합된 총 부피, 수중 부피, 해양 성장 부피 및 유체 충전(침수/평형수) 부피에 대한 요약이 포함되어 있습니다. 수액 충전량 값을 제외하고 보고된 용량은 다음과 같은 회원에게만 해당됩니다. PropPot 플래그가 FALSE로 설정되었습니다. 침수/밸러스트 용량은 유체가 채워진 모든 부재에 적용됩니다. PropPot 깃발.

4.11.3.2.3. 총 부력 하중

이 섹션에서는 (0,0,0)에 대해 합산할 때 변위되지 않은 하부 구조의 부력 하중을 자세히 설명합니다. 외부 부력에는 해양 성장의 효과가 포함되며 다음과 같은 구성원에게만 적용됩니다. PropPot 플래그는 FALSE로 설정됩니다. 내부 부력은 범람이나 평형수로 인한 부력에 대한 부정적인 영향이며, PropPot 깃발.

4.11.3.2.4. 통합 해양 성장 가중치

이 섹션에서는 약 (0,0,0)을 합산했을 때 변위되지 않은 하부 구조의 해양 성장 중량 하중을 자세히 설명합니다.

4.11.3.2.5. 스트립 이론 노드 테이블

이 표에는 HydroDyn에 의해 생성된 모든 사용자 정의 접합 및 내부 분석 노드에 대한 변위되지 않은 스트립 이론 노드 정보 및 속성이 자세히 설명되어 있습니다. 내부 노드는 요구 사항을 충족하기 위해 길이를 따라 어딘가에 입력 멤버를 분할하여 생성됩니다. MDivSize 기본 입력 파일 멤버 테이블의 매개변수입니다. 노드 인덱스는 첫 번째 열에 제공됩니다. 두 번째 열은 입력 멤버 인덱스를 제공합니다( MemberID) 각 내부 노드가 속해 있습니다. 사용자 정의 접합은 반드시 특정 멤버에 속할 필요가 없으므로 이 열에는 이러한 접합에 대한 정보가 제공되지 않습니다. Nxi, 니, 및 은지 (X,Y,Z) 전역 관성 프레임 좌표계의 좌표입니다. R 는 노드에 있는 부재의 외부 반경입니다(해양 성장 제외). t 노드의 부재 벽 두께입니다. tMG 해양 성장 두께이고, MGDens 해양 성장 밀도입니다. PropPot 이 노드에 부착된 요소가 포텐셜 유동 이론을 사용하여 모델링되었는지 여부를 나타냅니다. 만약에 FilledFlag TRUE이면 FillMass 노드에 할당된 채워진 유체 질량을 제공합니다. CD, 칼슘, CP, CB, AxCd, AxCa, AxCp, JAxCd, JAxCa, 및 JAxCp 는 각각 횡방향 항력, 횡방향 추가 질량, 횡방향 동적 압력, 부력 스케일링, 축방향 항력, 축방향 추가 질량, 축방향 동압력, 엔드플레이트 축방향 항력, 엔드플레이트 축방향 추가 질량 및 엔드플레이트 축방향 동압 계수입니다. 일부 열은 사용자 정의 접합에 대해서만 채워지고 다른 열은 단일 멤버에 속하는 내부 분석 노드에 대해서만 채워집니다.

4.11.3.2.6. 스트립 이론 멤버 테이블

이 섹션에서는 대체되지 않은 스트립 이론 멤버 및 관련 속성에 대해 자세히 설명합니다. 열 머리글의 접미사 1 또는 2는 각각 멤버의 시작 노드 또는 끝 노드를 나타냅니다. 첫 번째 열은 멤버 인덱스입니다. 조인트1 및 조인트2 이전 섹션의 노드 테이블에 있는 노드 인덱스를 참조하세요. 다음은 회원입니다 길이, 세분화된 요소의 수 NElem 만나기 위해 MDivSize 요구 사항 및 외관 용량. 이 외부 부피 계산에는 부재의 해양 성장 부피가 포함됩니다. MGVolume 해양 성장으로 인한 양적 기여를 제공합니다. 용량 및 MGVolume 잠재적인 흐름에 의해 모델링된 구성원의 경우 0이 됩니다. PropPot = TRUE의 경우 T. 각 노드의 외부 반경(해양 성장 포함)의 단면 특성과 벽 두께는 다음과 같이 지정됩니다. R1, t1, R2, 및 t2, 각각. PropPot 부재가 포텐셜 유동 이론을 사용하여 모델링되었는지 여부를 나타냅니다. 요소가 유체로 채워진 경우(침수 또는 밸러스트가 있는 경우) FilledFlag TRUE의 경우 T로 설정됩니다. FillDensity 및 FillFSLoc 채워진 유체 밀도와 자유 표면 위치(Z-전역 관성계 좌표계의 좌표). FillMass 을 곱하여 계산됩니다. FillDensity 요소의 내부 부피에 따른 값. 마지막으로 두 끝 조인트의 유체 역학 계수가 나열됩니다. 이는 위의 노드 테이블에 나열된 것과 동일한 계수입니다.

4.11.3.2.7. 사용자 요청 출력 요약

요약 파일에는 요청된 모든 회원 및 공동 출력 채널에 대한 정보가 포함됩니다.

4.11.3.2.7.1. 회원 산출물

첫 번째 열에는 HydroDyn 입력 파일의 OUTPUT CHANNELS 섹션에 입력된 대로 데이터 채널의 문자열 레이블이 나열됩니다. 시, 이, 및 지 구조가 변위되지 않을 때 전역 관성계 시스템에서 출력 위치의 좌표를 제공합니다. 다음 칼럼은, MemberID, 해당 입력 멤버 인덱스를 알려줍니다. 다음은 시작점의 좌표입니다(StartXi, StartYi, StartZi) 및 끝 (EndXi, EndYi, EndZi) 이 출력 위치를 포함하는 멤버의 노드입니다. 위치 이 멤버의 시작 노드로부터 정규화된 거리입니다.

4.11.3.2.7.2. 공동 출력

첫 번째 열에는 HydroDyn 입력 파일의 OUTPUT CHANNELS 섹션에 입력된 대로 데이터 채널의 문자열 레이블이 나열됩니다. 시, 이, 및 지 구조가 변위되지 않을 때 전역 관성계 시스템에서 출력 관절의 좌표를 제공합니다. InpJointID 다음을 지정합니다. JointID HydroDyn 입력 파일의 MEMBER JOINTS 테이블에 제공된 출력에 대해.

4.11.3.2.8. 방사선 메모리 효과 컨볼루션 커널

주파수-시간 영역 변환을 기반으로 하는 포텐셜 유동 솔루션에서 HydroDyn는 복사 문제로부터 주파수 종속 유체 역학 감쇠 행렬의 코사인 변환을 통해 복사 메모리 효과를 계산하기 위한 컨볼루션 방법에 사용되는 복사 커널을 계산합니다. 시간 종속 행렬인 시간 영역 복사 커널(방사 임펄스-응답 함수)이 이 섹션에 제공됩니다. n 및 t 행렬의 항목이 뒤따르는 시간 단계 인덱스와 시간을 제공합니다(K11, K12, 등) 그 시간과 관련된 방사선 커널의. 주파수 의존 유체 역학 감쇠 행렬은 대칭이므로 복사 커널도 대칭입니다. 따라서 행렬의 대각선 부분과 위쪽 삼각형 부분만 제공됩니다. 방사선 커널은 짧은 시간이 지나면 0으로 감소해야 하며 이는 적절한 값을 선택하는 데 도움이 됩니다. RdtnTMax. 복사 커널 매트릭스의 크기는 존재하는 포텐셜 유동체의 수에 따라 달라집니다(NBody) 그리고 NBodyMod HydroDyn 기본 입력 파일에 있습니다. 만약에 NBodyMod = 1(완전 유체역학적 커플링), 요약 파일에는 단일 6에 대한 데이터가 포함됩니다.NBody-by-6NBody 행렬. 만약에 NBodyMod > 1(유체역학적 커플링 없음), 요약 파일에는 다음에 대한 데이터가 포함됩니다. NBody 6x6 복사 커널 행렬.

4.11.3.3. 결과 파일

HydroDyn 시계열 결과는 명명 규칙을 사용하여 텍스트 기반 파일에 기록됩니다. OutRootName.HD.out 언제 OutSwtch 1 또는 3으로 설정됩니다. HydroDyn가 OpenFAST에 연결되고 OutSwtch 2 또는 3으로 설정되면 OpenFAST는 HydroDyn 결과를 포함하는 마스터 결과 파일을 생성합니다. 결과는 표 형식으로 되어 있으며, 각 열은 데이터 채널이고(첫 번째 열은 항상 시뮬레이션 시간임), 각 행은 시뮬레이션 출력 시간 단계에 해당합니다. 데이터 채널은 HydroDyn 기본 입력 파일의 OUTPUT CHANNELS 섹션에 지정됩니다. HydroDyn 생성 파일의 열 형식은 다음을 사용하여 지정됩니다. OutFmt 및 OutSFmt 기본 입력 파일의 매개변수입니다.
