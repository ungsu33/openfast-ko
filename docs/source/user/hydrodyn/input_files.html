4.11.2. 입력 파일

사용자는 기본 HydroDyn 입력 파일을 통해 유체역학 모델 매개변수와 하부 구조 형상 및 속성을 구성합니다. 독립형 모드에서 사용하는 경우 추가 드라이버 입력 파일이 필요합니다. 이 드라이버 파일은 일반적으로 OpenFAST에서 HydroDyn에 제공되는 초기화 입력과 HydroDyn에 대한 시간 단계별 입력을 지정합니다.

행 수가 지정된 테이블을 제외하고는 입력 파일에서 행을 추가하거나 제거해서는 안 됩니다.

HydroDyn는 SI 시스템(kg, m, s, N)을 사용합니다.

4.11.2.3. HydroDyn 기본 입력 파일

HydroDyn 입력 파일은 하부 구조 형상, 유체 역학 계수, 입사파 운동학 및 전류, 포텐셜 유동 솔루션 옵션, 범람/밸러스트 및 해양 성장, 보조 매개변수를 정의합니다. 띠 이론 부재의 형상은 MSL와 변형되지 않은 타워 중심선의 교차점을 원점으로 하는 전역 참조 시스템에서 변형되지 않은 하부 구조의 접합 좌표로 정의됩니다. 부재는 두 개의 관절을 연결합니다. 여러 멤버가 공통 조인트를 사용할 수 있습니다. 유체역학적 하중은 노드에서 계산되며, 이는 부재를 여러 개로 세분화한 결과입니다(MDivSize 입력) 요소(노드는 각 요소의 끝에 위치함)이며 모듈에 의해 계산됩니다. 부재 속성에는 외경, 두께, 동압력, 부가질량, 점성항력계수가 포함됩니다. 부재 속성은 조인트에서 지정됩니다. 속성이 한 조인트에서 다른 조인트로 변경되면 내부 노드에 대해 선형으로 보간됩니다.

파일은 여러 기능 섹션으로 구성됩니다. 각 섹션은 유체 역학 모델 또는 수중 하부 구조의 측면에 해당합니다. 샘플 HydroDyn 기본 입력 파일은 다음과 같습니다. 부록 A: OC4 반잠수식 입력 파일.

이 설명서가 테이블 항목의 ID를 참조하는 경우 이는 테이블 항목에 대한 정수 식별자이며 이러한 IDs는 연속적이거나 증가할 필요는 없지만 주어진 테이블 항목에 대해 고유해야 합니다.

입력 파일은 사용자가 사용할 수 있는 두 줄의 헤더 정보로 시작하지만 소프트웨어에서는 사용되지 않습니다. 다음 줄에서 다음을 설정합니다. Echo HydroDyn가 HydroDyn 입력 파일의 내용을 에코하도록 하려면 TRUE에 플래그를 지정하세요(입력 파일의 오류를 디버깅하는 데 유용함). 에코 파일의 명명 규칙은 다음과 같습니다. OutRootName.HD.ech. OutRootName HydroDyn 독립형 실행 시 드라이버 입력 파일의 HYDRODYN 섹션에 지정되거나 결합 시뮬레이션 실행 시 OpenFAST에 의해 지정됩니다.

4.11.2.3.1. 플로팅 플랫폼

입력 파일의 이 섹션과 다음 몇 섹션의 제목에는 "Floating Platform"이 있지만 입력 매개변수는 하위 구조가 플로팅하는지 여부에 관계없이 포텐셜 유동 모델을 제어합니다. 포텐셜 유동 솔루션은 0이 아닌 값과 함께 사용할 수 없습니다. MSL2SWL 또는 WaveMod = SeaState에서는 6입니다.

포텐셜 유동 이론의 부하 기여를 포함하려면 다음을 설정하십시오. PotMod WAMIT 출력을 기반으로 주파수-시간 영역 변환을 사용하려면 1로, FIT를 사용하려면 2로 설정합니다(FIT는 이 매뉴얼에 아직 문서화되어 있지 않습니다). 이 섹션의 나머지 매개변수는 다음과 같은 경우에만 사용됩니다. PotMod = 1.

ExctnMod 파동 여기가 없는 경우 0, 이산 푸리에 변환을 사용하는 주파수-시간 영역 파동 여기의 경우 1, 상태공간 파동 여기 모델의 경우 2로 설정할 수 있습니다. 선택에 따라 ExctnMod, 적합한 유체역학적 입력 파일은 다음을 통해 제공되어야 합니다. PotFile 입력. 자세한 내용은 아래를 참조하세요.

ExctnDisp 포텐셜 유동 파동을 평가할 때 수평면의 구조 변위를 고려해야 하는지 여부와 방법을 지정합니다. 환경 ExctnDisp = 0은 구조물 변위를 무시하고, OpenFAST의 이전 버전에서와 같이 변위되지 않은 구조물 위치를 사용하여 파동 가진을 계산합니다. 만약에 ExctnDisp = 1이면 HydroDyn는 수평면에서 필터링되지 않은 순간 PRP 위치를 사용하여 포텐셜 유동 파동을 계산합니다. 만약에 ExctnDisp = 2인 경우, HydroDyn는 대신 수평면에서 저역 통과 필터링된 PRP 위치를 기반으로 파동 여기를 계산합니다. 차단 주파수는 다음을 통해 지정됩니다. ExctnCutOff 헤르츠 단위. 이 옵션은 2차 포텐셜 유동 파동 여기가 활성화된 경우 유용합니다. 차단 주파수는 저주파 표류 운동을 유지하면서 2차 포텐셜 유동 파동 여기에 이미 포함된 1차 구조 운동의 기여도를 이중으로 계산하지 않도록 방지하면서 가능한 한 많은 파동 주파수 PRP 운동을 필터링하도록 설정되어야 합니다.

HydroDyn는 이제 스트립 이론 전용 모델과 하이브리드 포텐셜 유동 모델을 모두 사용하여 크지만 느린(파동 주파수보다 훨씬 낮은) 과도 플랫폼 요 모션을 지원합니다. 이 기능을 활성화하려면 입력 PtfmYMod, PtfmRefY, PtfmYCutoff, 및 NExctnHdg 적절하게 설정해야 합니다. HydroDyn에서는 여전히 플랫폼 롤 및 피치 각도가 작아야 합니다(예: +/-15도 이내).

기준 평균 위치에 대한 작은 변위로 구조를 제한하는 1차 및 2차 포텐셜 유동 이론을 따르려면 일정하거나 천천히 변하는 기준 플랫폼 요 방향을 설정해야 합니다.

환경 PtfmYMod = 0이면 HydroDyn가 다음과 같이 주어진 일정한 참조 요 각도를 사용할 수 있습니다. PtfmRefY 도 단위. 이 경우 시뮬레이션 중 플랫폼 요 회전은 다음과 같습니다. PRPYaw 출력 채널은 +/-15도 이내로 유지되어야 합니다. PtfmRefY 사용자가 지정합니다. 시뮬레이션 중 어느 시점에서든 이 요구 사항이 충족되지 않으면 심각한 경고가 표시되지만 가능하면 시뮬레이션을 계속할 수 있습니다. 하이브리드 포텐셜 유동 모델을 사용하는 경우 포텐셜 유동 파동 입력 파일은 요 오프셋 후 플랫폼에 상대적인 파동 방향의 적절한 범위를 포괄해야 합니다. PtfmRefY 적용됩니다.

대안적으로, PtfmYMod = 1은 HydroDyn가 기준 요 위치를 업데이트하도록 합니다. PtfmRefY 저역 통과 필터링된 플랫폼 요 회전을 기반으로 동적으로 수행되며, 이는 저속 드리프트 모션 모델링과 유사합니다. ExctnDisp = 위 2개. 이 경우, PtfmRefY 입력을 통해 사용자는 초기 참조 요 위치를 지정할 수 있습니다. t = 0. 플랫폼 요 회전을 위한 1차 저역 통과 필터의 차단 주파수는 다음과 같이 설정할 수 있습니다. PtfmYCutoff 헤르츠 단위. 이상적으로는, PtfmYCutoff 파동 주파수 영역과 플랫폼 방향의 느리지만 큰 변화의 특성 주파수 사이에 배치하여 저주파 방향 변경의 위상 변화를 최소화하면서 가능한 한 많은 파동 주파수 플랫폼 동작을 필터링해야 합니다. 시뮬레이션 전반에 걸쳐 즉각적인 플랫폼 요 회전은 현재 시간 종속의 +/-15도 이내로 유지되어야 합니다. PtfmRefY. 시뮬레이션 중 어느 시점에서든 이 요구 사항이 충족되지 않으면 심각한 경고가 표시되지만 가능하면 시뮬레이션을 계속할 수 있습니다.

와 함께 PtfmYMod = 1, HydroDyn는 첫 번째(가장 작은) 파향이 정확히 -180도이고 마지막(가장 큰) 파향이 정확히 +180도인 가능한 파향의 전체 범위를 포괄하기 위해 1차 및 2차(뉴먼 근사치의 평균 또는 느린 드리프트 하중) 포텐셜 유동 파동 여기 입력 파일이 필요합니다(+/-180도의 중복된 파향은 의도된 것임). 입력 파일이 이 요구 사항을 충족하지 않으면 HydroDyn에서 오류가 발생합니다. HydroDyn는 이 정보를 사용하여 플랫폼의 파동을 미리 계산합니다. NExctnHdg [-180,+180)도 범위에 걸쳐 균일하게 분산된 플랫폼 요/헤딩 각도. 예를 들어, NExctnHdg = 36, HydroDyn는 0, 10, 20, …, 350도 플랫폼 방향에 대한 파동 가진을 미리 계산합니다. 시간 영역 시뮬레이션 동안 플랫폼에 적용된 순간파 여기는 순간파동을 기반으로 이 데이터로부터 보간됩니다. PtfmRefY. NExctnHdg 플랫폼 방향에서 적절한 각도 해상도를 보장하도록 적절하게 설정되어야 합니다. 그러나, 높은 NExctnHdg OpenFAST의 메모리 사용량이 크게 늘어날 수 있습니다.

HydroDyn 입력에 대한 추가 제약 조건은 다음과 같은 경우에 적용됩니다. PtfmYMod = 1. 스트립 이론 유체 역학 하중은 변위된 구조 위치에서 파동 운동학과 동적 압력을 사용하여 다음과 같이 평가해야 합니다. WaveDisp = 1. 상태공간 파동 여기를 사용할 수 없습니다. ExctnMod 0(파동 여기 없음) 또는 1(역 이산 푸리에 변환을 사용한 주파수-시간 영역 변환) 중 하나여야 합니다. 마지막으로, 전체 차분 및 합 주파수 QTFs는 지원되지 않으므로 두 가지가 모두 필요합니다. DiffQTF 및 SumQTF 0으로 설정됩니다. 그러나 Newman 근사를 기반으로 한 평균 또는 느린 드리프트 하중은 다음을 통해 포함될 수 있습니다. MnDrift 또는 NewmanApp 입력은 아래에 설명되어 있습니다.

입력에 유의하세요. PtfmYMod 및 PtfmRefY 또한 스트립 이론 유체역학적 부하에도 영향을 미칩니다. 스트립 이론 구성원의 방향이 다음을 기반으로 업데이트되기 때문입니다. PtfmRefY 즉각적인 플랫폼 요 회전 대신. HydroDyn 이전 버전의 동작은 다음 설정을 통해 대략적으로 복구할 수 있습니다. PtfmYMod = 0 및 PtfmRefY = 0도, 이 경우 입력은 PtfmYCutoff 및 NExctnHdg 사용되지 않습니다.

HydroDyn에는 방사선 메모리 효과를 계산하는 두 가지 방법이 있습니다. 세트 RdtnMod 컨볼루션 방법의 경우 1, 선형 상태공간 모델의 경우 2, 메모리 효과 계산을 비활성화하려면 0입니다. 컨볼루션 방법의 경우, RdtnTMax 메모리 효과를 추적하는 기간을 결정합니다(컨볼루션을 잘라냄). t – RdtnTMax, 어디 t 는 현재 시뮬레이션 시간)이지만 시간 영역 복사 커널(방사 임펄스-응답 함수)이 파생되는 코사인 변환에 사용되는 주파수 단계도 결정합니다. 에이 RdtnTMax 짧은 시간 후에 방사선 커널이 0으로 붕괴되기 때문에 일반적으로 60초면 충분합니다. 환경 RdtnTMax 이보다 훨씬 크면 HydroDyn가 상당히 느리게 실행됩니다. (RdtnTMax 전체 시뮬레이션 길이와 일치하거나 초과할 필요는 없습니다.) 설정 RdtnTMax 0초로 설정하면 설정과 유사하게 메모리 효과가 비활성화됩니다. RdtnMod 0으로. 컨볼루션 방법의 경우 RdtnDT 는 방사선 계산(수치 컨볼루션)을 위한 시간 단계이지만 코사인 변환의 최대 주파수도 결정합니다. 상태공간 모델의 경우, RdtnDT 선형 상태공간 모델의 시간 통합에 사용할 시간 단계입니다. HydroDyn의 이 버전에서는, RdtnDT 글루 코드(OpenFAST/드라이버 프로그램) 시뮬레이션 시간 단계와 일치해야 합니다. 이를 위해 DEFAULT 키워드를 사용할 수 있습니다. 선택에 따라 RdtnMod, 적합한 유체역학적 입력 파일은 다음을 통해 제공되어야 합니다. PotFile 입력. 자세한 내용은 아래를 참조하세요.

HydroDyn는 여러 포텐셜 유동체의 포함을 지원합니다. NBody 존재하는 포텐셜 유동체의 수를 지정합니다. NBodyMod 여러 포텐셜 유동 몸체를 모델링하는 방법을 제어합니다. HydroDyn는 다음과 같은 경우 포텐셜 유동체 사이에서 완전한 유체 역학적 결합을 유지합니다. NBodyMod = 1. 이 옵션의 경우 모든 본체가 동일한 WAMIT 실행에 있어야 합니다. NBody HydroDyn는 WAMIT 입력 파일의 NBODY와 같습니다. WAMIT 출력 파일에는 6·NBody 모드에 대한 결과가 포함되어야 합니다. HydroDyn는 다음과 같은 경우 포텐셜 유동체 사이의 유체 역학적 결합을 무시합니다. NBodyMod = 2 또는 3. 두 경우 모두 WAMIT는 한 번에 하나씩 각 본체에 대해 개별적으로 실행되어야 합니다. WAMIT 계산이 원점(WAMIT에서 XBODY=0)을 중심으로 각 몸체를 실행하는 경우, NBodyMod = HydroDyn에서는 2를 사용해야 합니다. 이 경우 HydroDyn는 원점/PRP에서 각 포텐셜 유동 본체의 오프셋으로 인한 파동 위상의 변화를 설명하기 위해 WAMIT 출력을 처리합니다. HydroDyn는 HydroDyn의 각 몸체 방향에 따라 WAMIT 출력도 회전합니다. NBodyMod = 2는 예를 들어 여러 개의 동일한 포텐셜 유동체가 구조에 존재할 때 편리합니다. 몸체 간의 유체역학적 결합을 무시할 수 있는 경우 다음 설정을 통해 동일한 WAMIT 출력 파일 세트를 각 몸체에 사용할 수 있습니다. NBodyMod = 2. 반면, NBodyMod = 3은 WAMIT 입력 파일에서 XBODY를 설정하여 WAMIT의 원점/PRP를 기준으로 각 본체의 위치와 방향이 이미 올바른 경우 사용해야 합니다. 이 경우 HydroDyn는 제공된 WAMIT 출력을 그대로 사용합니다.

해당 PotFile 입력에는 따옴표로 묶인 WAMIT 출력 파일의 경로와 루트 이름(확장자 없음)이 포함되어야 합니다. 이러한 파일은 다음으로 구성됩니다. .1, .3, .hst, 2차 파일. 그만큼 .hst 파일에는 정수압 복원(강성) 매트릭스가 포함되어 있습니다. 그만큼 .1 파일에는 파동 복사 문제의 주파수 종속 유체역학적 추가 질량 및 감쇠 행렬이 포함되어 있습니다. 그만큼 .3 파일에는 선형 파동 회절 문제의 주파수 및 방향 종속 1차 파동 벡터가 포함되어 있습니다. 이는 WAMIT 프로그램에 의해 작성되었으며 파일 헤더를 포함해서는 안 됩니다. 선형 상태공간 모델이 파동 여기의 주파수-시간 영역 변환 대신 또는 복사의 컨벌루션 대신 사용되는 경우, .ssexctn 파동에 대한 파일(향후 더 많은 정보 제공 예정) 및/또는 .봄 여름 시즌 생성된 방사선에 대한 파일 SS_Fitting 다른 WAMIT 관련 파일과 동일한 루트 이름을 가져야 합니다.

다음의 경우 NBodyMod = 1, PotFile 관계없이 하나의 항목만 포함해야 합니다. NBody 왜냐하면 유체역학적 커플링이 있는 모든 몸체에 대한 유체역학적 계수가 단일 파일 세트 내에 포함되어야 하기 때문입니다. 언제 NBodyMod = 2 또는 3, PotFile 포함해야합니다 NBody 각 항목은 따옴표로 묶이고 쉼표나 공백으로 서로 구분됩니다. 각 항목의 PotFile 단일 포텐셜 유동 몸체에 해당합니다.

이 섹션을 참고하면 각 입력에는 다음이 포함되어야 합니다. NBody 항목에 관계없이 쉼표나 공백으로 구분된 항목 NBodyMod.

사용자는 세 가지 선택적 입력을 모두 생략하도록 선택할 수 있습니다. 이 경우 HydroDyn는 이전 버전의 OpenFAST와 마찬가지로 엔드플레이트 항력을 계산합니다. 또는 사용자는 선택적 매개변수만 포함할 수 있습니다. AxFDMod. 이 경우에는 속도 필터링이 적용되지 않습니다. 마지막으로 사용자는 위에서 설명한 대로 끝판 항력의 동작을 제어하기 위해 세 가지 선택적 매개변수를 모두 포함할 수 있습니다.

4.11.2.3.10. 채워진 회원

부재는 포텐셜 유동으로 모델링되었는지 여부에 관계없이 유체로 채워질 수 있습니다. 즉, 침수 및/또는 밸러스트가 채워져 있음을 의미합니다. 내부 유체는 침수/밸러스트 부재의 내벽에 정수압을 도입합니다. 또한 부재에 질량과 관성 모멘트를 추가합니다. 부재를 따른 분산 하중과 조인트/종판의 집중 하중이 모두 적용됩니다.

침수된 부재의 유체 부피는 부재의 외경/측면 길이, 벽 두께 및 유체가 채워진 레벨로부터 파생됩니다. 유체가 채워진 레벨이 부재의 중앙에 있는 경우 부재는 하단 조인트에서 유체가 채워진 레벨까지 부분적으로 침수되고, 유체가 채워진 레벨이 부재의 상단 조인트 위에 있는 경우 완전히 침수됩니다. 두 경우 모두, 부재 중심선에 수직인 수밀 격벽은 양쪽 끝에서 부재의 채워진 단면을 경계로 가정하므로 내부 자유 표면이나 슬로싱이 없습니다. 더욱이, 부재 내의 유체는 부재에 대한 관성 하중을 계산하기 위해 강체 방식으로 부재와 함께 이동하도록 구획화되는 것으로 가정됩니다. 그러나 내부 정수압을 계산할 때 구획화가 방수라고 가정하지 않습니다. 따라서 부재의 전체 충전 부피는 단일 연속 정수압 필드를 공유합니다. 예를 들어, 이 모델링 가정의 결과는 완벽하게 수직이고 테이퍼가 없는 스파 내부의 모든 밸러스트수의 무게가 스파를 따라 분산되는 대신 스파의 바닥 끝판에만 놓이게 된다는 것입니다.

또한 각 그룹에는 잠재적으로 여러 구성원이 포함될 수 있는 채워진 구성원 그룹의 개념을 소개합니다. 동일한 충전 부재 그룹에 속하는 모든 부재의 내부 침수 체적은 상호 연결된 것으로 간주되므로 동일한 연속 정수압장을 공유합니다. 채워진 각 회원 그룹은 공개 또는 비공개로 분류됩니다. 주어진 채워진 부재 그룹 중 적어도 하나의 부재가 모노파일과 같이 해저에 부분적으로 매립된 경우, 우리는 이 그룹을 부분적으로 매립된 부재의 바닥 개구부와 다공성 해저를 통해 외부 해수체에 개방된 것으로 취급합니다. 이 경우 내부 유체의 정수압은 외부 정수위에서 정수압이 0인 외부 수역과 평형을 이룬다. 또한, 개방형 충전부재 그룹의 충전수위는 외부 정수위보다 높을 수 없으며, 내부유체의 밀도는 외부 물의 밀도와 정확히 일치해야 합니다. 해저에 부분적으로 매립된 부재는 바닥이 개방되어 부재 바닥 끝 부분에 외부 또는 내부 정수압이 없는 것으로 간주됩니다. 채워진 구성원 그룹의 구성원 중 어느 누구도 해저를 횡단하지 않는 경우, 채워진 구성원 그룹은 부유식 플랫폼의 밸러스트 챔버와 같은 외부 수역에서 차단된 것으로 간주됩니다. 이 경우, 각 시간 단계에서 이 그룹에 속하는 모든 구성원의 내부 유체가 채워진 부피의 순간 최고점에서 내부 정수압은 0입니다.

4.11.2.3.15. 출력 채널

이 섹션에서는 HydroDyn에 의해 생성된 출력 수량을 제어합니다. 하나 이상의 출력 매개변수 이름을 포함하는 따옴표 붙은 문자열을 포함하는 하나 이상의 행을 입력하십시오. 쉼표, 세미콜론, 공백 및/또는 탭의 조합으로 출력 매개변수 이름을 구분합니다. 매개변수 이름 앞에 빼기 기호, "-", 밑줄, "_" 또는 문자 "m" 또는 "M"을 붙이면 HydroDyn는 데이터를 쓰기 전에 해당 채널의 값에 -1을 곱합니다. 매개변수는 반드시 입력 파일에 나열된 순서대로 작성되지는 않습니다. HydroDyn를 사용하면 여러 줄을 사용하여 목록을 의미 있는 그룹으로 나누고 줄을 더 짧게 만들 수 있습니다. 모든 행에서 닫는 따옴표 뒤에 설명을 입력할 수 있습니다. 줄 시작 부분이나 줄 시작 부분에 있는 따옴표 붙은 문자열의 시작 부분에 "END"라는 문자열이 포함된 줄을 입력하면 HydroDyn가 더 많은 채널 이름 줄 검색을 중단하게 됩니다. 요청한 항목에 대해 회원 및 공동 관련 수량이 생성됩니다. 회원 출력 목록 및 공동 출력 목록. HydroDyn가 알 수 없거나 유효하지 않은 채널 이름을 발견하면 사용자에게 경고하지만 출력 파일에서 의심스러운 채널을 제거합니다. 가능한 출력 매개변수의 전체 목록은 부록 C를 참조하십시오.
