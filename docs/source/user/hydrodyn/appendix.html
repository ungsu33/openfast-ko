4.11.9. 부록 C. 출력 채널 목록

이것은 HydroDyn 모듈에 대해 가능한 모든 출력 매개변수의 목록입니다. 이름은 의미별로 그룹화되어 있지만 적절하다고 판단되는 대로 HydroDyn 입력 파일의 OUTPUT CHANNELS 섹션에서 순서를 지정할 수 있습니다. MαNβ는 출력 멤버 α의 출력 노드 β를 나타냅니다. 여기서 α는 [1,9] 범위의 숫자이고 MEMBER OUTPUT LIST 테이블의 행 α에 해당하고 β는 [1,9] 범위의 숫자이며 테이블의 위치 β에 해당합니다. NodeLocs 해당 테이블 항목의 목록입니다. Jα는 출력 조인트 α를 나타냅니다. 여기서 α는 [1,9] 범위의 숫자이고 JOINT OUTPUT LIST 테이블의 α 행에 해당합니다. Bα는 신체 α를 나타내며, 여기서 α는 [1,9] 범위의 숫자입니다. α > NBody를 설정하면 잘못된 출력이 생성됩니다. NBody > 9인 경우 처음 9개 본체만 출력될 수 있습니다. Waveα는 파고를 출력할 수 있는 지점 α를 의미하며, 여기서 α는 [1,9] 범위의 숫자입니다. α > NWaveElev를 설정하면 잘못된 출력이 생성됩니다. 모든 출력은 전역 관성 프레임 좌표에 있습니다.
