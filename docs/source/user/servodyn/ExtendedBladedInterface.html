4.15.2. 확장 블레이드 인터페이스

Bladed 스타일 DLL 컨트롤러 인터페이스는 예약된 범위의 채널 그룹에 배열된 상당수의 새 채널을 허용하도록 확장되었습니다. 이것은 다음과 같이 표시됩니다. 그림 4.53 아래에.

그림 4.53 Bladed DLL 인터페이스 확장을 위한 채널 구성표입니다.

ServoDyn 요약 파일에는 사용 중인 모든 DLL 인터페이스 채널의 요약과 예약된 채널 블록이 포함되어 있습니다.
