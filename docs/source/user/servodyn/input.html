4.15.1. 입력 파일

사용자는 기본 ServoDyn 입력 파일뿐만 아니라 구조 제어를 위한 별도의 입력 파일 및 컨트롤러 DLL를 통해 서보 역학 모델 매개변수를 구성합니다. 이 정보는 불완전하며 나중에 여기에 문서화될 예정입니다.

4.15.1.1. 단위

ServoDyn는 SI 시스템(kg, m, s, N)을 사용합니다. 별도로 지정하지 않는 한 각도는 라디안 단위로 간주됩니다.

4.15.1.2. ServoDyn 기본 입력 파일

기본 ServoDyn 입력 파일은 컨트롤러의 모델링 옵션을 정의합니다. 여기에는 일부 DLL 옵션과 구조 제어 옵션(일반적으로 조정된 질량 댐퍼 시스템)이 포함됩니다.

4.15.1.2.1. 시뮬레이션 제어

Echo [깃발]

<RootName>.ech에 대한 Echo 입력 데이터

DT [비서]

컨트롤러의 통신 간격(또는 "기본값")

4.15.1.2.3. 발전기 및 토크 제어

가변 속도 제어 모드 {0: 없음, 1: 단순 VS, 3: 루틴 UserVSCont에서 사용자 정의, 4: Simulink/Labview에서 사용자 정의, 5: Bladed 스타일 DLL에서 사용자 정의}

GenModel [스위치]

생성기 모델 {1: 단순, 2: Thevenin, 3: 루틴 UserGen에서 사용자 정의} [다음 경우에만 사용됩니다. VSContrl==0 ]

GenEff [%]

발전기 효율 [Thevenin 및 사용자 정의 생성기 모델에서는 무시됨]

GenTiStr [깃발]

발전기 시동 방법 {T: TimGenOn를 사용하여 시간 설정, F: SpdGenOn를 사용하여 발전기 속도}

GenTiStp [깃발]

발전기 정지 방법 {T: TimGenOf를 사용하여 시간 설정, F: 발전기 전력 = 0인 경우}

SpdGenOn [rpm]

시동을 위해 발전기를 켜는 발전기 속도(HSS 속도) [다음 경우에만 사용됩니다. GenTiStri==거짓 ]

TimGenOn [비서]

시동을 위해 발전기를 켜는 시간 [다음 경우에만 사용됩니다. GenTiStr==참 ]

TimGenOf [비서]

발전기를 끄는 시간 [다음 경우에만 사용됩니다. GenTiStp==참 ]

4.15.1.2.9. 공기 역학적 흐름 제어

AfCmode [스위치]

에어포일 제어 모드 {0: 없음, 1: 사인파 사이클, 4: Simulink/Labview에서 사용자 정의, 5: Bladed 스타일 DLL에서 사용자 정의}

AfC_Mean [-]

코사인 순환 또는 안정된 값의 평균 수준 [다음에만 사용됨 AfCmode==1 ]

AfC_Amp [-]

플랩 신호의 코사인 순환 진폭 [다음에만 사용됨 AfCmode==1 ]

AfC_Phase [도]

플랩 신호의 코사인 순환에 대한 블레이드 방위각(0은 수직)에 상대적인 위상 [다음에만 사용됨 AfCmode==1 ]

다음의 경우 AfCmode==1, 에어포일 흐름 제어를 위한 신호는 다음 식으로 설정됩니다. AfC_Mean + p%AfC_Amp*cos( 방위각 + AfC_phase) 여기서 방위각은 특정 블레이드의 방위각입니다(방위각=0은 수직으로 간주됩니다).

4.15.1.2.10. 케이블 제어

MoorDyn 또는 SubDyn 모듈에 지정된 케이블 요소의 제어는 블레이드형 컨트롤러에 의해 ServoDyn를 통해 제어될 수 있습니다. 각 케이블은 한 쌍의 컨트롤러 채널을 수신합니다. 하나는 요청된 케이블 길이 변경(DeltaL)용이고 다른 하나는 케이블 길이 변경 속도(DeltaLdot)용입니다. 채널 할당은 케이블 요소(현재 MoorDyn 및/또는 SubDyn)가 있는 모듈에 의해 요청되며 적절한 제어 채널에 매핑됩니다. 채널을 요청한 모듈에 대한 요약은 ServoDyn의 요약 파일 출력에서 ​​확인할 수 있습니다. DLL에 연결하는 경우 최대 100개의 채널 그룹이 요청될 수 있고, Simulink에 연결되는 경우에는 20개의 채널 그룹이 요청될 수 있습니다.

CCmode [스위치]

케이블 제어 모드 {0: 없음, 4: Simulink/Labview에서 사용자 정의, 5: Bladed 스타일 DLL에서 사용자 정의}.

각 케이블 제어 채널 그룹은 컨트롤러/Simulink 인터페이스의 DeltaL(요청된 케이블 길이 변경)에 대한 채널과 DeltaLdot(케이블 길이 변경 속도)에 대한 채널로 구성됩니다.

4.15.1.2.11. 구조 제어

다음을 참조: 섹션 4.17.1.2 다음 각 옵션의 장착 위치에 대한 설명은 다음을 참조하세요.

블레이드 구조 컨트롤러 수

블레이드 구조 컨트롤러용 파일 이름(한 줄에 인용 문자열) [사용하지 않는 경우 NumBStC==0 ]

NumNStC [정수]

나셀 구조 컨트롤러 수

NStCfiles [-]

나셀 구조 컨트롤러용 파일 이름(한 줄에 인용된 문자열) [사용하지 않는 경우 NumNStC==0 ]

NumTStC [정수]

타워 구조 컨트롤러 수

TStCfiles [-]

타워 구조 제어 댐핑 파일 이름(한 줄에 인용된 문자열) [사용하지 않는 경우 NumTStC==0 ]

NumSStC [정수]

하부 구조 구조 컨트롤러 수

SStCfiles [-]

하위 구조 구조 컨트롤러의 파일 이름(한 줄에 인용 문자열) [사용하지 않는 경우 NumSStC==0 ]

4.15.1.2.12. 블레이드 컨트롤러 인터페이스

DLL_FileName [-]

Bladed-DLL 형식의 동적 라이브러리 {.dll [Windows] 또는 .so [Linux]}의 이름/위치 [블레이드 인터페이스에만 사용]

DLL_InFile [-]

DLL로 전송된 입력 파일의 이름 [블레이드 인터페이스에만 사용]

DLL_ProcName [-]

호출할 DLL의 프로시저 이름 [대소문자를 구분합니다. DLL 인터페이스에만 사용됨]

DLL_DT [비서]

동적 라이브러리의 통신 간격(또는 "기본값") [블레이드 인터페이스에만 사용]

DLL_Ramp [깃발]

DLL_DT 시간 단계 사이에 선형 램프를 사용해야 하는지 여부[참인 경우 시간 이동 도입] [블레이드 인터페이스에만 사용]

BPCutoff [Hz]

4.15.1.2.14. 산출

SumPrint [깃발]

요약 데이터를 <RootName>.sum으로 인쇄합니다. 이 파일에는 입력 요약이 포함되어 있으며 사용 시 블레이드 스타일 컨트롤러와의 통신 채널에 대한 자세한 목록을 제공합니다. 이 정보는 컨트롤러를 디버깅하거나 ServoDyn 구성 방법을 확인하는 데 도움이 될 수 있습니다.

OutList 섹션은 ServoDyn에 의해 생성된 출력 수량을 제어합니다. 하나 이상의 출력 매개변수 이름을 포함하는 따옴표 붙은 문자열을 포함하는 하나 이상의 행을 입력하십시오. 쉼표, 세미콜론, 공백 및/또는 탭의 조합으로 출력 매개변수 이름을 구분합니다. 매개변수 이름 앞에 빼기 기호, "-", 밑줄, "_" 또는 문자 "m" 또는 "M"을 붙이면 ServoDyn는 데이터를 쓰기 전에 해당 채널의 값에 -1을 곱합니다. 매개변수는 입력 파일에 나열된 순서대로 작성됩니다. ServoDyn를 사용하면 여러 줄을 사용하여 목록을 의미 있는 그룹으로 나누고 줄을 더 짧게 만들 수 있습니다. 모든 행에서 닫는 따옴표 뒤에 설명을 입력할 수 있습니다. 줄 시작 부분이나 줄 시작 부분에 있는 따옴표 붙은 문자열의 시작 부분에 "END"라는 문자열이 포함된 줄을 입력하면 ServoDyn가 더 많은 채널 이름 줄 검색을 중단하게 됩니다. ServoDyn가 알 수 없거나 유효하지 않은 채널 이름을 발견하면 사용자에게 경고하지만 출력 파일에서 의심스러운 채널을 제거합니다. 엑셀 파일의 ServoDyn 탭을 참고해주세요 OutListParameters.xlsx 에서 사용 가능한 전체 출력 매개변수 목록을 확인할 수 있습니다.
