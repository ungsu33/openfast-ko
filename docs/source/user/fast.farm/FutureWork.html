4.19.8. 향후 개발 계획

이 목록에는 향후 릴리스에서 구현될 수 있는 기능이 포함되어 있습니다.

  • 다음을 포함하여 충실도가 높은 전구체 시뮬레이션에서 주변 바람을 생성/처리하는 보다 효율적인 방법을 개발합니다.

    • 3D 볼륨의 대안으로 Taylor의 동결 난류 가설을 사용하여 주변 바람 데이터의 2D 평면 전파

    • Turbsim에서 균일하지 않은 그리드 허용

    • 동적 모드 분해를 사용하여 저해상도 도메인의 파일 크기 압축

    • 고해상도 도메인을 대체하기 위해 Gabor 모드 강화 구현

    • 일반적으로 구조화되지 않은 단순한 직사각형 그리드를 기반으로 보다 효율적인 ABLSolver를 개발합니다.

  • 추가 물리학으로 소용돌이 점도 공식을 개선합니다.

  • 다음을 포함하여 추가적인 항적 모델링 접근 방식을 추구합니다.

    • 더 단순한 항적 부족 모델(예: Bastankhah 및 Porté-Agel의 Gaussian 항적 모델, Blondel 및 Cathelain의 Super-Gaussian 모델 도입)

    • Jiménez의 모델이나 Qian 및 Ishihara의 모델과 같이 더 간단한 후류 편향 모델을 도입합니다.

    • 근접 후류에 대해 자유 와류 방법 적용

    • 편향된 흐름 조건에서 신장 모양의 후류를 통합합니다(예: 편향으로 인한 말굽 소용돌이의 반대 와류를 통합함).

    • 배경 난류(후류 구불구불한 현상에 추가)의 결과로 베이스-후류 부족을 변형합니다(비대칭 도입).

    • 항적에 따른 난류 통합

    • 복잡한 지형 처리 개선(주변 바람 데이터를 VTK 형식의 NaN로 지정하는 것 이상)

    • 나셀 및 지지 구조의 후류 포함

    • 반사가 땅에서 깨어납니다.

  • 대규모 풍력 발전 단지에 대한 딥 어레이 효과를 해결하고 풍력 발전 단지 가장자리 주변의 흐름 속도 증가를 설명합니다. 즉, 풍력 발전 단지 차단 효과를 설명합니다. 예를 들어 LES 주변 바람 전구체의 표면 거칠기를 사용하여 풍력 발전 단지에서 유발된 경계층을 모방합니다.

  • LIDAR 및 기타 원격 감지 기술에서 얻은 측정값을 모방하는 모델을 구현합니다.

  • MPI를 통합하여 메모리 병렬화 및 HPC 노드 간 병렬화를 활용하여 대규모 풍력 발전 단지 모델링을 지원합니다.

  • 보다 일반적인 모듈 형식을 허용합니다. 예:

    • 연속 상태 지원

    • 입력에서 출력으로의 직접 피드스루 지원

    • 전체 시스템 선형화를 지원합니다.

  • 개별 풍력 터빈 컨트롤러를 위한 Simulink 인터페이스를 지원합니다.

  • 체크포인트 재시작 기능을 구현합니다.

  • 이진 바람 데이터 입력 및 출력 형식과 이진 시계열 결과 출력 형식을 활성화합니다.

  • 평행할 필요가 없는 2D 슬라이스에 VTK 형식으로 교란된 바람을 출력하는 기능을 추가합니다. X-Y, Y-Z 및/또는 X-Z 전역 관성계 좌표계의 평면.

  • VTK 형식의 FAST.Farm 생성 시각화 출력 파일에 사용되는 명명 규칙에 따라 주변 바람 데이터 입력 파일의 이름을 VTK 형식으로 바꿉니다(선행 0 포함 및 제외). t).

  • 풍력 발전소의 처음 9개 이상의 풍력 터빈에 대한 유입 및 후류 관련 출력 채널을 지원합니다.

  • 풍력 발전소 통합 시스템 설계 및 엔지니어링 모델에 대한 FAST.Farm 인터페이스(WISDEM\(^\text{TM}\)) 시스템 엔지니어링 애플리케이션(다분야 설계, 분석 및 최적화, 불확실성 정량화 등)을 위한 것입니다.

  • OpenFAST를 사용하는 FAST.Farm 분석보다 훨씬 더 계산적으로 효율적인 고급 성능 전용 풍력 발전소 분석을 지원하기 위해 OpenFAST의 대안으로 독립형 AeroDyn(또는 동등한 BEM 도구)의 공기 역학 모듈인 AeroDyn용 래퍼를 개발합니다.

  • 다음과 같은 고유한 해상 풍력 에너지 문제를 해결합니다.

    • 해상 풍력 발전소 전체에 걸쳐 일관된 파도 보장

    • 공기-물 인터페이스 지원

    • 공유 계류 및 정박 장치를 고려하십시오(부유식 해상 풍력 발전소의 경우).

  • 해저 해양 터빈 어레이를 지원하는 기능을 채택합니다(추가 질량 효과를 처리하기 위해 입력에서 출력으로의 직접적인 피드스루 지원이 필요할 수 있음).
