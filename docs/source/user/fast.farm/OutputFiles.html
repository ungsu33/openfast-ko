4.19.5. 출력 파일

FAST.Farm은 에코 파일, 요약 파일, 시각화 출력 파일, 시계열 결과 파일, OpenFAST 관련 파일 등 5가지 유형의 출력 파일을 생성합니다. 다음 섹션에서는 이러한 파일의 목적과 내용을 자세히 설명합니다.

4.19.5.1. Echo 파일

다음의 경우 Echo = FAST.Farm 기본 입력 파일의 TRUE, 파일 내용은 명명 규칙 <을 사용하여 파일에 반영됩니다.RootName.ech, 여기서 <RootName>에 정의된 대로입니다. 섹션 4.19.4.3. 에코 파일은 기본 입력 파일을 디버깅하는 데 유용합니다. 기본 입력 파일을 구문 분석하는 동안 FAST.Farm에서 오류가 발생하면 에코 파일의 내용이 잘립니다. 오류는 일반적으로 마지막으로 성공적으로 에코된 줄 다음 줄에 해당합니다.

4.19.5.2. 요약 파일

다음의 경우 SumPrint = FAST.Farm 기본 입력 파일의 TRUE, FAST.Farm은 <라는 명명 규칙을 사용하여 요약 파일을 생성합니다.RootName.sum>. 이 파일에는 풍력 터빈 위치 및 OpenFAST 기본 입력 파일을 포함하여 풍력 발전소 모델에 대한 주요 정보가 요약되어 있습니다. 웨이크 역학 유한차분 그리드 및 매개변수; 다양한 모델 구성요소의 시간 단계; 그리고 선택된 출력의 이름 단위와 순서.

4.19.5.3. 시각화 출력 파일

다음의 경우 WrDisWind = FAST.Farm 기본 입력 파일의 TRUE인 FAST.Farm은 전체 3D 저해상도 및 고해상도 교란 바람 데이터 출력 파일, 즉 시각화를 위해 풍력 단지 전체에 걸쳐 주변 바람 및 후류 상호 작용을 생성합니다. 이러한 출력 파일의 VTK 데이터 형식 및 공간 해상도(그리드 포인트 수, 원점 및 간격)는 FAST.Farm 시뮬레이션에서 사용되는 해당 저해상도 및 고해상도 주변 바람 데이터와 일치합니다. VTK 파일은 다음 디렉터리에 기록됩니다. vtk_ff FAST.Farm 기본 파일이 저장되는 위치입니다. 이러한 출력 파일의 명명 규칙은 다음과 같습니다. <RootName>.낮음.Dis.<n낮은>.vtk 및 <RootName>.HighT<nt>.디스.<n높은>.vtk 저해상도 및 고해상도 교란 풍속 데이터 파일에 대해 각각 적용되며, 여기서 <nt>, <n낮은>, 및 <n높은 에 정의된 바와 같습니다 섹션 4.19.4.3, 그러나 앞에 0이 붙습니다.

  • 마찬가지로 만약에 NOutDisWindXY, NOutDisWindYZ, 또는 NOutDisWindXZ FAST.Farm 기본 입력 파일에서 0보다 큰 값으로 설정되면 FAST.Farm은 전체 저해상도 영역의 2D 슬라이스인 저해상도 교란 바람 데이터(후류 포함) 출력 파일을 생성합니다. 2D 슬라이스는 평행합니다. X-Y, Y-Z및/또는 X-Z 전역 관성계 좌표계의 평면. VTK 파일은 다음 디렉터리에 기록됩니다. vtk_ff FAST.Farm 기본 파일이 저장되는 위치입니다. 이러한 출력 파일의 명명 규칙은 다음과 같습니다. <RootName>.낮음.DisXY<n밖으로>.<n낮은>.vtk, <RootName>.낮음.DisYZ<n밖으로>.<n낮은>.vtk, 및

  • <RootName>.낮음.DisXZ<n밖으로>.<n낮은>.vtk 에 대한 X-Y, Y-Z, 및 X-Z 각각 슬라이스 <n밖으로> 에 정의된 바와 같다 섹션 4.19.4.3, 그러나 앞에 0이 붙습니다.

방해받는 모든 바람 데이터 파일의 시간 단계(프레임 속도의 역수)는 입력 매개변수에 의해 설정됩니다. WrDisDT FAST.Farm 기본 입력 파일에 있습니다. 전체 고해상도 교란 바람 데이터 출력 파일은 다음의 프레임 속도로 출력되지 않습니다. \(1/\)DT_High, 그러나 출력은 다음 주기마다 출력됩니다. WrDisDT 초.

각 시각화 출력 파일은 충실도가 높은 전구체 시뮬레이션을 위한 주변 바람 데이터 파일에 사용되는 것과 동일한 VTK 형식을 따릅니다. 보다 섹션 4.19.4.4 파일 형식에 대한 자세한 내용은

주변 바람과 후류 상호 작용을 시각화하는 것은 결과를 해석하고 문제를 디버깅하는 데 유용할 수 있습니다. 그러나 FAST.Farm은 다음과 같은 경우 출력 옵션당 많은 파일을 생성합니다. WrDisWind = TRUE 및/또는 언제 NOutDisWindXY, NOutDisWindYZ및/또는 NOutDisWindXZ 0보다 크게 설정되었습니다. 이 파일 생성으로 인해 FAST.Farm 속도가 느려지고 특히 전체 저해상도 및 고해상도 교란 바람 데이터 파일을 생성할 때 많은 디스크 공간을 차지합니다. 따라서 많은 FAST.Farm 시뮬레이션을 실행할 때는 시각화를 비활성화하는 것이 좋습니다.

4.19.5.4. 웨이크 역학 평면 파일

옵션 설정 OutAllPlanes 기본 FAST.Farm 입력 파일에서 true로 설정하면 Wake Dynamics 모듈의 깨우기 평면이 기록됩니다. 이 옵션을 사용하려면 디스크에 집중적으로 써야 하며 시뮬레이션 속도가 크게 느려집니다. 웨이크 플레인은 폴더에 VTK 형식으로 기록됩니다. vtk_ff_planes 시뮬레이션 디렉토리의 루트에 있습니다. VTK 파일은 각 평면, 시간 단계 및 터빈에 대해 작성됩니다. 작성되는 비행기의 수는 각각 증가합니다. DT_Low 전체 평면 수까지의 시간 단계 Num_Planes 도달했습니다. 평면의 좌표는 구불구불한 참조 프레임(전역 좌표가 아님)에 있으며 데카르트 좌표를 사용합니다. 다음 필드는 항상 기록됩니다: 후류 부족 속도(구불구불한 프레임에서), 주변, 전단 및 총 와류 점도의 x,y,z 구성요소. 언제 Mod_Wake=1` (극 후류), 필드는 극에서 데카르트로 변환됩니다. 다음과 같은 경우 VTK 파일에 추가 속도 구배가 제공됩니다. Mod_Wake/=1`.

4.19.5.5. 시계열 결과 파일

FAST.Farm 시계열 결과는 명명 규칙 <을 사용하여 ASCII 텍스트 기반 파일에 기록됩니다.RootName.out. 결과는 표 형식으로 되어 있으며, 각 열은 데이터 채널이고 첫 번째 열은 항상 시뮬레이션 시간입니다. 각 행은 시뮬레이션 출력 시간 단계에 해당합니다. 데이터 채널은 OutList 섹션 OUTPUT FAST.Farm 기본 입력 파일의 섹션. FAST.Farm 생성 파일의 열 형식은 다음을 사용하여 지정됩니다. OutFmt FAST.Farm 기본 입력 파일의 매개변수입니다.

4.19.5.6. OpenFAST 출력 파일

FAST.Farm에서 생성된 출력 파일 외에도 각 풍력 터빈의 OpenFAST 모델도 출력 파일을 생성할 수 있습니다. OpenFAST가 생성할 수 있는 다양한 출력 파일(OpenFAST 입력 파일 내에 지정된 드라이버/글루 코드 및 모듈 수준 모두에서)은 OpenFAST 문서에 설명되어 있으며 요약(.합집합) 파일, 시계열 결과(ASCI .밖으로 또는 바이너리 .outb) 파일, 시각화(.vtk) 파일 등. FAST.Farm 시뮬레이션은 이와 동일한 파일을 생성하지만 경로/루트 이름은 다음으로 변경됩니다. <WT_FASTInFile의 RootName>.T<nt>.
