4.5.6. 결론

이 문서에서는 오픈 소스 공력서보탄성 솔버 OpenFAST와 결합된 주파수 기반 공력음향 모델 세트를 설명합니다. 이 모델의 목표는 풍력 터빈 로터의 공력소음 방출을 예측하는 것입니다. 이 문서는 OpenFAST에 결합된 모델과 뮌헨 기술 대학에서 구현되고 공력탄성 솔버 Cp-Lambda에 결합된 모델 간의 코드 간 비교를 보여줍니다. 비교는 IEA Wind Task 37 육상 기반 기준 풍력 터빈의 공력음향 방출을 시뮬레이션하여 수행되었습니다. 결과는 두 구현 간에 좋은 일치를 보여줍니다. 동일한 터빈 모델은 나중에 그 성능을 보여주는 공력음향 모델을 연습하는 데 사용됩니다. 마지막으로 부록에서는 공력음향 해석을 실행하기 위한 OpenFAST 입력 파일의 항목을 설명합니다.

향후 작업은 항공음향 모델의 검증에 중점을 둘 것입니다. 이와 병행하여 전파 모델을 조사하고 구현합니다. 마지막으로, 초저주파 소음과 이를 시뮬레이션할 수 있는 시간 영역 모델에 주의를 기울일 것입니다.
