4.13.6. 부록

4.13.6.1. InflowWind 입력 파일

이 부록에서는 InflowWind 입력 파일 구조를 설명하고 예제를 제공합니다.

1) InflowWind 드라이버 입력 파일 (driver input file example):

드라이버 입력 파일은 InflowWind의 독립형 버전에만 필요합니다. 여기에는 InflowWind 파일, 보간 매개변수 및 원하는 출력 파일에 관한 입력이 포함됩니다. 대신 명령줄 인수를 사용하면 이 파일 없이 InflowWind 드라이버를 실행할 수도 있습니다.

2) InflowWind 기본 입력 파일 (primary input file example):

기본 InflowWind 입력 파일은 다른 파일에서 생성되거나 읽혀지는 유입을 정의합니다. InflowWind 파일에는 각 유형의 바람 파일 형식에 대한 섹션이 포함되어 있습니다.

3) 기본 블레이드 스케일링 파일 (primary input file example):

이 파일에는 Bladed의 무차원 전체 필드 난류 파일의 크기를 조정하는 방법을 결정하는 줄이 포함되어 있습니다.

4) 균일풍 데이터 파일 (uniform wind input file example):

이 파일에는 균일한(결정론적) 바람 데이터 파일을 정의하는 라인이 포함되어 있습니다.
