4.13.2. InflowWind 입력 파일

고정 및 부동 MHK 터빈의 경우 모든 InflowWind 매개변수는 해저를 기준으로 정의되어야 합니다. MHK 터빈에 대한 터빈과 유입 좌표계 간의 일관성을 유지하기 위해 InflowWind에 전달된 쿼리 지점은 해저에 원점을 배치하도록 글루 코드/드라이버 수준에서 조정됩니다.

4.13.2.1. InflowWind의 기본 Bladed 바람 파일 지원

기본 Bladed wind 파일(스케일링 없이)을 읽는 기능이 InflowWind에 추가되었습니다. 이 기능을 사용하려면 WindType 으로 설정해야 합니다. 7 기본 InflowWind 입력 파일의 5번째 줄에 있습니다. 이 파일의 예는 inAn로 제공됩니다. 이 Native Bladed 스케일링 파일의 예는 다음에 포함되어 있습니다. 섹션 4.13.6.

7                  WindType       - switch for wind file type (1=steady; 2=uniform; 3=binary TurbSim FF; 4=binary Bladed-style FF; 5=HAWC format; 6=User defined; 7=Bladed native)

섹션에서 WindType = 4, 중간 Bladed wind 파일의 이름이 제공되어야 합니다(파일 확장자 포함). tower 파일 플래그는 무시됩니다.

================== Parameters for Binary Bladed-style Full-Field files   [used only for WindType = 4] =========
"tw06_80hh_s200.BladedWind.ipt"  FilenameRoot   - Name of the Full field wind file to use (.wnd, .sum)
 F                               TowerFile      - Have tower file (.twr) (flag)

중간 Bladed 바람 스케일링 파일에는 다음 정보가 포함되어야 하며, 이 정보는 Bladed 프로젝트 시뮬레이션 파일에서 직접 검색할 수 있습니다. MSTART WINDSEL 및 MSTART WINDV 섹션. 또한 파일에는 다음이 포함될 수 있습니다. XOFFSET 바람이 주어진 거리만큼 이동할 수 있도록 하는 선입니다. 포함되지 않은 경우, XOFFSET 0으로 가정됩니다. 이 Native Bladed 스케일링 파일의 예는 다음에 포함되어 있습니다. 섹션 4.13.6.

UBAR  12
REFHT  90
TI  0.033333
TI_V  0.026667
TI_W  0.016667
WDIR  0
FLINC  .139626222222222
WINDF    "../tw06_80hh_s200.wnd"
WSHEAR    .2
XOFFSET  0

4.13.3. InflowWind에 지정된 각도

풍향과 상승 각도는 InflowWind 입력 파일에서 지정할 수 있습니다. InflowWind에서 기본 블레이드 바람 파일 지원을 사용할 때 InflowWind 입력의 각도는 기본 블레이드 입력 파일에 지정된 값으로 덮어쓰여집니다. InflowWind는 이러한 풍향과 상승 각도에 따라 허브 높이 타워 중심선을 기준으로 윈드 박스를 회전시킵니다.

균일한 바람 파일은 바람의 방향과 상승 각도도 지정합니다. 균일한 바람 파일 DO NOT에 지정된 각도는 바람 상자를 회전하지만 단지 지역 풍속을 전역 좌표로 변환합니다.

로컬에서 변환하는 경우 [u v w] 글로벌로 [U V W] 기준 시스템, 상향류 회전, R(upflow) 풍향 회전 전에 발생하며, R(wind direction):

[U V W] = R(wind direction) * R(upflow) * [u v w]

InflowWind 및 UniformWind 파일에서 각도 조합을 사용하는 경우 UniformWind 각도가 먼저 적용됩니다.

참고: 이는 InflowWind에 상향 흐름이 지정되고 UniformWind에 풍향이 지정된 경우 두 각도가 동일한 파일에 지정된 경우와 다른 순서로 회전이 수행됨을 의미합니다.

[U V W] = R(wind direction: InflowWind) * R(upflow: InflowWind) * R(wind direction: UniformWind) * R(upflow: UniformWind) * [u v w]

4.13.4. 파동과 유입전류의 중첩

MHK 터빈의 경우 모든 수중 구성요소가 동일한 유입장에 노출되도록 파동 및 해류 속도와 가속도가 중첩(즉, 합산)됩니다. AeroDyn 및 HydroDyn는 모두 SeaState에 파동장 정보를 쿼리할 수 있습니다. 그런 다음 SeaState는 현재 필드에 대해 InflowWind를 쿼리하고 속도와 가속도를 합산하고 중첩된 흐름장 정보를 반환합니다. 이는 아래 나열된 MHK 터빈 모델링에 여러 가지 의미를 갖습니다. InflowWind의 동적 압력 기여는 무시됩니다.

로터 또는 로터/타워만 모델링하는 경우(즉, AeroDyn로만 모델링된 유체역학):

  • 파도가 있는 유동장을 정의할 때 SeaState를 사용해야 합니다.

  • SeaState의 현재 정의는 항상 0으로 설정되어야 합니다.

  • SeaState가 활성화되면 InflowWind도 활성화되어야 하지만 전류는 0으로 설정될 수 있습니다.

  • 전류로 유동장을 정의할 때 InflowWind를 사용해야 합니다.

  • 결합된 파동 및 전류 흐름 필드의 경우 SeaState는 InflowWind를 쿼리합니다.

로터 또는 로터/타워 및 지지 구조를 모델링할 때(즉, AeroDyn 및 HydroDyn에서 모델링된 유체 역학):

  • 파동이 없는 유동장을 정의하는 경우에도 SeaState를 항상 사용해야 합니다.

  • SeaState의 현재 정의는 항상 0으로 설정되어야 합니다.

  • SeaState가 활성화되면 InflowWind도 활성화되어야 하지만 전류는 0으로 설정될 수 있습니다.

  • 전류로 유동장을 정의할 때 InflowWind를 사용해야 합니다.

  • 현재의 경우에만 SeaState 웨이브 필드를 0으로 설정합니다. 현재 정보는 InflowWind에서 SeaState를 통해 전달됩니다.

  • 결합된 파동 및 전류 흐름 필드의 경우 SeaState는 InflowWind를 쿼리합니다.
