4.1.2. API 버전 간 변경

이 페이지에는 서로 다른 버전 간의 OpenFAST API(입력 파일)의 주요 변경 사항이 나열되어 있습니다.

변경 사항은 모듈 입력 파일, 줄 번호 및 플래그 이름에 따라 표로 작성됩니다. 줄 번호는 모든 변경 사항이 구현된 후 결과 줄 번호에 해당합니다. 따라서 다음 줄 번호가 정확하도록 각 항목을 순서대로 구현해야 합니다.

4.1.2.1. OpenFAST v4.2.x ~ OpenFAST v5.0.0

추가된 질량 및 유체 관성 ​​하중이 AeroDyn의 로터 블레이드와 타워에 추가되었습니다. 이로 인해 AeroDyn 블레이드 입력 파일에 새 열이 생성되고 AeroDyn 기본 입력 파일의 "타워 영향 및 공기 역학" 섹션에 새 열이 생성됩니다. 이러한 하중이 추가되면 부력 플래그도 제거되었으며 각각에 대해 별도의 플래그를 통하는 대신 적절한 계수를 0으로 설정하여 부력, 추가된 질량 및 관성 하중을 모두 끌 수 있습니다.

InflowWind와 SeaState 사이의 파동 및 전류 속도의 중첩이 활성화되었으며, 이를 위해서는 AeroDyn 드라이버 입력 파일에 "SeaState 데이터" 섹션이 필요합니다.

OpenFAST 입력 파일의 변경 사항은 하나의 터빈에서 여러 로터를 지원합니다. 라인 16, NRotors는 터빈의 로터 수를 지정하는 데 필요합니다. 50-56행은 두 번째 로터에 대한 ElastoDyn, BeamDyn 및 ServoDyn 입력 파일을 지정합니다. 다른 모든 모듈은 첫 번째 섹션에 지정된 입력 파일을 사용합니다. 그만큼 MirrorRotor 라인은 로터가 회전하는 방향을 바꾸도록 플래그를 설정합니다. 첫 번째 로터는 항상 일반적인 방향으로 회전합니다. 이 라인은 NRotors가 1보다 큰 경우에만 지정되며 후속 로터에 대해 반복됩니다.
