4.3.11. 부록

4.3.11.1. AeroDyn 입력 파일

이 부록에서는 AeroDyn 입력 파일 구조를 설명하고 예제를 제공합니다.

1) 기본 AeroDyn 드라이버 입력 파일: (driver input file example): 드라이버 입력 파일은 AeroDyn의 독립형 버전에만 필요하며 일반적으로 OpenFAST에서 생성되고 결합되지 않은 모델에 대한 공기 역학 시뮬레이션을 제어하는 데 필요한 입력을 포함합니다.

AeroDyn 드라이버 시계열 입력 파일 (driver timeseries input file example): AeroDyn 드라이버의 케이스에 대한 시계열 입력 파일을 사용하면 매개변수가 시간에 따라 달라질 수 있습니다. 이 기능은 OpenFAST 외부의 공기 역학적 응답을 디버깅하는 데 유용할 수 있습니다.

2) 멀티로터 AeroDyn 드라이버 입력 파일 (driver input file example)

3) AeroDyn 기본 입력 파일 (primary input file example)

기본 AeroDyn 입력 파일은 모델링 옵션, 환경 조건(자유 흐름 제외), 익형, 타워 노드 이산화 및 속성, 타워, 허브 및 나셀 속성은 물론 출력 파일 사양을 정의합니다.

파일은 여러 기능 섹션으로 구성됩니다. 각 섹션은 공기역학 모델의 측면에 해당합니다.

입력 파일은 사용자용이지만 소프트웨어에서는 사용되지 않는 두 줄의 헤더 정보로 시작됩니다.

  1. 에어포일 데이터 입력 파일

(profile data)

(profile coordinates)

익형 데이터 입력 파일 자체(각 익형당 하나)에는 양력, 항력, AoA 대비 피칭 모멘트 계수와 UA 모델 매개변수가 포함된 테이블이 포함되어 있습니다. 이러한 파일에서는 공백이 아닌 첫 번째 문자가 느낌표(!)인 줄은 무시됩니다(주석 줄 삽입 시). 주석이 아닌 줄은 파일 내에서 순서대로 나타나야 하지만 명확하게 읽기 위해 원하는 대로 주석 줄을 혼합할 수도 있습니다.

5) 블레이드 데이터 입력 파일 (blade data input file example)

블레이드 데이터 입력 파일에는 블레이드의 절점 이산화, 형상, 비틀림, 현, 익형 식별자 및 부력 속성이 포함되어 있습니다. 각 블레이드에 대해 별도의 파일이 사용되므로 공기역학적 불균형을 모델링할 수 있습니다.

4.3.11.2. AeroDyn 출력 채널 목록

AeroDyn에는 일반 출력이 있습니다(참조: 섹션 4.3.3.17 위의) 및 노드 출력(참조 섹션 4.3.3.18).

출력에 사용되는 좌표계(i, h, p, l, a로 표시)는 다음에 설명되어 있습니다. 섹션 4.3.2.

가능한 모든 출력 매개변수의 포괄적인 최신 목록이 Excel 파일에 제공됩니다. OutListParameters.xlsx탭에서 AeroDyn 및 AeroDyn_Nodes . Excel 파일의 이름은 의미별로 그룹화되어 있지만 원하는 대로 AeroDyn 입력 파일의 OUTPUTS 섹션에서 순서를 지정할 수 있습니다.

일반 출력 일반 출력의 몇 가지 예가 아래에 나와 있습니다(참조: 전체 목록은 OutListParameters.xlsx ):

  • RtAeroCp : 공기 역학적 동력 계수.

  • \(B \alpha N \beta\), 출력 노드를 나타냅니다. 블레이드의 \(\beta\) 블레이드의 \(\alpha\), 여기서 \(\alpha\) 는 [1,3] 범위의 숫자이고 \(\beta\) 는 항목에 해당하는 [1,9] 범위의 숫자입니다. \(\beta\) 의 \(\textit{BlOutNd}\) 목록.

  • \(\textit{TwN}\beta\) 는 출력 노드를 나타냅니다. 타워의 \(\beta\) 는 항목에 해당하는 [1,9] 범위에 있습니다. \(\beta\) 의 \(\textit{TwOutNd}\) 목록.

노드 출력

노드 출력의 예는 아래에 설명되어 있습니다(참조: 전체 목록은 OutListParameters.xlsx ).

교란되지 않은 유속의 x 성분(VUnd) 관성 프레임의 모든 블레이드 노드에서(\(i\))를 배치하여 요청합니다. AeroDyn 노드 출력 목록의 \(VUndxi\) . 그러면 다음 형식의 출력 채널이 생성됩니다. AB\(\alpha N\beta\) 분드시, 노드용 \(\beta\) 블레이드의 \(\alpha\), 여기서 \(\alpha\) 는 [1,3] 범위의 숫자이고 \(\beta\) 는 AeroDyn 블레이드 노드의 인덱스에 해당하는 [1,999] 범위의 숫자입니다.
