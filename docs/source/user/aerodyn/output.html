4.3.4. 출력 파일

AeroDyn는 에코 파일, 요약 파일, 시계열 결과 파일의 세 가지 유형의 출력 파일을 생성합니다. 다음 섹션에서는 이러한 파일의 목적과 내용을 자세히 설명합니다.

4.3.4.1. Echo 파일

다음을 설정하면 Echo 플래그를 지정하다 TRUE AeroDyn 드라이버 파일 또는 AeroDyn 기본 입력 파일에서 해당 파일의 내용은 명명 규칙을 사용하여 파일에 반영됩니다. OutFileRoot.ech 드라이버 입력 파일의 경우 OutFileRoot.AD.ech AeroDyn 기본 입력 파일의 경우. OutFileRoot AeroDyn 독립형 실행 시 드라이버 입력 파일의 I/O SETTINGS 섹션에 지정되거나 결합 시뮬레이션 실행 시 FAST 프로그램에 의해 지정됩니다. 에코 파일은 입력 파일을 디버깅하는 데 유용합니다. AeroDyn가 입력 파일을 구문 분석하는 동안 오류가 발생하면 에코 파일의 내용이 잘립니다. 오류는 일반적으로 마지막으로 성공적으로 에코된 줄 다음 줄에 해당합니다.

4.3.4.2. 요약 파일

AeroDyn는 명명 규칙을 사용하여 요약 파일을 생성합니다. OutFileRoot.AD.sum 만약에 SumPrint 매개변수는 다음과 같이 설정됩니다. TRUE. OutFileRoot AeroDyn 독립형 실행 시 드라이버 입력 파일의 I/O SETTINGS 섹션에 지정되거나 결합 시뮬레이션 실행 시 FAST 프로그램에 의해 지정됩니다. 이 파일에는 활성화된 기능과 선택된 출력을 포함하여 공기 역학 모델에 대한 주요 정보가 요약되어 있습니다.

4.3.4.3. 결과 파일

독립형 모드에서는 AeroDyn 시계열 결과(각 사례마다 별도의 파일)가 명명 규칙을 사용하여 텍스트 기반 파일에 기록됩니다. OutFileRoot.#.out, 어디 OutFileRoot 드라이버 입력 파일의 I/O SETTINGS 섹션에 지정되어 있으며 '#’ 문자는 COMBINED-CASE ANALYSIS 섹션에 있는 테스트 케이스 라인에 해당하는 정수입니다. AeroDyn가 FAST에 연결된 경우 FAST는 AeroDyn 결과를 포함하는 마스터 결과 파일을 생성하고 AeroDyn는 자체 결과를 작성하지 않습니다. 결과는 표 형식으로 되어 있으며, 각 열은 데이터 채널이고(첫 번째 열은 항상 시뮬레이션 시간임) 각 행은 시뮬레이션 출력 시간 단계에 해당합니다. 데이터 채널은 AeroDyn 기본 입력 파일의 OUTPUTS 섹션에 지정됩니다. AeroDyn 생성 파일의 열 형식은 다음을 사용하여 지정됩니다. OutFmt 드라이버 입력 파일의 매개변수입니다.
