4.17.1. 입력 파일

사용자는 별도의 입력 파일을 사용하여 각 StC 인스턴스를 구성합니다. 이 입력 파일은 장착 위치를 기준으로 StC의 위치를 ​​정의하고 속성을 정의합니다. 또한 해당 위치에 시계열 하중을 적용하기 위해 외부 힘 파일과 함께 사용할 수도 있습니다(주로 진단 목적으로 사용됨).

4.17.1.1. 단위

구조 제어는 SI 시스템(kg, m, s, N)을 사용합니다. 별도로 지정하지 않는 한 각도는 라디안 단위로 간주됩니다.

4.17.1.2. 구조적 제어 위치

구조 제어 입력 파일은 StC 인스턴스의 위치와 속성을 정의합니다. 위치는 기본 ServoDyn 입력 파일에 제공된 StC 유형을 기준으로 합니다(참조). 섹션 4.15.1.2.11). 네 가지 위치 유형은 Nacelle, Tower, Blade 및 Platform입니다.

StC에 대한 매핑 정보는 기본 OpenFAST 요약 파일에 제공됩니다.

4.17.1.2.1. 나셀 StC

이 StC 장착 위치는 나셀 기준점을 기준으로 부착됩니다. 모든 나셀 모션(요, 타워 플렉스 및 플랫폼 모션으로 인한 모션 포함)을 추적합니다.

4.17.1.2.2. 타워 StC

이 StC 장착 위치는 타워 베이스 위에 지정된 높이의 타워 메쉬에 부착됩니다. 이 StC 부착물은 해당 높이에서 라인 메시와 함께 이동합니다. 예를 들어, 90m 타워의 85m 높이에 장착된 StC는 타워 중심선의 85m 높이 위치에 해당하는 메쉬 라인으로 이동합니다.

4.17.1.2.3. 블레이드 StC

이 StC 장착 위치는 블레이드의 z축(IEC 블레이드 좌표계)을 따라 블레이드 루트로부터 지정된 거리에 있는 블레이드 구조 중심에 부착됩니다. 이 위치는 모든 블레이드 변형 및 동작(BeamDyn와 함께 사용할 때 블레이드 비틀림 포함)을 따릅니다. 이 옵션은 BeamDyn 및 ElastoDyn 블레이드 표현 모두에서 사용할 수 있습니다.

이 옵션을 사용하면 각 블레이드에 동일한 StCs가 부착됩니다. StC가 장착된 각 블레이드의 응답은 별도로 추적되며 ServoDyn 탭에 지정된 출력 채널에서 사용할 수 있습니다. OutListParameters.xlsx.

4.17.1.2.4. 플랫폼 StC

이 StC 장착 위치는 플랫폼 기준점을 기준으로 위치합니다. 강체 플랫폼이 모델링되면(예: 강체 반잠수정) 플랫폼 기준점에 부착됩니다. 유연한 부유체를 모델링하면 StC가 SubDyn 메쉬에 부착됩니다.

4.17.1.3. 구조 제어 입력 파일

입력 파일에는 임의 개수의 주석 처리된 헤더 행과 입력 파일의 임의 위치에 주석 처리된 행이 있을 수 있습니다. (Example Structural Control input file for tuned mass damper on tower for NREL 5 MW TLP):

4.17.1.3.1. 시뮬레이션 제어

Echo [깃발]

<RootName>.ech에 대한 Echo 입력 데이터

4.17.1.4. StC 자유도

StC_DOF_MODE [스위치]

DOF 모드 {0: StC 또는 TLCD DOF 없음; 1: StC_X_DOF, StC_Y_DOF 및/또는 StC_Z_DOF(3개의 독립적인 StC DOFs); 2: StC_XY_DOF(2DOF 전방향 StC); 3: StC_XYZ_DOF(3DOF 전방향 StC); 5: TLCD; 6: 규정된 힘/모멘트 시계열; 7: 외부 DLL에 의해 결정되는 힘}

StC_X_DOF [깃발]

StC X에 대해 DOF 켜기 또는 끄기 [다음 경우에만 사용됩니다. StC_DOF_MODE==1 ]

StC_Y_DOF [깃발]

StC Y에 대해 DOF 켜기 또는 끄기 [다음 경우에만 사용됩니다. StC_DOF_MODE==1 ]

StC_Z_DOF [깃발]

StC Z에 대해 DOF 켜기 또는 끄기 [다음 경우에만 사용됩니다. StC_DOF_MODE==1 ]

4.17.1.5. StC 위치

StC의 위치는 연결된 구성 요소를 기준으로 합니다. 이는 기본 ServoDyn 입력 파일에 지정됩니다. 위의 설명을 참조하세요.

StC_P_X [m]

StC의 정지 X 위치

StC_P_Y [m]

StC의 정지 Y 위치

StC_P_Z [m]

StC의 정지 Z 위치

4.17.1.6. StC 초기 조건

경우에만 사용 StC_DOF_MODE==1, 2 또는 3

StC_X_DSP [m]

StC X 초기 변위 [휴지 위치에 비해]

StC_Y_DSP [m]

StC Y 초기 변위 [휴지 위치에 비해]

StC_Z_DSP [m]

StC Z 초기 변위 [휴지 위치에 비해; 경우에만 사용 StC_DOF_MODE==1 및 StC_Z_DOF==TRUE 또는 다음의 경우 StC_DOF_MODE==3 ]

StC_Z_PreLd [N]

StC Z 스프링 예압. 뉴턴 단위의 스프링 예압에 대한 직접적인 값 또는 "중력" 중력이 작용할 때 StC Z 질량의 정지 위치를 다음과 같이 이동시키도록 스프링에 예하중을 가하기 위한 \(F_{Z_{PreLoad}} = M_Z * G\), 또는 "없음" 스프링 프리로드를 비활성화합니다. 보다 섹션 4.17.2.1.4.2 구현에 대한 자세한 내용은 [다음 경우에만 사용됩니다. StC_DOF_MODE==1 및 StC_Z_DOF==TRUE 또는 다음의 경우 StC_DOF_MODE==3 ]

4.17.1.12. 규정된 시계열

StC 댐퍼 대신에 미리 정해진 힘과 모멘트의 시계열을 적용할 수 있습니다. 힘과 모멘트는 전체 좌표계 또는 로컬(후속) 좌표계에 적용될 수 있습니다. 이 기능은 경우에만 사용 StC_DOF_MODE==6.

PrescribedForcesCoord [스위치]

규정된 힘은 전역 또는 지역 좌표에 있습니다. {1: 전역; 2: 로컬}. StC_DOF_MODE==7을 사용하는 경우 PrescribedForcesCoord는 1이어야 합니다.

PrescribedForcesFile [-]

규정된 힘의 파일 이름입니다. 예상되는 형식은 time, FX, FY, FZ, MX, MY, MZ의 7개 열입니다. 값은 지정된 시간 단계와 값 세트 사이의 파일에서 보간됩니다. 입력 파일에는 임의 개수의 주석 처리된 헤더 행과 입력 파일의 임의 위치에 주석 처리된 행이 있을 수 있습니다.

블레이드에 장착된 StCs의 경우 각 블레이드에 대해 서로 다른 시간 시리즈 입력 파일을 제공할 수 있습니다(새 줄에 추가 파일 이름 추가). 하나의 파일만 제공되면 모든 블레이드에 사용됩니다. 회귀 테스트의 예를 참조하세요. StC_test_OC4Semi_blade2 예제 설정을 위해.
