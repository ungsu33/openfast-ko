4.6.1. 입력 및 출력 파일

4.6.1.1. 단위

AeroDisk는 SI 시스템(kg, m, s, N)을 사용합니다.

4.6.1.2. 입력 파일

AeroDisk 입력 파일은 액추에이터 디스크 계산에 필요한 일반 입력을 정의합니다. 원하는 동작을 달성하기 위해 사용자가 다음 입력을 변경할 수 있습니다.

4.6.1.2.1. 시뮬레이션 제어

에코 [스위치]

입력 파일 내용을 <RootName>.ADsk.ech 파일에 씁니다. 이는 입력 파일에 대해 보고된 오류를 진단하는 데 유용합니다.

DT [초]

AeroDisk가 사용할 통합 시간 단계 또는 글루 코드 시간 단계를 사용하는 _”기본값”_입니다.

4.6.1.2.2. 환경 조건

AirDens [kg/m^3]

공기 밀도 또는 _”기본값”_ - 글루 코드의 공기 밀도 사용

4.6.1.2.3. 액추에이터 디스크 속성

RotorRad [m]

로터의 반경 또는 글루 코드에서 전달된 값을 사용하는 _”기본값”_

디스크 액츄에이터 힘과 모멘트에 대한 조회 테이블은 다음과 같습니다. 이 테이블의 데이터는 단일 변수(TSR 예를 들어) 또는 최대 4개의 변수입니다. 테이블의 마지막 6개 열에는 첫 번째 열 세트에 제공된 조건 세트에 해당하는 6개의 힘 및 모멘트 계수가 포함되어야 합니다.

InColNames [-]

입력 파일의 변수 열에 해당하는 열 이름 목록을 쉼표로 구분합니다. 옵션은 아래를 참조하세요.

InColDims [-]

명명된 각 변수 열 이름에 대한 고유 항목 수를 쉼표로 구분한 목록입니다. 테이블의 행 수는 주어진 모든 숫자의 곱과 같아야 합니다. 에 명시된 항목 수와 동일해야 합니다. InColNames

테이블의 입력 변수 열에는 최소한 하나의 열이 제공되어야 하며 아래 나열된 5개 중 최대 4개(TSR 및 RtSpd 상호 배타적입니다).

TSR [-]

팁 속도 비율은 _RtSpd_와 함께 사용할 수 없습니다.

RtSpd [rpm]

로터 속도는 _TSR_과 함께 사용할 수 없습니다.

VRel [m/s]

로터에 수직인 풍속의 상대 속도

정점 [도]

집단 블레이드 피치

비스듬한 [도]

유입 각도가 기울어집니다. 이것이 제공되지 않으면 왜곡의 영향은 다음과 같이 모델링됩니다. \((cos(\chi))^2\)

테이블의 나머지 6개 열에는 힘과 모멘트 계수가 포함되어야 합니다. 아래의 예시 표를 참조하세요.

4.6.1.3. 출력

쓰기 출력은 다음과 같습니다.

  • "ADSpeed": 액추에이터 디스크 회전 속도(rpm)

  • "ADTSR": 액추에이터 디스크 팁 속도 비율(-)

  • "ADPitch": 액추에이터-디스크 집합 블레이드-피치 각도(deg)

  • "ADVWindx, ADVWindy, ADVWindz": 로컬 좌표계의 액추에이터 디스크 평균 풍속(m/s)

  • "ADSTVx, ADSTVy, ADSTVz": 로컬 좌표계의 액추에이터 디스크 구조 병진 속도(m/s)

  • "ADVRel": 액추에이터 디스크 평균 상대 풍속(m/s)

  • "ADSkew": 액추에이터 디스크 유입 스큐 각도(deg)

  • "ADCp, ADCt, ADCq": 액추에이터 디스크 출력, 추력 및 토크 계수(-)

  • "ADFx, ADFy, ADFz": 로컬 좌표계(N)의 액추에이터 디스크 공기역학적 힘 하중

  • "ADMx, ADMy, ADMz": 로컬 좌표계의 액추에이터 디스크 공기역학적 모멘트 하중(N-m)

  • “ADPower”: 액추에이터 디스크 전력(W)
