4.21.2.1. 입력 파일

이 문서에서는 WaveTank 구성 입력 파일(wavetankconfig_input.txt)는 해양 유체 역학(MHK) 터빈 테스트를 위한 WaveTank 모델을 설정하고 실행하는 데 사용됩니다.

  • 초기화 중에 WaveTank 라이브러리에서 파일을 읽습니다.

4.21.2.2. 컨벤션 및 단위

  • SI 단위는 m, s, kg, N, Pa 전체에서 사용됩니다.

  • 별도로 지정하지 않는 한 각도는 도 단위입니다.

  • 회전 속도는 명시된 rpm 단위입니다.

  • 별도의 언급이 없는 한 위치와 높이는 평균 해수면(MSL)을 기준으로 합니다.

  • 모듈의 입력 파일은 상대 경로 또는 절대 경로일 수 있습니다.

4.21.2.3. 파일 및 시뮬레이션 제어

OutRootName(문자열)

요약이나 기타 파일을 작성할 때 사용되는 루트 이름입니다. 예: FRM1Q_Floating_tank_test.

DT(들)

WaveTank 내부 스케줄링의 공칭 시간 단계입니다. 현재 미사용/예약되어 있습니다.

TMax(들)

WaveTank 내부 스케줄링을 위한 최대 시뮬레이션 시간입니다. 현재 미사용/예약되어 있습니다.

MHK(스위치)

MHK 터빈 유형 스위치:

  • 0: MHK 터빈이 아님

  • 1: 고정 MHK 터빈

  • 2: 플로팅 MHK 터빈

현재는 부동 옵션(2)만 지원됩니다.

InterpOrd (-)

내부 데이터 보간을 위한 보간 순서입니다. 현재 미사용/예약되어 있습니다.

DebugLevel(스위치)

로깅 및 시각화 세부 정보를 제어합니다.

  • 0: 없음

  • 1: I/O 요약

  • 2: + 위치/방향 전달됨

  • 3: + 입력 파일

  • 4: + 모든 메쉬

참고

"사용되지 않음"으로 표시된 매개변수는 향후 개발을 위해 예약되어 있으며 현재 코드 경로에서 무시됩니다.

4.21.2.4. Froude 스케일링(비활성화)

다음 매개변수가 나타날 수 있지만 일반적으로 주석 처리되어 있습니다. 현재 코드에서는 Froude 스케일링이 완료되지 않았습니다. 명시적으로 활성화하지 않는 한 사용하지 마세요.

ScaleFact (-)

Froude 배율 인수 λ = (전체 크기 치수) / (모델 크기 치수). 축소 모델 테스트의 경우 > 1이 예상됩니다.

DensFact (-)

힘/모멘트의 Froude 스케일링과 함께 사용되는 밀도 비율 ρ_full / ρ_model.

4.21.2.5. 환경

Gravity (m/s^2)

중력 가속도.

WtrDens(kg/m^3)

물(작동유체) 밀도.

WtrVisc (m^2/초)

작동 유체의 동점도.

SpdSound (m/초)

작동유체에서의 소리의 속도.

팻(Pa)

기압. 캐비테이션 검사에 사용됩니다.

Pvap(파)

작동유체의 증기압. 캐비테이션 검사에 사용됩니다.

WtrDpth (m)

수심.

MSL2SWL (m)

정수면(SWL)과 평균 해수면(MSL) 사이의 오프셋; 긍정적인 상향.

4.21.2.6. 바다의 주

SS_InputFile(문자열)

파도 조건을 정의하는 SeaState 입력 파일의 경로입니다. 실행 디렉터리를 기준으로 경로가 유효한지 확인하거나 절대 경로를 사용하세요.

WaveTimeShift(들)

위상 및 매치 탱크 조건을 조정하기 위해 SeaState 파동 시계열에 시간 이동을 적용했습니다.

4.21.2.7. MoorDyn

MD_InputFile(문자열)

계류 시스템 속성 및 연결을 정의하는 MoorDyn 입력 파일의 경로입니다.

4.21.2.8. AeroDyn 및 InflowWind

AD_InputFile(문자열)

공기역학적 모델 구성을 정의하는 AeroDyn 입력 파일의 경로입니다(MHK 컨텍스트에서 적용 가능한 수력/공기력 결합에 사용됨).

IfW_InputFile(문자열)

로터의 유입 조건(예: 모델 설정에 따라 전류 또는 바람)을 정의하는 InflowWind 입력 파일의 경로입니다.

4.21.2.9. 터빈 형상 및 참조 프레임

NumBl (-)

로터의 블레이드 수.

HubRad (m)

로터 정점에서 블레이드 루트까지의 거리.

PreCone(도)

블레이드 콘 각도.

OverHang (m)

요 축(타워 중심선)에서 로터 정점까지의 거리입니다. 음수 값은 모델의 규칙에 따라 요 축 뒤쪽의 로터 정점을 나타냅니다.

ShftTilt(도)

로터 샤프트 기울기 각도.

Twr2Shft (m)

타워 상단에서 로터 샤프트 중심(나셀 중심)까지의 수직 거리. 음수 값은 타워 상단 아래에 있습니다.

TowerHt (m)

MSL를 기준으로 한 타워의 높이입니다. 타워는 수직으로 정렬되어 있습니다. TowerBsPt (경사 타워는 지원되지 않음)

TowerBsPt (m, m, m)

x 및 y의 플랫폼 기준 위치와 z의 MSL를 기준으로 한 타워 기본 위치:

  • x: 서지 축을 따라

  • y: 흔들림 축을 따라

  • z: MSL를 기준으로 한 높이

PtfmRefPos (m, m, m)

MSL를 기준으로 한 플랫폼 기준점 위치입니다. 모든 플랫폼 동작과 하중이 이 지점에서 연결됩니다.

PtfmRefOrient(도,도,도)

오일러 각도[롤, 피치, 요]로 제공되는 플랫폼 기준 방향입니다.

4.21.2.10. 터빈 초기 조건

RotSpeed(rpm)

로터의 초기 회전 속도(로터 좌표)입니다.

NacYaw(도)

초기 또는 고정 나셀 요 각도.

BldPitch(도)

초기 블레이드 1 피치 각도. 다중 블레이드 모델을 사용하는 경우 블레이드 피치 제어는 일반적으로 다른 모듈의 블레이드별로 적용됩니다. 여기서는 블레이드 1을 초기화합니다.

방위각(도)

초기 로터 방위각.

4.21.2.11. 웨이브 부표

WaveBuoyLoc (m, m)

탱크 좌표계에서 파도 고도 측정 부표의 위치. SeaState 데이터는 이 위치의 각 시간 단계에서 반환됩니다.

4.21.2.12. 산출

SendScreenToFile(플래그)

true인 경우 화면 출력을 다음 이름의 파일로 보냅니다. <OutRootName>.screen.log.

OutFile(스위치)

채널의 표 형식 출력을 제어합니다.

  • 0: 채널의 출력 파일이 없습니다.

  • 1: 텍스트 형식의 출력 파일(기본값 DT로 작성됨)

OutFmt(문자열)

텍스트 표 형식 출력 채널(시간 채널 제외)에 대한 형식 지정자입니다. Fortran과 유사한 형식 문자열을 사용합니다. 예: ES20.6E2.

4.21.2.13. VTK 시각화 출력

WrVTK_Dir(문자열)

VTK 시각화 파일의 출력 디렉터리입니다.

WrVTK(스위치)

VTK 시각화 데이터 출력:

  • 0: 없음

  • 1: 초기화 데이터만

  • 2: 애니메이션

  • 3: 모드 형상

WrVTK_type(스위치)

VTK 시각화 데이터 유형:

  • 1: 표면

  • 2: 기본 메쉬(선/점)

  • 3: 모든 메시(디버그)

참고

일부 빌드에서는 선/점만 지원될 수 있습니다. 표면이 지원되지 않는 경우 다음을 사용하십시오. WrVTK_type = 2 라인/포인트 데이터를 시각화합니다.

WrVTK_DT(들)

VTK 파일을 쓰기 위한 시간 단계입니다.

VTKNacDim (m, m, m, m, m, m)

형식의 VTK 표면 렌더링을 위한 나셀 치수 [x0, y0, z0, Lx, Ly, Lz]:

  • x0, y0, z0: 나셀 원점 오프셋

  • Lx, Ly, Lz: x, y, z를 따른 나셀 범위

4.21.2.14. 구현 참고 사항 및 모범 사례

  • 플로팅 MHK(MHK = 2)는 현재 지원됩니다. 다른 MHK 모드는 예상대로 작동하지 않습니다.

  • 외부 파일 경로(SeaState, MoorDyn, AeroDyn, InflowWind)는 작업 디렉토리를 기준으로 유효하거나 절대 경로를 지정합니다.

  • 조정 규칙:

    • 별도의 언급이 없는 한 위치와 높이는 MSL를 참조합니다.

    • 플랫폼 기준점(PtfmRefPos)는 운동과 하중의 결합점입니다.

    • 타워 베이스는 다음을 기준으로 정의됩니다. PtfmRefPos x와 y에서는, z에서는 MSL로.

  • 선택하다 OutFmt 정밀도와 파일 크기의 균형을 유지합니다. 예 ES20.6E2 폭이 고정된 과학적 표기법에 적합합니다.
