4.2.4. 솔버

OpenFAST 밀착 결합 솔버는 다음에서 구현됩니다. modules/openfast-library/src/FAST_Solver.f90. 이는 연속 상태를 통합하고 Newton-Raphson 수렴 반복과 함께 일반화된 알파 체계를 사용하여 모듈 간의 입력-출력 결합을 해결합니다.

  • 사용자 입력 매개변수

  • 일반화된 알파 통합

  • 모듈 주문

  • 야코비안 구조

    • 변수선택(VF_Solve 깃발)

    • 야코비 구조(TC 야코비 행렬)

    • 야코비안 업데이트 전략

    • 모듈별 야코비안 기여

    • 선형 해결

    • 수렴 확인

  • 솔버의 출력 채널

4.2.4.1. 사용자 입력 매개변수

모든 솔버 매개변수는 기본 OpenFAST 입력 파일(*.fst) 아래 기능 스위치 및 플래그 및 밀착 결합/솔버 섹션.

매개변수

유형

설명

DT

실수

글로벌(솔버) 시간 단계(초)입니다. 모든 모듈 시간 단계는 다음과 같거나 정수 제수여야 합니다. DT.

ModCoupling

정수

결합 방법.

  • 1 – 느슨한 결합: 구조 모듈(ED/BD/SD)은 옵션 1로 처리되며 ~ 아니다 엄격한 뉴턴 루프에 참여하십시오.

  • 2 – 고정된 야코비안 업데이트와의 긴밀한 결합(DT_UJac 업데이트 빈도를 제어합니다).

  • 3 – 적응형 야코비안 업데이트와의 긴밀한 결합(뉴턴 루프가 반복 예산 내에서 수렴하지 못할 때마다 야코비안이 다시 작성됨)

RhoInf

실수

일반화된 알파 적분기에 대한 수치적 감쇠 매개변수 ρπ. 범위 [0, 1]; 1 = 수치적 감쇠 없음(2차 정확도), 0 = 최대 감쇠(1차 정확도). 일반적인 값: 0.9. 감소 RhoInf 1 미만이면 정확도가 약간 떨어지지만 고주파수 수치 노이즈가 감쇠됩니다.

MaxConvIter

정수

솔버가 수렴 실패를 선언하기 전 시간 단계당 뉴턴 수렴 반복의 최대 횟수입니다. 일반적인 값: 20. 와 함께 ModCoupling=2 또는 1, 실패 시 치명적인 오류가 발생합니다. ~와 함께 ModCoupling=3 야코비 행렬이 먼저 재구축되고 경고가 발생하기 전에 단계가 다시 시도됩니다.

ConvTol

실수

수렴 내성. 평균이 다음과 같을 때 반복이 중지됩니다. L2-뉴턴 업데이트 벡터의 표준은 이 값보다 낮습니다. 일반적인 값: 1.0e-4. 허용오차가 엄격하면 계산 비용이 증가하지만 엄격한 문제에는 필요할 수 있습니다.

DT_UJac

실수

야코비안 재구축 사이의 시간 간격(초) ModCoupling=2.

  • 다음의 경우 DT_UJac < DT: 야코비안은 수렴 반복 예산의 일부만으로 재구축됩니다.

  • 다음의 경우 DT_UJac ≥ DT: 야코비 행렬은 매 번 재구성됩니다. CEILING(DT_UJac/DT) 시간 단계.

  • 환경 DT_UJac 매우 크다(예: 9999) 전체 시뮬레이션에 대해 야코비안을 고정합니다. 프로파일링에 유용하거나 시스템이 거의 선형이고 야코비 행렬이 비용이 많이 드는 경우에 유용합니다.

UJacSclFact

실수

야코비안의 행과 열을 로드하는 데 적용되는 조건 조정 배율 인자입니다. 선형 해석 전에 힘과 모멘트 변수를 이 계수로 나누고 나중에 다시 곱하여 변위/속도 항목에 상대적인 하중 항목의 크기를 동일하게 만듭니다. 일반적인 값: 1.0e5 해양 시스템용; 매우 크거나 매우 작은 터빈의 경우 조정이 필요할 수 있습니다.

CompElast

정수

구조 역학 모듈을 선택합니다: 1 = ElastoDyn, 2 = BeamDyn(블레이드만 해당, ElastoDyn는 여전히 타워/플랫폼을 처리함), 3 = 단순화된 ElastoDyn. 선택한 모듈은 다음과 같은 경우 TC 구성원이 됩니다. ModCoupling ≥ 2.

CompSub

정수

하위 구조 모듈: 0 = 없음, 1 = SubDyn, 2 = ExtPtfm, 3 = SlD(SoilDyn). SubDyn는 다음과 같은 경우 TC 세트에 합류합니다. ModCoupling ≥ 2.

CompHydro

정수

0 = 없음, 1 = HydroDyn. HydroDyn는 항상 옵션 1입니다.

CompMooring

정수

0 = 없음, 1 = MAP++, 2 = FEAMooring, 3 = MoorDyn, 4 = OrcaFlex. 계류 모듈은 항상 옵션 1입니다.

CompAero

정수

공기역학 모듈: 0 = 없음, 1 = AeroDisk, 2 = AeroDyn. AeroDyn는 육상 터빈의 경우 옵션 2이고 MHK의 경우 옵션 1입니다.

CompServo

정수

컨트롤러 모듈: 0 = 없음, 1 = ServoDyn. ServoDyn는 기본적으로 사후 해결이지만 구조 컨트롤러(타워, 블레이드, 나셀 StC)가 활성화되면 옵션 1이 됩니다.

4.2.4.2. 일반화된 알파 통합

밀착 결합 솔버는 다음 형식의 2차 ODEs를 적분합니다.

\[\mathbf{M}\,\ddot{\mathbf{q}} + \mathbf{f}(\mathbf{q}, \dot{\mathbf{q}}, t) = 0\]

사용하여 일반화 알파 방법 (정 & 헐버트, 1993). 다음과 같이 지정된 스펙트럼 반경 ρρ가 주어지면 RhoInf, 메소드 매개변수는 다음과 같습니다.

\[\begin{split}\alpha_m &= \frac{2\rho_\infty - 1}{\rho_\infty + 1} \\ \alpha_f &= \frac{\rho_\infty}{\rho_\infty + 1} \\ \gamma &= \tfrac{1}{2} - \alpha_m + \alpha_f \\ \beta &= \tfrac{1}{4}(1 - \alpha_m + \alpha_f)^2\end{split}\]

수렴 루프 전체에서 사용되는 두 가지 파생 계수는 다음과 같습니다.

\[\begin{split}\beta' &= h^2 \beta \frac{1 - \alpha_f}{1 - \alpha_m} \\ \gamma' &= h \gamma \frac{1 - \alpha_f}{1 - \alpha_m}\end{split}\]

여기서 h = DT.

상태 벡터 레이아웃 – 솔버는 모듈별로 유지합니다. 일반화된 좌표 (q) 4개의 열이 있는 벡터:

열

의미

q

변위/방향 상태(DerivOrder = 0)

v

속도 상태(DerivOrder = 1)

vd

가속(물리적, 모듈에서) CalcContStateDeriv)

a

알고리즘 가속(일반화 알파 내부 변수)

각 단계 시작 시 상태 예측:

\[\begin{split}q_{n+1}^{\rm pred} &= q_n + h v_n + h^2[(\tfrac{1}{2} - \beta)a_n + \beta\, a_{n+1}] \\ v_{n+1}^{\rm pred} &= v_n + h[(1-\gamma)a_n + \gamma\, a_{n+1}]\end{split}\]

동안 FAST_SolverInit 각 모듈은 다음을 기준으로 분류됩니다. ModCoupling 자체 물리 유형을 가지며 순서가 지정된 인덱스 배열 중 하나에 할당됩니다. Glue_TCParam 구조:

4.2.4.4. 야코비안 구조

두 개의 별도 야코비 행렬이 조립됩니다.

  1. TC/Option-1 야코비안 (BuildJacobianTC) — 주요 시간 단계 수렴 루프의 경우.

  2. IO 야코비안 (BuildJacobianIO) - 초기 및 선형화 입력-출력 해결을 위해.

4.2.4.4.1. 변수선택(VF_Solve 깃발)

동안 FAST_SolverInit → SetVarSolveFlags, VF_Solve 플래그는 야코비 행렬에 나타나야 하는 변수에 설정됩니다.

  • 연속 상태 모든 TC 모듈의 (자동).

  • 모션 메시 TC-to-TC 매핑의 입력/출력(모든 필드).

  • 모션 메시 TC-to-Option1 또는 Option1-to-TC 매핑의 입력 가속.

  • 메쉬 로드 TC/Option1 매핑과 관련된 입력 및 출력.

  • 메쉬 로드 매핑이 모멘트를 전달할 때 대상 모듈의 변위 출력(모멘트 암 야코비안 항에 필요)

  • 변수 대 변수 TC/Option1 모듈의 매핑된 입력/출력.

  • 다음을 포함하는 모든 변수 VF_NoLin 에서 제외됩니다 VF_Solve.

4.2.4.4.2. 야코비 구조(TC 야코비 행렬)

조립된 TC 야코비안 J 크기가 있다 NumJ × NumJ, 어디:

\[N_J = \underbrace{N_Q}_{\text{TC states}} + \underbrace{N_{U_T}}_{\text{TC inputs}} + \underbrace{N_{U_1}}_{\text{Option-1 inputs}}\]

열과 행은 다음과 같이 분할됩니다.

\[\begin{split}\mathbf{J} = \begin{bmatrix} J_{11} & J_{12} \\ J_{21} & J_{22} \end{bmatrix}\end{split}\]

여기서

  • J₁₁ (NumQ × NumQ) — TC 변위/속도 상태에 대한 가속도 잔차의 미분(모듈에서 형성됨) dXdx 하위 야코비 행렬과 일반화된 알파 탄젠트).

  • J₁₂ (NumQ × NumU_T) — TC 입력에 대한 가속도 잔차의 미분(에서 dXdu).

  • J₂₁ (NumU_T × NumQ) — TC 상태에 대한 입력 잔차의 도함수(에서 dUdx = dUdy · dydx).

  • J₂₂ (NumU × NumU) - 로드 조절 행/열을 포함하여 입력에 대한 입력 잔차의 파생물입니다.

오른쪽(XB)에는 잔차가 포함됩니다.

  • 상태 잔여 (행 iJX): 예측된 속도 미분과 모듈에서 계산한 가속도 간의 차이입니다.

  • 입력 잔차 (행 iJU): 메시 매핑에서 계산된 입력 간의 차이(FAST_InputSolve) 및 현재 반복.

하중 부분(행 iJL)는 다음과 같이 미리 나누어집니다. UJacSclFact 조건화를 개선하기 위해 인수분해하기 전.

4.2.4.4.3. 야코비안 업데이트 전략

ModCoupling = 2 (수정된 업데이트)

다음 카운터 중 하나가 0에 도달하면 야코비 행렬이 다시 작성됩니다.

  • UJacStepsRemain - 남은 단계; 초기화됨 CEILING(DT_UJac/DT) 야코비 행렬이 재구성될 때마다.

  • UJacIterRemain - 반복 예산 초기화됨 CEILING(DT_UJac/DT · MaxConvIter) 언제 DT_UJac < DT.

수렴이 실패하면 솔버는 즉시 치명적인 오류를 반환합니다.

ModCoupling = 3 (적응형 업데이트)

야코비 행렬은 수렴 루프가 처음 실패할 때 다시 작성됩니다. 강제 재구축 후에도 단계가 여전히 수렴되지 않으면 치명적이지 않은 경고가 발행되고 시뮬레이션이 진행됩니다.

4.2.4.4.4. 모듈별 야코비안 기여

모듈 수준 야코비안 부분 행렬은 내부의 유한 차분을 통해 계산됩니다. BuildJacobianTC 및 BuildJacobianIO 사용하여 MV_Perturb / MV_ComputeDiff / MV_ComputeCentralDiff 유틸리티 ModVar. 플래그가 지정된 각 변수에 대해 VF_Solve:

  1. 양의 크기 섭동 적용 Var%Perturb 작업 상태/입력 배열에.

  2. 부르다 FAST_CalcOutput (또는 FAST_GetContStateDeriv).

  3. 동일한 음의 섭동을 적용합니다.

  4. 다시 전화하세요.

  5. 중심차를 계산합니다: (y_plus - y_minus) / (2·Perturb).

방향 변수의 경우(FieldOrientation), 섭동은 직접 추가보다는 쿼터니언 구성에 의해 적용됩니다(MV_Perturb), 차이점은 회전 벡터(MV_ComputeDiff).

4.2.4.4.5. 선형 해결

LU 인수분해 J 으로 계산됩니다 LAPACK_getrf 시스템은 다음과 같이 해결됩니다. LAPACK_getrs (포장 NWTC_LAPACK). 업데이트 전략이 재구축을 트리거할 때까지 동일한 인수분해된 행렬이 수렴 반복 전반에 걸쳐 재사용됩니다.

4.2.4.4.6. 수렴 확인

각 뉴턴 단계 이후 수렴 오류는 평균입니다. L2-업데이트 벡터의 표준:

\[e = \frac{\|\Delta \mathbf{z}\|_2}{N_J}\]

여기서 \(\Delta \mathbf{z}\) 상태 및 입력 업데이트를 결합합니다. 다음과 같은 경우 루프가 종료됩니다. e < ConvTol (ErrID_None) 또는 반복 횟수가 도달하면 MaxConvIter (ErrID_Fatal 또는 ErrID_Warn 에 따라 ModCoupling).

4.2.4.5. 솔버의 출력 채널

세 개의 출력 채널이 기록됩니다. DriverWriteOutput 활성화되면 각 단계가 출력 파일에 표시됩니다.

색인

콘텐츠

1

단계의 총 수렴 반복(TotalIter)

2
