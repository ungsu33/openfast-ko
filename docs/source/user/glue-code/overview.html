4.2.1. 접착제 코드 개요

OpenFAST 글루 코드는 개별 물리 모듈(ElastoDyn, AeroDyn, HydroDyn, ServoDyn 등)을 결합 시뮬레이션에 연결하는 소프트웨어 계층입니다. 주로 다음 지역에 산다. modules/openfast-library/src/ 에 의존하며 모듈 간에 교환되는 모든 변수에 대한 추상적인 설명은 ModVar 모듈 modules/nwtc-library/src/ModVar.f90 입니다.

높은 수준의 책임에는 다음이 포함됩니다.

  • 각 모듈 초기화 및 해당 변수를 글루 코드로 등록

  • 다중 속도 하위 스테핑 관리(시간 단계가 글로벌 시간 단계의 제수인 모듈)

  • 한 모듈의 출력을 다른 모듈의 입력으로 매핑(모션 메시, 로드 메시 및 스칼라 변수)

  • 느슨한 결합 또는 긴밀한 일반화 알파 결합에서 시간 단계 루프 실행

  • 조립된 시스템을 선형화하여 상태공간 행렬 생성

4.2.1.1. 소스 파일

파일

목적

FAST_Subs.f90

최상위 초기화: 입력 파일을 읽고 각 모듈의 _Init및 호출 MV_AddModule 는 모든 모듈을 글루 코드로 등록합니다.

4.2.1.3. 시간 단계 루프(개요)

각 호출 FAST_SolverStep 는 다음 순서를 따릅니다.

  1. 수정 반복 (외부 루프) – 최대 p%MaxConvIter 반복.

  2. 옵션 2 – 입력 해석 + 상태 업데이트 + 느슨하게 결합된 모듈용 CalcOutput .

  3. 옵션 1 입력이 TC 출력에 의존하고 동일한 뉴턴 루프에 수렴되는 – 반암시적 모듈에 대한 입력 해석 + 상태 업데이트.

  4. TC 입력 해결 – 밀착 결합 모듈에 대한 입력을 수집합니다.

  5. 수렴 반복 (내부 루프) – 업데이트 표준이 아래로 떨어질 때까지 TC 상태 및 입력의 Newton-Raphson 업데이트 ConvTol 또는 반복 제한에 도달했습니다.

  6. 해결 후 입력 해결 – ServoDyn, 외부 유입.

모듈 등록 및 변수 순서는 다음 페이지에 자세히 설명되어 있습니다. 모듈 변수(ModVar). 모듈별 변수가 전역 배열과 야코비 행렬로 결합되는 방법은 다음에서 다룹니다. ModGlue – 모듈을 글로벌 어레이로 결합. 솔버 알고리즘과 야코비안 구성은 다음에서 다룹니다. 솔버.
