4.10.2. 입력 파일

사용자는 기본 ElastoDyn 입력 파일뿐만 아니라 타워 및 타워에 대한 별도의 입력 파일을 통해 구조 모델 매개변수를 구성합니다. 나중에 여기에 문서화될 다른 것들.

입력 파일에 줄을 추가하거나 제거해서는 안 됩니다.

4.10.2.1. 단위

ElastoDyn는 SI 시스템(kg, m, s, N)을 사용합니다. 별도로 지정하지 않는 한 각도는 라디안 단위로 간주됩니다.

4.10.2.2. ElastoDyn 기본 입력 파일

기본 ElastoDyn 입력 파일은 타워, 나셀, 구동계 및 블레이드(BeamDyn가 사용되지 않는 경우)를 포함하여 OpenFAST 구조에 대한 모델링 옵션 및 형상을 정의합니다. 또한 구조의 초기 조건을 설정합니다.

4.10.2.2.1. 시뮬레이션 제어

다음을 설정합니다: Echo ElastoDyn가 ElastoDyn 기본, 에어포일 및 블레이드 입력 파일의 내용을 에코하도록 하려면 TRUE에 플래그를 지정하세요(입력 파일의 오류를 디버깅하는 데 유용함). 에코 파일의 명명 규칙은 다음과 같습니다. OutRootFile.ED.ech. OutRootFile ElastoDyn 독립형 실행 시 드라이버 입력 파일의 I/O SETTINGS 섹션에 지정되거나 결합 시뮬레이션 실행 시 OpenFAST 프로그램에 의해 지정됩니다.
