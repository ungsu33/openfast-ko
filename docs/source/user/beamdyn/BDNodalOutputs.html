절점 출력

명명된 출력 외에도 섹션 4.7.3.3.5 위에서 BeamDyn를 사용하면 전체 세트 블레이드 노드 동작 및 부하를 출력할 수 있습니다(현재 타워 노드는 사용할 수 없음). 엑셀 파일의 BeamDyn_Nodes 탭을 참고해주세요 OutListParameters.xlsx 에서 사용 가능한 전체 출력 매개변수 목록을 확인할 수 있습니다.

이 섹션은 다음을 따릅니다. END 위에서 설명한 일반 출력 섹션의 명령문으로, 구분 기호 설명 줄과 다음 optino가 포함되어 있습니다.

BldNd_BlOutNd 출력할 노드를 지정합니다. 현재는 사용되지 않습니다.

해당 OutList 섹션은 BeamDyn에 의해 생성된 노드 출력 수량을 제어합니다. 이 섹션에서 사용자는 출력할 채널 계열의 이름을 지정합니다. 각 채널의 출력 이름은 블레이드 번호, 노드 번호 및 채널 제품군 이름을 결합하여 BeamDyn에 의해 내부적으로 생성됩니다. 예를 들어, 사용자가 지정하는 경우 TDxr 채널 패밀리 이름으로 출력 채널은 다음 규칙에 따라 이름이 지정됩니다. B\(\mathbf{\beta}\)N###TDxr 여기서 \(\mathbf{\beta}\) 블레이드 번호이고, ### 세 자리 노드 번호입니다.
