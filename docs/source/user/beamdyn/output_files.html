4.7.4. 출력 파일

BeamDyn는 선택한 옵션에 따라 에코 파일, 요약 파일, 시계열 결과 파일 등 세 가지 유형의 출력 파일을 생성합니다. 다음 섹션에서는 이러한 파일의 목적과 내용을 자세히 설명합니다.

4.7.4.1. Echo 파일

사용자가 설정한 경우 Echo BeamDyn 기본 입력 파일의 TRUE에 플래그를 지정하면 이 파일의 내용이 명명 규칙을 사용하여 파일에 반영됩니다. InputFile.ech. 에코 파일은 입력 파일을 디버깅하는 데 유용합니다. BeamDyn가 입력 파일을 구문 분석하는 동안 오류가 발생하면 에코 파일의 내용이 잘립니다. 오류는 일반적으로 마지막으로 성공적으로 에코된 줄 다음 줄에 해당합니다.

4.7.4.2. 요약 파일

독립 실행형 모드에서 BeamDyn는 명명 규칙을 사용하여 요약 파일을 생성합니다. InputFile.sum 만약에 SumPrint 매개변수는 TRUE로 설정됩니다. FAST에 결합하면 요약 파일 이름이 지정됩니다. InputFile.BD.R*.B*.sum.yaml. 이 파일에는 다음을 포함하여 시뮬레이션에 대한 주요 정보가 요약되어 있습니다.

  • 블레이드 질량.

  • 블레이드 길이.

  • 블레이드 질량 중심.

  • BD 좌표계의 초기 전역 위치 벡터입니다.

  • BD 좌표계의 초기 전역 회전 텐서.

  • 분석 유형.

  • 수치적 감쇠 계수.

  • 시간 단계 크기.

  • Newton-Raphson 솔루션의 최대 반복 횟수입니다.

  • 중지 기준의 수렴 매개변수입니다.

  • Newton-Raphson 해의 인수분해 빈도.

  • 수치 적분(구적법) 방법.

  • FE 사다리꼴 구적법에 사용되는 메쉬 세분화 계수입니다.

  • 요소 수.

  • FE 노드 수.

  • BD 좌표계에서 FE 노드의 초기 위치 벡터입니다.

  • BD 좌표계에서 FE 노드의 초기 회전 벡터입니다.

  • BD 좌표계의 구적 점 위치 벡터입니다. 가우스 구적법의 경우 가우스 점의 물리적 좌표가 나열됩니다. 사다리꼴 구적법의 경우 구적점의 물리적 좌표가 나열됩니다.

  • 로컬 블레이드 기준 좌표계의 직교 지점에서의 단면 강성과 질량 행렬. 이는 구적점 계산에 사용되는 데이터이며 BeamDyn가 필요에 따라 단면 속성을 구적점에 선형적으로 보간하므로 블레이드 입력 파일의 섹션과 다를 수 있습니다.

  • BD 좌표계에서 FE 노드의 초기 변위 벡터입니다.

  • BD 좌표계에서 FE 노드의 초기 회전 변위 벡터입니다.

  • BD 좌표계에서 FE 노드의 초기 병진 속도 벡터입니다.

  • BD 좌표계에서 FE 노드의 초기 각속도 벡터입니다.

  • 요청된 출력 정보입니다.

이러한 수량은 모두 BD 좌표계의 이 파일에 출력되며, 이는 BeamDyn 계산에서 내부적으로 사용됩니다. 아래 첨자로 표시된 초기 블레이드 기준 좌표계 \(r0\) IEC 표준을 따르는 내부 BD 좌표계와 관련됩니다. 표 4.3 에서 섹션 4.7.5.

4.7.4.3. 결과 파일

BeamDyn 시계열 결과는 명명 규칙을 사용하여 텍스트 기반 파일에 기록됩니다. DriverInputFile.out 여기서 DriverInputFile BeamDyn가 독립형 모드로 실행될 때 드라이버 입력 파일의 이름입니다. BeamDyn가 FAST에 연결된 경우 FAST는 BeamDyn 결과를 포함하는 마스터 결과 파일을 생성합니다. 결과는 DriverInputFile.out 각 열은 데이터 채널(첫 번째 열은 항상 시뮬레이션 시간임)이고 각 행은 시뮬레이션 시간 단계에 해당하는 테이블 형식입니다. 데이터 채널은 기본 입력 파일의 OUTPUT 섹션에 지정됩니다. BeamDyn 생성 파일의 열 형식은 다음을 사용하여 지정됩니다. OutFmt 기본 입력 파일의 매개변수입니다.
