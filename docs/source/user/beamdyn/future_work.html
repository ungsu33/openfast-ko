4.7.6. 향후 개발 계획

다음 목록에는 BeamDyn 소프트웨어에 대한 향후 작업이 포함되어 있습니다.

  • 단정밀도의 수치 문제를 제거합니다.

  • 고유값 분석을 구현합니다.

  • 독립 실행형 버전의 입력 옵션을 개선하여 더욱 사용자 친화적으로 만들었습니다.

  • 계산 효율성을 위해 모달 방법을 기반으로 GEBT를 구현합니다.

  • 블레이드 단면 속성 입력에 대한 더 많은 옵션을 추가합니다. 예를 들어, 일반적인 등방성 빔의 경우 단면 오프셋, 재료 특성 등을 포함한 엔지니어링 매개변수를 사용하여 6개의 빔을 생성합니다. \(\times\) BeamDyn에는 6개의 행렬이 필요합니다.

  • BeamDyn를 사용하여 합성 빔 구조 모델링에 대한 일반 지침 작성(예: 시간 단계 선택 방법, 모델 이산화 선택 방법, 블레이드 참조 축 정의 방법, 6x6 질량/강성 행렬을 얻는 위치 등)

  • FAST의 응용 프로그램을 풍력 터빈 시스템의 다른 가는 구조물(예: 타워, 계류 라인 및 샤프트)로 확장합니다.

  • 계산 효율성을 위해 회전 DOFs(굽힘, 비틀림)만 사용하여 단순화된 형태의 GEBT를 개발합니다.
