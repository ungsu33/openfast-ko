4.7.2. BeamDyn 실행

이 섹션에서는 개인용 컴퓨터에서 BeamDyn를 얻고 실행하는 방법에 대해 설명합니다. 소프트웨어의 독립형 버전과 FAST 결합 버전이 모두 고려됩니다.

4.7.2.1. BeamDyn 소프트웨어 다운로드

BeamDyn 소프트웨어에는 독립형과 FAST 시뮬레이터에 결합되는 두 가지 형태 중에서 선택할 수 있습니다. 사용자가 반드시 두 가지 양식을 모두 필요로 하는 것은 아니지만 처음부터 블레이드 모델을 구축하는 경우 독립 실행형 모델에 익숙하고 실행해야 할 가능성이 높습니다. 독립형 드라이버는 FAST 내에서 육상/해상 풍력 터빈의 에어로-하이드로-서보-탄성 시뮬레이션을 수행하는 것이 목표인 경우에도 모델 문제 해결에도 도움이 됩니다.

4.7.2.2. BeamDyn 실행

4.7.2.2.1. 독립 실행형 BeamDyn 프로그램 실행

독립형 BeamDyn 프로그램, BeamDyn_Driver.exe, FAST에 연결하지 않고 사용자 입력 모델의 정적 및 동적 응답을 시뮬레이션합니다. 결합된 버전과 달리 독립 실행형 소프트웨어에는 기본 및 블레이드 BeamDyn 입력 파일 외에 드라이버 파일을 사용해야 합니다. 이 드라이버 파일은 블레이드 루트의 동작과 외부에서 적용되는 하중을 포함하여 일반적으로 FAST에 의해 BeamDyn에 제공되는 입력을 지정합니다. 독립 실행형 BeamDyn를 사용할 때 BeamDyn 요약 파일과 결과 출력 파일을 모두 사용할 수 있습니다(섹션 참조). 출력 파일 BeamDyn 출력 파일에 관한 자세한 내용은)

예를 들어 다음을 입력하여 DOS 명령 프롬프트에서 독립 실행형 BeamDyn 소프트웨어를 실행합니다.

>BeamDyn_Driver.exe Dvr_5MW_Dynamic.inp

어디, Dvr_5MW_Dynamic.inp 섹션에 설명된 대로 BeamDyn 드라이버 입력 파일의 이름입니다. BeamDyn 드라이버 입력 파일.

4.7.2.2.2. FAST와 연성된 BeamDyn 실행

다음과 같이 입력하여 명령 프롬프트에서 결합된 FAST 소프트웨어를 실행합니다.

>openfast.exe Test26.fst

여기서 Test26.fst 기본 FAST 입력 파일의 이름입니다. 이 입력 파일에는 FAST 내에서 BeamDyn 기능을 활성화 또는 비활성화하는 기능 스위치와 BeamDyn 입력 파일에 대한 해당 참조가 있습니다. 자세한 내용은 FAST와 함께 제공된 설명서를 참조하십시오.
