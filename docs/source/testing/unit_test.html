5.1. 단위 테스트

OpenFAST처럼 역동적이고 협업적인 소프트웨어 패키지에서는 강력한 단위 테스트 시스템을 통해 여러 계층의 코드에 대한 신뢰도가 가장 잘 달성됩니다. 강력한 테스트 관행을 통해 전체 OpenFAST 커뮤니티는 코드 블록 뒤에 숨은 의도를 이해하고 더 빠르고 자신감 있고 안정적으로 기능을 디버깅하거나 확장할 수 있습니다.

OpenFAST 모듈의 단위 테스트는 다음을 통해 수행됩니다. 시운전. 테스트 드라이브는 CMake 변수가 있을 때 OpenFAST부터 CMake까지 함께 컴파일됩니다. BUILD_TESTING 켜져 있고(기본적으로 꺼져 있음) CMake 변수 BUILD_UNIT_TESTING 켜져 있습니다(다음 경우에는 기본적으로 켜져 있습니다). BUILD_TEST 켜져 있음).

BeamDyn 및 NWTC 라이브러리 모듈에는 일부 샘플 단위 테스트가 포함되어 있으며 향후 개발 및 테스트를 위한 참조 역할을 해야 합니다.

5.1.1. 종속성

단위 테스트에는 다음 패키지가 필요합니다.

  • CMake

  • 테스트 드라이브 - unit_test/test-drive의 OpenFAST 저장소에 포함됨

5.1.2. 컴파일 중

단위 테스트 컴파일은 일반적으로 OpenFAST 컴파일과 유사하게 CMake로 처리됩니다. CMake를 구성한 후 BUILD_TESTING 켜져 있으면 단위 테스트 프레임워크에 포함된 각 모듈에 대해 새 빌드 대상이 생성됩니다. [module]_utest. 그 다음에, make 테스트 대상:

cmake .. -DBUILD_TESTING=ON
make beamdyn_utest

그러면 단위 테스트 실행 파일이 생성됩니다. openfast/build/unit_tests/beamdyn_utest.

5.1.3. 실행 중

모듈의 단위 테스트를 실행하려면 단위 테스트 바이너리를 실행하면 됩니다. 예를 들어:

>>>$ ./openfast/build/unit_tests/beamdyn_utest
All tests PASSED

각 테스트가 실행될 때마다 통과 또는 실패 상태가 제공됩니다. 테스트가 실패하면 오류 메시지가 출력됩니다. 실패 사례에는 다음 출력이 표시됩니다.

5.1.4. 단위 테스트 추가

각각의 새로운 항목에 대해 단위 테스트가 포함되어야 합니다. 테스트 가능 코드 블록(서브루틴 또는 함수). 테스트 가능한 것은 개발자의 재량이지만 풀 요청 검토 프로세스의 한 요소는 테스트 적용 범위를 평가하는 것입니다.

새로운 단위 테스트를 tests 옆에 있는 디렉토리 src 각 모듈에 포함된 디렉터리입니다. 예를 들어, 모듈 디렉토리는 다음과 같이 구성될 수 있습니다.

openfast/
  └── modules/
      └── sampledyn/
          ├── src/
          │   ├── SampleDyn.f90
          │   └── SampleDyn_Subs.f90
          └── tests/
              ├── sampledyn_utest.F90
              ├── test_SampleDyn_Feature1.F90
              ├── test_SampleDyn_Feature2.F90
              └── test_SampleDyn_Feature3.F90

각 단위 테스트 파일에는 다음에 따라 단위 테스트 목록을 채우는 함수를 내보내는 모듈이 포함되어야 합니다. test-drive 선적 서류 비치. 이 모듈에는 다음을 수행하는 서브루틴이 포함되어 있습니다. error 에 의해 채워지는 인수 check 에서 제공하는 서브루틴 test-drive. 그만큼 sampledyn_utest.F90 인접한 모듈에서 모든 단위 테스트 목록을 수집하고 실행합니다. 이러한 프로그램은 다음을 통해 컴파일됩니다. unit_tests/CMakeLists.txt 파일에 모든 관련 모듈과 프로그램이 지정되어 있습니다.

기존 단위 테스트를 참조하세요. BeamDyn 또는 NWTC Library 단위 테스트 드라이버를 구성하고 구축하는 방법에 대한 예를 보여주는 단위 테스트입니다. 또한 test-drive 문서 시운전.
