5.2.5.4.1. Visual Studio 회귀 테스트를 사용하는 Windows

  1. openfast 저장소를 복제하고 테스트 데이터베이스를 초기화합니다.

    1. git 명령 셸 창 열기(예: git bash)

    2. 작업 디렉터리를 로컬 저장소가 위치할 위의 위치로 변경합니다. 저장소는 이 위치의 openfast라는 폴더에 배치됩니다.

    기음. 유형: git clone https://github.com/openfast/openfast.git (이렇게 하면 컴퓨터에 openfast 저장소의 로컬 버전이 생성됩니다). 다음과 같은 내용이 표시됩니다.

    Cloning into 'openfast'...

Receiving objects: 100% (23801/23801), 92.10 MiB  18.99 MiB/s, done.
Resolving deltas: 100% (13328/13328), done.
Checking connectivity... done.

    1. 유형: cd openfast (작업 디렉토리를 openfast 폴더로 변경하세요)

    2. 유형: git checkout dev (이것은 openfast repo의 올바른 분기에 로컬 repo를 배치합니다)

    3. 유형: git submodule update --init --recursive (이렇게 하면 테스트 데이터베이스가 컴퓨터에 다운로드됩니다.) 다음과 같은 내용이 표시됩니다.

  2. 회귀 테스트 DISCON DLLs 구축

    1. Visual Studio 솔루션(Discon.sln)에 위치 openfast\vs-build\Discon 접는 사람

    2. 솔루션 구성 및 솔루션 플랫폼에 대해 각각 릴리스 및 x64를 선택합니다.

    3. 메뉴 표시줄에서 선택 Build->Build Solution

    4. 이제 파일이 표시됩니다. Discon.dll, Discon_ITIBarge.dll, 및 Discon_OC3Hywind.dll 사용 중인 openfast\reg_tests\r-test\glue-codes\fast\5MW_Baseline\ServoData 접는 사람.

  3. Visual Studio를 사용하여 OpenFAST 빌드

    1. Visual Studio 솔루션(FAST.sln)에 위치 openfast\vs-build\FAST 접는 사람

    2. 솔루션 구성 및 솔루션 플랫폼으로 각각 Release_Double 및 x64를 선택합니다.

    3. 메뉴 표시줄에서 선택 Build->Build Solution

      1. openfast 빌드를 처음 시도하는 경우 빌드 오류가 발생합니다!!! [(ii) 및 (iii) 단계를 계속 진행하고, 그렇지 않으면 FAST가 성공적으로 빌드되면 (3d) 단계를 계속 진행합니다.]

      2. 메뉴 표시줄을 사용하여 빌드 취소 Build->Cancel

        [ VS는 FASTlib에 있는 프로젝트 파일의 빌드 순서/종속성에 대해 혼란스러워하지만 VS를 취소하고 다시 시작하면 어떻게든 부분 빌드의 정보로 이 문제를 바로잡기에 충분합니다.]

      3. Visual Studio를 닫은 다음 (a)~(c) 단계를 반복합니다.

    4. 이제 파일이 표시됩니다. openfast_x64_Double.exe 사용 중인 openfast\build\bin 접는 사람.

  4. 회귀 테스트 준비

    1. 라는 하위 디렉터리를 만듭니다. reg_tests 사용 중인 openfast\build 접는 사람.

    2. 내용을 복사하세요. openfast\reg_tests\r-test 까지 openfast\build\reg_tests.

  5. OpenFAST 회귀 테스트 실행

    1. Python용으로 구성된 명령 프롬프트를 엽니다(예: Anaconda3).

    2. 작업 디렉토리를 다음으로 변경하십시오. openfast\reg_tests

    3. 유형: python manualRegressionTest.py ..\build\bin\openfast_x64_Double.exe 2.0 1.9

      당신은 이것을보아야합니다 : executing AWT_YFix_WSt

    4. 최종적으로 다음과 같은 내용이 나타날 때까지 테스트는 하나씩 계속 실행됩니다.
