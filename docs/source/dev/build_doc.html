6.1.6.3. 개발 문서

OpenFAST 문서는 다음에서 호스팅됩니다. 문서 읽기. 를 통해 자동으로 생성됩니다. readthedocs 빌드 시스템은 두 가지 모두에서 main 및 dev 는 새로운 커밋이 추가될 때마다 분기됩니다. 이 문서에서는 재구성된 텍스트 마크업 언어.

6.1.6.3.1. 이 문서를 로컬에서 빌드하기

문서는 다음과 같이 컴파일됩니다. Sphinx는 Python 기반 도구입니다. 이 패키지와 다음에 나열된 다른 필수 Python 패키지를 설치합니다. openfast/docs/requirements.txt 포함 pip 또는 다른 Python 패키지 관리자.

이러한 추가 패키지는 선택 사항이며 요구 사항 파일에 포함되지 않습니다.

  • Doxygen

  • Doxylink

  • 그래프비즈

  • LaTeX

Doxygen 및 Graphviz는 웹사이트에서 직접 설치하거나 다음과 같은 패키지 관리자를 사용하여 설치할 수 있습니다. brew, yum또는 apt.

문서를 로컬로 작성하면 HTML 파일 세트와 이에 수반되는 필수 파일이 생성됩니다. 기본 HTML 파일이 존재합니다 openfast/build/docs/html/index.html. 이 파일은 모든 브라우저에서 열 수 있으며 마치 다른 웹 사이트인 것처럼 로컬로 생성된 문서를 보고 탐색할 수 있습니다.

6.1.6.3.1.1. 순수 파이썬 빌드

시스템에서 CMake 및 Make를 사용할 수 없는 경우 다음을 사용하여 문서를 직접 생성할 수 있습니다. 스핑크스.

참고

이 방법은 Doxygen을 통해 API 문서를 생성하지 않습니다.

먼저 다음 위치에 디렉터리를 생성하여 디렉터리 구조를 표준 OpenFAST 빌드에 맞춥니다. openfast/build. 그런 다음 이동 openfast/build 를 실행하고 다음 명령을 실행하세요.

# sphinx-build -b <builder-name> <source-directory> <output-directory>
sphinx-build -b html ../docs ./docs/html

이것이 성공적으로 완료되면 html 파일이 다음 위치에 생성됩니다. 모든 웹 브라우저에서 열 수 있는 build/docs/html/index.html . CMake 및 Make를 사용하여

6.1.6.3.1.2. 빌드

OpenFAST 디렉토리에서 build 디렉터리로 이동합니다. 그런 다음 이 플래그를 사용하여 CMake를 실행합니다. -DBUILD_DOCUMENTATION=ON. CMake는 문서 작성에 필요한 파일로 빌드 시스템을 구성합니다.

다음으로 명령을 실행하여 문서를 컴파일합니다.

make docs

이는 먼저 Doxygen API 문서를 빌드한 다음 Sphinx 문서를 빌드합니다. 성공적으로 완료되면 html 파일이 생성됩니다. build/docs/html/index.html . CMake 및 Make를 사용하여

문서를 구성하고 작성하는 전체 절차는 다음과 같습니다.

mkdir build
cd build
cmake .. -DBUILD_DOCUMENTATION=ON
make docs

소스 파일이 수정된 경우 openfast/docs/source, 다음을 실행하여 html 파일을 간단히 업데이트할 수 있습니다. make 명령을 다시 실행하세요.

아래 표에는 문서와 관련된 make-target이 나열되어 있습니다.
