6.1.6.7. 버전 관리

OpenFAST 팔로우 의미론적 버전 관리. 요약하면 버전 번호가 MAJOR.MINOR.PATCH이면 구성 요소가 다음과 같이 증가한다는 의미입니다.

  • 호환되지 않는 API 변경 사항을 도입할 때 MAJOR 버전,

  • 이전 버전과 호환되는 방식으로 기능을 추가하는 경우 MINOR 버전

  • 이전 버전과 호환되는 버그 수정 시 PATCH 버전.

예를 들어, OpenFAST-v1.0.0-123-gabcd1234-dirty OpenFAST를 다음과 같이 설명합니다.

버전 구성요소

설명

v1.0.0

MAJOR.MINOR.PATCH 번호 매기기 시스템; GitHub에서 NREL(현재 2025년 이후에는 NLR라고 함)가 수행한 태그가 지정된 커밋에 해당합니다.

123-g

빌드에 대한 가장 최근 태그 이후의 추가 커밋 수( -g 이다 git)

abcd1234

현재 커밋 해시의 처음 8자

더러운

로컬 변경이 이루어졌지만 커밋되지 않았음을 나타냅니다. 로컬 변경사항이 없으면 생략됨
