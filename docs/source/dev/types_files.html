6.1.6.4. 유형 파일 및 OpenFAST 레지스트리

최신 소프트웨어 프로젝트인 OpenFAST는 맞춤형 데이터 유형의 복잡한 시스템을 갖추고 있습니다. Fortran에서는 이를 "파생 데이터 유형"이라고 합니다. 각 모듈에는 추가할 수 있지만 OpenFAST 프레임워크를 준수해야 하는 고유한 파생 유형 컬렉션이 포함되어 있습니다. 모듈 유형은 일반적으로 다음과 같은 포함된 프로그램에 의해 자동 생성됩니다. OpenFAST 레지스트리. OpenFAST 레지스트리는 C로 작성되었으며 다음에서 사용되는 유사한 유틸리티를 적용했습니다. WRF. 방문 OpenFAST 레지스트리 README 자세한 내용은

OpenFAST 레지스트리에는 특정 모듈에 필요한 유형을 설명하는 입력 파일이 필요합니다. 일반적으로 모든 모듈은 비슷한 명명 규칙을 사용합니다. <모듈>_Registry.txt, 결과 Fortran 코드는 다음과 같은 파일에 저장됩니다. <모듈>_Types.f90. 예를 들어, AeroDyn OpenFAST 레지스트리 입력 파일은 다음 위치에 있습니다. openfast/modules/aerodyn/src/AeroDyn_Registry.txt 결과적으로 자동 생성된 Fortran 소스 코드는 다음과 같습니다. openfast/modules/aerodyn/src/AeroDyn_Types.f90.

유형 모듈이 자동 생성되므로 데이터 유형에 대한 모든 변경 사항은 이후에 변경 사항을 덮어쓰지 않도록 OpenFAST 레지스트리 입력 파일에 직접 표현되어야 합니다.

6.1.6.4.1. OpenFAST 레지스트리 컴파일

OpenFAST 레지스트리는 CMake를 통해 OpenFAST 빌드 시스템에 포함됩니다. 그러나 기본값은 ~ 아니다 OpenFAST 레지스트리 실행 파일을 컴파일하고 대신에 포함된 유형 모듈을 사용하십시오. 자식 OpenFAST를 컴파일하는 동안. 빌드 프로세스에 OpenFAST 레지스트리를 포함하고 레지스트리 프로그램을 컴파일하려면 다음을 사용하여 CMake를 구성합니다. GENERATE_TYPES 깃발:

cmake .. -DGENERATE_TYPES=ON

와 함께 GENERATE_TYPES 활성화하면 CMake가 openfast-레지스트리 다른 모든 대상의 종속성으로 컴파일할 대상입니다. OpenFAST 레지스트리 실행 파일은 다음에서 찾을 수 있습니다. openfast/build/modules/openfast-registry/openfast-registry.

6.1.6.4.2. 유형 모듈 재생성

다음을 사용하여 GENERATE_TYPES 플래그가 활성화되면 OpenFAST 레지스트리를 사용할 수 있도록 구성된 모듈에 추가 단계가 추가됩니다. 추가 단계에서는 OpenFAST 레지스트리를 실행하고 기존 모듈을 덮어쓰는 유형 모듈을 재생성합니다. 유형 모듈에 대한 모든 변경 사항은 다음에서 분명하게 드러납니다. 자식. 레지스트리 입력 파일이 변경되지 않은 모듈의 경우 결과 유형 모듈은 변경되지 않습니다. 그러나 수정된 ​​레지스트리 입력 파일의 경우 출력 유형 모듈이 다시 컴파일됩니다.

6.1.6.4.3. 새로운 유형 모듈 추가

새로운 유형 모듈을 추가하는 프로세스는 다음과 같습니다. 유형 모듈 재생성 면밀히. 여기서는 새 입력 파일에서 레지스트리를 실행하고 결과 유형 모듈을 컴파일 단계에 포함하도록 CMake를 구성하는 추가 단계가 필요합니다.

먼저, 새로운 OpenFAST 레지스트리 입력 파일을 생성해야 합니다. 그런 다음 해당 모듈의 레지스트리를 통과하도록 구성해야 합니다. CMakeLists.txt:

# This is the control statement for allowing the Registry to execute
if (GENERATE_TYPES)

    # Here is the CMake wrapper-function to execute the Registry
    # syntax: generate_f90_types(<Registry input file> <output file location>)
    generate_f90_types(src/AeroDyn_Registry.txt ${CMAKE_CURRENT_LIST_DIR}/src/AeroDyn_Types.f90)
    generate_f90_types(src/New_Registry.txt ${CMAKE_CURRENT_LIST_DIR}/src/New_Types.f90)
endif()

마지막으로 결과 유형 모듈을 해당 모듈의 소스 파일에 추가해야 합니다.

# AeroDyn lib
set(AD_LIBS_SOURCES
    src/AeroDyn.f90
    src/AeroDyn_IO.f90
    src/AirfoilInfo.f90
    src/BEMT.f90
    src/DBEMT.f90
    src/BEMTUncoupled.f90
    src/UnsteadyAero.f90
    src/fmin_fcn.f90
    src/mod_root1dim.f90
    src/AeroDyn_Types.f90
    src/AirfoilInfo_Types.f90
    src/BEMT_Types.f90
    src/DBEMT_Types.f90
    src/UnsteadyAero_Types.f90

    # Add the new types module here
    src/New_Types.f90
)

CMake가 올바르게 구성되면 빌드 프로세스 중에 OpenFAST 레지스트리가 실행 중임을 나타내는 메시지가 표시됩니다.
