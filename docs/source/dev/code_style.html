6.1.6.2. 코드 스타일

OpenFAST와 그 기본 모듈은 대부분 2003 표준을 준수하는 Fortran으로 작성되었지만 모듈은 C 또는 C++로 작성할 수 있습니다. 는 NWTC Programmer's Handbook 는 FAST Framework 작업 및 OpenFAST에 코드 추가와 관련된 모든 질문에 대한 최종 참조입니다.

일반적으로 코드는 읽기 쉽게 작성되어야 합니다. 구문상의 편의나 간결함으로 인해 가독성이 저하되어서는 안 됩니다. 이에 대한 예외는 성능상 읽기 어려운 코드가 필요한 상황입니다. 여기서는 코드에서 쉽게 알 수 없는 내용을 설명하기 위해 주석 블록을 사용해야 합니다. 들여쓰기는 일반적으로 탭 없이 공백 3개로 이루어집니다.
