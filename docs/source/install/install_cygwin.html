2.8.2. CMake 및 Cygwin 64비트를 사용하여 Windows에서 OpenFAST 빌드

WARNING: 이 빌드 프로세스에는 상당히 오랜 시간이 걸립니다. GNU 도구가 필요하지 않은 경우 Windows 사용자는 다음 섹션 중 하나를 참조하는 것이 좋습니다.

  • 바이너리 다운로드

  • Windows용 Visual Studio를 사용하는 CMake

  • Visual Studio를 사용하여 Windows에서 OpenFAST 빌드.

2.8.2.1. 필수 구성 요소 설치

  1. 다운로드 및 설치 시그윈 64비트. 당신은해야합니다 Run as Administrator 설치 프로세스를 완료하려면

    • 선택하다 Install from internet

    • 기본 설치 위치 선택

    • 기본 패키지 다운로드 위치 선택

    • 선택하다 Direct connection

    • 다운로드 사이트를 선택하세요

    • 다음 단계를 참조하세요. select packages. 또는 이 단계를 건너뛰고 실행할 수 있습니다. setup-x86_64.exe 나중에 언제든지 필요한 소프트웨어를 선택하고 설치할 수 있습니다.

  2. 컴파일에 필요한 패키지 선택 OpenFAST. 선택하다 binary 패키지이며 소스 옵션이 아닙니다.

    • 선택하다 Category 보기에서 우리는 패키지를 설치할 것입니다 Devel 및 Math

    • 에서 Devel 다음 패키지를 설치용으로 표시하세요

      • cmake

      • cmake-doc

      • cmake-gui

      • cygwin-devel

      • gcc-core

      • gcc-fortran

      • gcc-g++

      • git

      • make

      • makedepend

    • 에서 Math 다음 패키지를 설치용으로 표시하세요

      • liblapack-devel

      • libopenblas

    • 테스트 스위트를 실행하려면 다음에서 이러한 선택적 패키지를 설치하십시오. Python:

      • python3

      • Python3-numpy

    • 딸깍 하는 소리 Next 종속성을 충족하기 위해 설치 프로세스에서 설치를 요청하는 모든 추가 패키지를 수락합니다.

  3. 그것은 추천 설치 후 컴퓨터를 다시 시작할 것을 Cygwin 그리고 필요한 모든 패키지.

2.8.2.2. OpenFAST 컴파일하기

여기에서 CMake 지침을 사용하여 Linux에서 선택하세요. Linux용 Make가 포함된 CMake/macOS.

2.8.2.3. 기타 팁

  • 달리고 싶다면 openfast.exe 에서 cmd 터미널을 추가한 다음 C:\cygwin64\lib\lapack 및 C:\cygwin64\home\<USERNAME>\software\bin 당신에게 %PATH% 환경 설정의 변수입니다. 바꾸다 <USERNAME> Windows 시스템의 계정 이름으로.

  • Cygwin의 경우 최적화 레벨 2로 컴파일하는 것이 좋습니다. cmake 명령에서 빌드 모드를 변경하면 됩니다.

    cmake .. -DCMAKE_BUILD_TYPE=RelWithDebInfo
