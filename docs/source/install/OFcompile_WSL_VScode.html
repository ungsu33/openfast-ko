2.4.4.1. 가이드: WSL 및 VS 코드를 사용하여 Windows에서 OpenFAST 설정

참고

작성자가 작성한 가이드에서 수정됨 skvibimigger 이슈 댓글에서: OpenFAST 문제 #2904

이 가이드는 Linux용 Windows 하위 시스템(WSL)을 사용하여 Windows 시스템의 소스에서 OpenFAST를 컴파일하기 위한 포괄적인 단계별 프로세스를 제공합니다. 이 방법은 안정성이 높으며 기본 Windows 컴파일러와 관련된 일반적인 문제를 방지합니다.

2.4.4.1.1. 1부: Linux 환경 설정(WSL)

2.4.4.1.1.1. 1. Linux용 Windows 하위 시스템(WSL) 설치

WSL를 사용하면 Windows에서 직접 Linux 배포판을 실행할 수 있습니다.

  • 관리자 권한으로 Windows PowerShell 또는 명령 프롬프트를 엽니다.

  • 설치 명령을 실행하십시오.

    wsl --install

  • 메시지가 나타나면 컴퓨터를 다시 시작하십시오. 재부팅 후 Ubuntu 터미널이 열리고 설정이 완료됩니다. Unix 사용자 이름과 비밀번호를 생성하라는 메시지가 표시됩니다.

2.4.4.1.1.2. 2. 빌드 도구 및 종속성 설치

Ubuntu 터미널이 실행되면 필요한 컴파일러와 라이브러리를 설치해야 합니다.

  • 업데이트 패키지 목록:

    sudo apt-get update

  • 컴파일러 설치 및 시스템 구축:

    sudo apt-get install -y build-essential gfortran cmake git

  • 필수 수학 라이브러리 설치:

    sudo apt-get install -y libblas-dev liblapack-dev

  • (선택 사항) 문서 종속성을 설치합니다.

    경고

    해당 texlive-full 패키지는 수 기가바이트이므로 설치하는 데 시간이 오래 걸릴 수 있습니다.

    sudo apt-get install -y graphviz texlive-full doxygen
pip install sphinx

2.4.4.1.2. 2부: OpenFAST 컴파일하기

2.4.4.1.2.1. 1. OpenFAST 저장소 복제

주요 소스 코드를 다운로드하세요:

git clone https://github.com/OpenFAST/openfast.git

2.4.4.1.2.2. 2. 테스트 케이스(하위 모듈) 다운로드

회귀 테스트 파일(r-test)은 별도의 저장소(Git 하위 모듈)에 있으며 명시적으로 다운로드해야 합니다.

  • 다음으로 이동합니다. openfast 예배 규칙서:

    cd openfast

  • 하위 모듈을 초기화하고 다운로드합니다.

    git submodule init
git submodule update --progress

2.4.4.1.2.3. 3. CMake로 빌드하고 만들기

CMake를 사용하여 빌드를 구성하고 make를 사용하여 프로젝트를 컴파일합니다.

  • 빌드 디렉터리를 생성하고 해당 디렉터리로 이동합니다.

    mkdir build
cd build

  • CMake를 실행하여 빌드를 구성합니다.

    cmake .. -DBUILD_SHARED_LIBS=ON -DBUILD_TESTING=ON -DBUILD_DOCUMENTATION=ON

  • 프로젝트를 컴파일합니다.

    make

오류 없이 완료되면 OpenFAST가 성공적으로 빌드됩니다.

2.4.4.1.3. 3부: Python 환경 설정

2.4.4.1.3.1. 1. 호환되는 Python 버전 설치

새로운 Ubuntu 릴리스의 기본 Python 버전은 일부 패키지에 비해 너무 새로운 버전일 수 있습니다. Python 3.11을 설치합니다.

  • "deadsnakes" 저장소를 추가합니다:

    sudo add-apt-repository ppa:deadsnakes/ppa

  • Python 3.11 및 해당 가상 환경 모듈을 설치합니다.

    sudo apt update
sudo apt install python3.11 python3.11-venv

2.4.4.1.3.2. 2. 가상 환경 생성 및 활성화

Python 패키지에 대한 독립형 환경을 만듭니다.

  • 홈 디렉터리로 이동합니다.

    cd ~

  • 가상 환경을 생성합니다:

    python3.11 -m venv openfast_env

  • 환경을 활성화합니다:

    source openfast_env/bin/activate

2.4.4.1.3.3. 3. Python 패키지 설치

  • 설치하다 pyOpenFAST 로컬 소스에서:

    cd ~/openfast/glue-codes/python/
pip install .

  • Jupyter 및 기타 라이브러리를 설치합니다.

    pip install jupyterlab pandas matplotlib

2.4.4.1.4. 4부: VS 코드 구성 및 사용

2.4.4.1.4.1. 1. VS 코드 확장 설치

  • Windows에서 VS 코드를 엽니다.

  • 확장 탭으로 이동합니다.

  • 다음 공식 Microsoft 확장을 설치하세요.

    • WSL

    • 주피터

    • Python

2.4.4.1.4.2. 2. VS 코드를 WSL에 연결

  • VS 코드 창의 왼쪽 하단에 있는 녹색 >< 버튼을 클릭하세요.

  • 메뉴에서 "WSL에 연결"을 선택합니다. 창이 다시 로드됩니다.

2.4.4.1.4.3. 3. 노트북 생성 및 실행

  • 연결된 VS 코드 창에서 프로젝트 폴더를 엽니다(예: /home/YOUR_USERNAME).

  • 라는 이름의 새 파일을 만듭니다. simulation.ipynb.

  • 노트북이 열리면 오른쪽 상단에 있는 “커널 선택”을 클릭하세요.

  • "Python Environments…"를 선택하고 가상 환경과 연결된 커널을 선택합니다. openfast_env (Python 3.11.x).

2.4.4.1.5. 파트 5: 예제 테스트 스크립트

이 코드를 노트북의 셀에 붙여넣어 테스트 시뮬레이션을 실행하고 결과를 플롯합니다.

# Import the correct class from the correct file
from pyOpenFAST.fast import FastLibAPI
import os
import matplotlib.pyplot as plt

print("--- Step 1: Setting up paths ---")

# The OpenFAST library file
openfast_library_path = os.path.expanduser('~/openfast/build/modules/openfast-library/libopenfastlib.so')

# Use the minimal example test case
sample_input_file = '/home/YOUR_USERNAME/openfast/reg_tests/r-test/glue-codes/openfast/MinimalExample/Main.fst'

print("\n--- Step 2: Running OpenFAST ---")
try:
        # Initialize the OpenFAST library interface
        fast_api = FastLibAPI(
                library_path=openfast_library_path,
                input_file_name=sample_input_file
        )

        # Run the simulation
        fast_api.run()
        print("✅ OpenFAST simulation ran successfully!")

        # --- Step 3: Post-processing ---
        print("\n--- Step 3: Accessing results ---")

        results = fast_api.output_values
        channels = fast_api.output_channel_names

        print(f"Simulation produced {results.shape[0]} time steps and {results.shape[1]} output channels.")
        print(f"Available channels: {channels}")

        # Define the channel to plot (choose one from the "Available channels" list)
        channel_to_plot = 'OoPDefl1'

        # Find the index of the channel
        try:
                channel_idx = channels.index(channel_to_plot)
                time = results[:, 0]
                channel_data = results[:, channel_idx]

                # Plot the results
                plt.figure(figsize=(10, 5))
                plt.plot(time, channel_data)
                plt.xlabel('Time (s)')
                plt.ylabel(f'{channel_to_plot} (m)')
                plt.grid(True)
                plt.title(f'{channel_to_plot} vs. Time')
                plt.show()
                print("✅ Plot generated successfully!")

        except ValueError:
                print(f"❌ Could not find '{channel_to_plot}' in the output channels.")

except Exception as e:
        print(f"❌ An error occurred during the simulation: {e}")

2.4.4.1.6. 메모

  • 바꾸다 YOUR_USERNAME 해당되는 경우 실제 Linux 사용자 이름을 사용하세요.

  • 런타임 오류를 방지하려면 모든 종속성이 올바르게 설치되었는지 확인하세요.

  • 추가 도움이 필요하면 다음을 참조하세요. OpenFAST GitHub 저장소.
