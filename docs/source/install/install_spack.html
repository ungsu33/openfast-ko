2.8.1. Spack으로 OpenFAST 구축

OpenFAST를 빌드하고 설치하는 프로세스 스팩 Linux 또는 macOS의 는 여기에 설명되어 있습니다.

2.8.1.1. 종속성

OpenFAST에는 다음과 같은 종속성이 있습니다.

  • LAPACK 라이브러리. 사용자가 설정해야 합니다. 표준 경로에서 라이브러리를 찾을 수 없는 경우 CMake에 적합한 BLAS_LIBRARIES 및 LAPACK_LIBRARIES 입니다. 사용 BLASLIB .

  • 선택적 C++ API의 경우, HDF5 (제공: HDF5_ROOT) 및 yaml-cpp (제공: YAML_ROOT)

  • 선택적 테스트 프레임워크인 Python 3+ 및 Numpy

2.8.1.2. macOS 또는 Linux에서 Spack을 사용하여 반자동으로 OpenFAST 구축

다음은 다음을 사용하여 macOS에서 OpenFAST 및 해당 종속성을 대부분 자동으로 빌드하는 방법을 설명합니다. 스팩 Linux 또는 macOS의. 이는 Spack을 사용하여 모든 Linux 시스템에서 OpenFAST를 구축하기 위한 템플릿으로 사용할 수도 있습니다.

이 지침은 Homebrew를 통해 설치된 다음 도구를 사용하여 macOS 10.11에서 개발되었습니다.

  • GCC 6.3.0

  • CMake 3.6.1

  • pkg-config 0.29.2

2.8.1.2.1. 1단계

github에서 공식 Spack 저장소를 확인하세요. ${HOME}):

cd ${HOME} && git clone https://github.com/LLNL/spack.git

2.8.1.2.2. 2단계

Spack 쉘 지원을 추가하십시오. 다음 줄을 추가하여 .profile :

export SPACK_ROOT=${HOME}/spack
. $SPACK_ROOT/share/spack/setup-env.sh

2.8.1.2.3. 3단계

복사 https://raw.githubusercontent.com/OpenFAST/openfast/dev/share/spack/package.py 파일을 Spack 설치에 추가합니다:

mkdir ${SPACK_ROOT}/var/spack/repos/builtin/packages/openfast
cd ${SPACK_ROOT}/var/spack/repos/builtin/packages/openfast
wget --no-check-certificate https://raw.githubusercontent.com/OpenFAST/openfast/dev/share/spack/package.py

2.8.1.2.4. 4단계

시도해 보세요 spack info openfast 를 사용하여 Spack이 작동하는지 확인하세요. 그렇다면 다음을 통해 사용 가능한 컴파일러를 확인하십시오.

machine:~ user$ spack compilers
==> Available compilers
-- gcc ----------------------------------------------------------
gcc@6.3.0  gcc@4.2.1

-- clang --------------------------------------------------------
clang@8.0.0-apple  clang@7.3.0-apple

2.8.1.2.5. 5단계

선택한 GCC 버전으로 OpenFAST를 설치합니다.

spack install openfast %gcc@6.3.0

C++ API로 OpenFAST를 설치하려면 다음을 수행하십시오.

spack install openfast+cxx %gcc@6.3.0

그래야지! Spack은 별도로 지정하지 않는 한 자동으로 최신 종속성을 사용합니다. 예를 들어 OpenFAST가 일부 특정 종속성 버전을 사용하도록 제한하려면 Spack 설치 명령을 실행할 수 있습니다.

spack install openfast %gcc@6.3.0 ^hdf5@1.8.16

실행 파일과 라이브러리는 다음 위치에 있습니다.

spack location -i openfast

적절한 경로를 추가하십시오. OpenFAST를 실행하기 위한 PATH 및 LD_LIBRARY_PATH .
