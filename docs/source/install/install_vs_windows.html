2.4.3.1. Visual Studio를 사용하여 Windows에서 OpenFAST 빌드

이 지침은 특히 다음의 독립 실행형 Visual Studio 프로젝트에 적용됩니다. openfast/vs-build. Windows 사용자를 위해 별도의 CMake 설명서가 제공됩니다. 섹션 2.4.7.

2.4.3.1.1. 전제조건

  1. Visual Studio 버전(VS).

    • NOTE: 모든 VS Studio 버전이 Intel 컴파일러에서 지원되는 것은 아닙니다. 일반적으로 Fortran 컴파일러는 Visual Studio보다 최신 버전이어야 합니다. Intel Fortran 호환 VS 버전 목록 및 특정 설치 참고 사항이 있습니다. 여기.

    • 현재 VS 2019 Community Edition, VS 2022 Professional 및 VS 2022 Community Edition은 OpenFAST로 테스트되었습니다. VS 2022 커뮤니티 다운로드 여기.

    • Visual Studio를 설치할 때 다음을 선택하십시오. Desktop development with C++ 아래에 Workloads.

    • 참고: MAP++ 및 레지스트리에 포함된 C/C++ 프로젝트 파일은 VS 2019와 호환되지만 VS의 최신 버전으로 자연스럽게 업그레이드됩니다.

  2. 인텔 포트란 컴파일러

    • Intel의 IFX 컴파일러로 컴파일하는 것이 좋습니다. 이는 다음 항목에 포함됩니다. Intel Fortran Essentials 설치 패키지. 현재 버전 2025.3에서 테스트되었습니다.

    • 다운로드할 수 있습니다 Intel Fortran Essentials 여기. 참고: 설치하지 마십시오. oneAPI HPC Toolkit

    • Visual Studio 설치를 완료한 후에만 Intel Fortran을 설치하십시오. Intel Fortran은 사용 중인 Visual Studio 버전과 호환되어야 합니다. 보다 여기 호환성 테이블의 경우.

  3. 윈도우용 힘내

    • 다운로드 및 설치 자식 Windows용.

  4. Windows용 Python 3.x(회귀/단위 테스트용)

    • OpenFAST의 테스트 프레임워크에는 Python을 사용해야 합니다.

    • 참조하세요 섹션 5 이 주제에 대한 자세한 내용은 OpenFAST 테스트를 참조하세요.

    • 우리는 Continuum과 협력해 왔습니다. 아나콘다 Windows용 Python 3.6 설치.

2.4.3.1.2. OpenFAST 컴파일하기

  1. 열려 있는 A command prompt, 또는 git bash 의 껍질 Start 메뉴

  2. OpenFAST 저장소를 복제할 디렉터리를 생성합니다(변경 code 원하는 이름으로)

    mkdir code
cd code

  3. OpenFAST 저장소 복제

    git clone https://github.com/openfast/openfast.git

그러면 다음과 같은 디렉토리가 생성됩니다. openfast 이내에 code 예배 규칙서.

  1. Windows 탐색기를 사용하여 디렉터리로 이동합니다. openfast\vs-build\FAST 그리고 FAST.sln Visual Studio 솔루션 파일. 그러면 FAST 솔루션 및 관련 프로젝트가 포함된 Visual Studio가 열립니다.

NOTE: Visual Studio 2015 이상을 사용하는 경우 두 가지 모두 업그레이드하라는 메시지가 표시됩니다. Fast_Registry.vcxproj 그리고 MAP_dll.vcxproj 파일을 최신 형식으로 변환합니다. 해당 파일에 대한 업그레이드를 수락하세요.

  1. 다음과 같이 원하는 솔루션 구성을 선택합니다. Release, 원하는 솔루션 플랫폼(예: x64 메뉴바 아래에 있는 드롭다운 상자를 사용합니다.

  2. 다음을 사용하여 솔루션을 구축합니다. Build->Build Solution 메뉴 옵션.

  3. 솔루션이 오류 없이 빌드된 경우 실행 파일은 openfast\build\bin 접는 사람.
